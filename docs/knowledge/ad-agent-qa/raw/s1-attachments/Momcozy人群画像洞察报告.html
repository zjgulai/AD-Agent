1数据口径说明

两条转化链路独立，指标不可混比。

① DTC 链路（Meta / Google / TikTok → 独立站）

三条渠道引流到 Shopify 独立站，可横向对比 CPA（获客成本 = Cost÷转化）、AOV（客单价 = 转化价值÷转化）、CVR、ROAS。转化环境一致，口径可比。

② Amazon 链路（ASI → 站内）

Amazon Search Insights 站内闭环，看 TGI（购买集中度）、SA 渗透率、NTB 新客占比、CVR。与 DTC 的 CVR 口径不同（站内 vs 独立站），不可混在同一张表对比。

📐 衍生指标口径：CPA = Cost ÷ 转化数；AOV = 转化价值 ÷ 转化数。TGI / SA 渗透率 / NTB 均为 Amazon ASI 原生指标，跨季度可比（相对指标）。
