# 四：产品功能

产品能够实现的六个方面的功能

1：市场洞察

2：增长策略

3：预算分配

4：素材生产

5：广告投放

6：实时优化

贯穿投前、投中、投后，适配不同客户不同阶段的需求

目前支持TikTok、Meta、Google三个平台的广告投放。

可以在GrowthGPT页面一键生成素材、创编计划。

# 五：数据产出逻辑

1:接入Claude、OpenAI、seedance等全球领先的大模型，调用不同大模型最新最先进的模型模块，并跟随大模型更新做实时更新。

2:接入十几家API，包括平台方TikTok、Facebook、Google等，第三方平台applovin、Fastmoss、Kalodata等数据，做数据拉取和交叉验证。

3:蒸馏诸多十年以上投手经验并植入系统中，同时还在持续自我学习和优化，行程整体专家skill模型。

4:采用如chatGPT自然对话模式作为交互页面，扩张客户可沟通交互维度。
