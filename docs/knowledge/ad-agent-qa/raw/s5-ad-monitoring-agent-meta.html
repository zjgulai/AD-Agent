系统不会把整个广告账户的所有数据都丢给大模型，而是像用手术刀一样精准筛选：按对象检索：只查当前出问题的这一个广告组（或 Campaign）的数据，无关的广告组一概不查。按时间窗检索：只查最近一段时间内（例如过去 24 小时或 7 天）的日志，半年前的陈年旧账不查。注入：把筛选出来的这两小块精准信息，拼接到大模型的提示词（Prompt）里发给它。
