# references（简体中文版）

这个目录是诊断知识库的**主档**，报告默认读这一套。

- 繁体版镜像在 `../references-zh-tw/`，内容一一对应、文件结构一致。
- 繁体版由 OpenCC 转换：大部分文件用 `s2twp`（台湾用词），`market-knowledge/hongkong.md` 用 `s2hk`（香港用字）。
- **要修改内容请改这里，再重新转换繁体版**，不要只改单边，避免两边不同步。
