# 诊断工具整合定义

> 定义每个诊断维度使用哪些工具、用工具做什么、产出什么。
> 原则：工具是为了「拿到证据」，不是为了炫技。报告中每个扣分项都应有工具取得的证据（截图、数据、实测结果）。

## 工具总览

| 工具 | 用途 | 产出物 |
|---|---|---|
| Agent Reach | 市场调研、竞品调研、当地消费习惯与口碑搜集 | 调研摘要、引用来源清单 |
| Browser / Playwright | 实测官网：购物流程、速度、移动端、事件触发 | 截图、流程录影、事件触发记录 |
| Imagegen | 生成报告视觉素材（雷达图占位、封面图、改善示意） | PNG/JPG 图片 |
| AEO/GEO 内容教练 | 评估内容结构、产出 FAQ/Schema 改造建议 | 内容诊断与改写示范 |
| Meta Ad Library | 查竞品与客户自己的在投广告 | 竞品素材清单、投放角度分析 |

## 一、品牌定位 × 工具

| 任务 | 工具 | 具体做法 | 产出 |
|---|---|---|---|
| 竞品识别 | Agent Reach | 搜「{品类} {市场} 品牌 推荐」，整理 Top 5 竞品 | 竞品清单 |
| 品牌声量检查 | Agent Reach | 搜品牌名+市场词，看第三方提及 | 声量摘要 |

## 工具使用顺序（标准诊断流程）

1. **Browser/Playwright 先跑**：官网实测（速度、结账流程、移动端）——10 分钟拿硬证据
2. **Pixel Helper 检查**：事件触发实测——5 分钟
3. **Meta Ad Library**：客户与竞品广告盘点——10 分钟
4. **Agent Reach**：市场调研 + AI 能见度实测 + 口碑搜集——15 分钟
5. **AEO/GEO 内容教练**：内容诊断——10 分钟
6. **Imagegen**：报告视觉素材（可选）——5 分钟

## 降级策略（工具不可用时）

| 工具不可用 | 降级方案 |
|---|---|
| Playwright 无法执行 | 改用人工浏览器实测 + 截图，记录相同检查项 |
| Agent Reach 失败 | 改用直接 WebSearch/Google，标注「调研深度受限」 |
| Meta Ad Library 无法访问 | 改搜竞品 FB/IG 主页「广告透明度」区块 |
| Imagegen 失败 | 报告视觉用纯 CSS/图表库替代，不阻塞交付 |
| AEO/GEO 教练不可用 | 用 `checklists/seo-aeo-geo.md` 人工逐项评分 |

## 证据存放约定

- 诊断过程中的截图、记录统一放在报告输出目录的 `evidence/` 子目录
- 报告内引用证据时标注来源（如「证据：evidence/checkout-flow.png」）
- 敏感信息（客户后台数据）不截图、不入报告，只描述结论
