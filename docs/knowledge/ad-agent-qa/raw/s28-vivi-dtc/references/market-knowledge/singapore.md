# 新加坡 · 市场知识库

> 核心判断：新加坡市场小但客单价高、消费者购买力强、对品质和品牌要求高。适合「高毛利、有故事」的品牌，不适合低价走量打法。

## 一、市场概况

- 人口约 600 万，人均 GDP 东南亚最高，消费力对标发达国家。
- 电商成熟：Shopee 第一、Lazada 第二、Amazon.sg 与 TikTok Shop 分食。
- 消费者决策理性：会比价、看成分、看评价，「便宜」不是最强卖点，「值得」才是。
- 多元种族：华人 ~74%、马来人 ~13%、印度人 ~9%，英文是主要商业语言。
- 市场小的含义：受众池小，广告容易快速触及上限，素材疲劳快，要频换素材。
- 广告 CPM 参考：Meta 新加坡 CPM 约 S$15-35，区域最贵之一，转化质量也最高。

## 六、法规与合规

> 新加坡对化妆品采「通报制、事后监管」，上市快但罚则重。法规会变动，重大投入前请当地法规顾问确认最新要求。

| 检查项 | 内容 |
|---|---|
| 事前注册/备案 | **要**。制度叫「化妆品通报」（Cosmetic Product Notification），经 HSA 的 PRISM 线上系统提交；HSA 不审查、确认函不代表官方背书。费用：一般化妆品每单品 S$13，眼周/唇部/口腔产品或含二胺类染发剂 S$28，第 4 个起变体各 S$8。通报效期 1 年，继续销售须每年再通报 |
| 时程 | **近乎即时**：确认函由系统自动生成，收到即可开始销售；官方未公布工作日承诺（文件准备时间另计） |
| 当地主体/境内责任人 | **要**。须由 ACRA 注册的新加坡公司担任「Person Responsible（责任人）」；外国公司不能直接通报，必须委托当地实体（可授权第三方服务商代操作）。标签须标该公司在新加坡的名称与地址 |
| 检验报告 | 上市前不强制提交；但须依 ASEAN 规范备妥 **PIF（产品信息档案）**（含安全评估员签署的安全评估报告）供 HSA 调阅。污染物限值：汞 ≤1 ppm、铅 ≤20 ppm、砷 ≤5 ppm、镉 ≤5 ppm、1,4-二恶烷 ≤10 ppm |
| 标签语言 | **英文必须**（可加其他语言但内容须与英文一致）；成分表 INCI 命名、按含量降序 |
| 广告宣称红线 | 任何治疗/预防疾病、改变生理机能的宣称均禁止（ASEAN 宣称指南＋新加坡 SCAP 广告守则）。罚则：未通报即销售最高 S$20,000 罚款及/或 12 个月监禁；含违禁成分最高 S$100,000 及/或 3 年监禁 |
| 分类升级陷阱 | 以治疗为目的（祛痘治疗霜、湿疹、抗真菌药膏）、局部抗菌消毒类、含药油膏 → 落入**治疗性产品（Therapeutic Products）须注册**，官方审评 60-270 个工作日（约 3 个月到 1 年以上），与即时通报天壤之别 |

**分类升级陷阱示例：** 同一瓶抗菌洗手液，写「清洁双手、清新体感」是化妆品（通报即卖）；写「杀灭 99.9% 病菌、预防感染」就可能被归治疗性产品——从即时变成数月起。拿不准分类可向 HSA 提交官方分类判定申请。

## 七、广告投放注意事项

- **英文为主、中文为辅**：主力受众用英文素材，中文素材针对华人细分可加分。
- **素材质感要求高**：新加坡消费者对粗糙素材容忍度低，精修图 + 原生 UGC 混合效果最佳。
- **受众池小**：类似受众（LAL）容易快速耗尽，建议用「广泛受众 + 好素材」让系统自己找人。
- **重内容质量**：新加坡用户教育程度高，成分党、研究型消费者多，广告落地页的「证据链」（成分、数据、评价）要做足。
- **合规严格**：健康/美妆功效宣称受 HSA 规范，减肥、医疗宣称是 Meta + 当地法规双重红线。
- **预算参考**：冷启动每日 S$50-100/组，CPM 高但转化价值也高，重点看 ROAS 不是 CTR。

## 八、文化禁忌与消费习惯

- **规则意识强**：退换货政策、配送时效、成分标示都要写得清清楚楚，模糊会被投诉。
- **投诉文化**：新加坡消费者遇到问题会直接留差评或投诉 CASE（消费者协会），客服响应要快。
- **促销节点**：Great Singapore Sale（6-7 月）、双数大促、黑色星期五都有人跟，但折扣深度不用像大马那么夸张。
- **品质敏感 > 价格敏感**：「Cheap」在新加坡甚至是负面词，文案用「value」「worth it」而非「cheapest」。
- **多元种族敏感**：素材注意种族平衡，别只出现单一种族；宗教议题（清真、印度教）保持中性。
- **送礼文化**：企业送礼、节庆礼盒（圣诞、新年）客单价高，B2B 礼盒是值得开发的线。
