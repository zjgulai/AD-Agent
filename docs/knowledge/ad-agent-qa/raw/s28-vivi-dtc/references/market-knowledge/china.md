# 中国大陆 · 市场知识库

> 核心判断：大陆是体量最大、但门槛也最高的市场。跨境电商路径（9610/1210）可以免注册备案先跑起来，但做不了线下铺货；要走一般贸易落地，必须先过法规注册这一关。先想清楚「跨境电商试水」还是「一般贸易落地」，两条路的时程与成本完全不同。

## 一、市场概况

- 人口约 14 亿，电商渗透率全球最高之一，移动支付与物流基建成熟。
- 平台生态与海外完全不同：天猫国际、京东国际、抖音电商、拼多多是主渠道；没有 Meta/Google/Shopee。
- 客群特征：一二线城市成分党、精致妈妈、功效党成熟；下沉市场价格敏感度极高。
- 消费力分层：一二线愿为品牌与成分付溢价；三四线及以下看性价比与直播议价。
- 台湾品牌心智：「台湾制造」在美妆保养、食品品类有品质联想，但国货品牌崛起快，不能只靠产地光环。
- 广告成本参考：抖音/小红书投放成本逐年上升，美妆类目竞争激烈，KOC 种草仍是性价比最高的冷启动方式。

## 五、物流选项

| 方案 | 时效 | 说明 |
|---|---|---|
| 保税仓发货（1210） | 2-5 天 | 先进保税仓再按订单清关发货，体验接近国内电商；商品需在跨境电商正面清单内 |
| 海外直邮（9610） | 7-15 天 | 台湾直发，时效长、体验差，适合试水期低库存运作 |
| 一般贸易进口+国内仓 | 1-3 天 | 完成注册备案后走一般贸易，可铺线下与经销 |

注意：1210 保税仓路径有「正面清单」限制，上架前先确认商品税号在清单内。

## 六、法规与合规

> 美妆品类进大陆的第一道硬门槛。法规会变动，重大投入前请当地法规顾问确认最新要求。

| 检查项 | 内容 |
|---|---|
| 事前注册/备案 | 一般贸易进口化妆品：**特殊化妆品要注册，普通化妆品要备案**。跨境电商 9610/1210 路径可免注册备案 |
| 时程 | 特殊化妆品注册 **12-16 个月**；普通化妆品备案 **4-6 个月** |
| 当地主体/境内责任人 | 一般贸易必须指定**境内责任人（RP）**；跨境电商路径由平台/境内服务商承担对应责任 |
| 检验报告 | 注册/备案需提交检验报告（微生物、重金属、毒理等）；跨境路径虽免注册，平台仍会抽检 |
| 标签语言 | 一般贸易：简体中文标签必标（成分表、备案/注册编号、境内责任人信息）；跨境电商商品可不贴中文标签，但销售页面须有中文说明 |
| 广告宣称红线 | 《广告法》极限词（「最」「第一」「国家级」）禁用；化妆品不可宣称医疗作用（治疗、消炎、生发等）；美白、防晒属特殊化妆品宣称，注册下来之前不能讲 |
| 分类升级陷阱 | 见下方「文案决定分类」 |

**分类升级陷阱（文案决定分类）：** 同一支洗发精，写「护色／减少褪色」是普通化妆品（备案 4-6 个月）；写成「补色／染色／上色」就可能被归为染发类＝特殊化妆品（注册 12-16 个月）。时程从 4 个月变 16 个月，详情页、短视频脚本、直播话术要一起管。

**特殊 vs 普通化妆品分界：** 染发、烫发、祛斑美白、防晒、防脱发，以及宣称新功效的产品＝特殊化妆品（注册制）；其余＝普通化妆品（备案制）。

**跨境电商路径的限制：** 9610/1210 免注册备案、上线快，但买家不得二次销售——意味着做不了线下铺货与经销。要走线下或招经销，必须走一般贸易＋完成注册/备案。

## 七、广告投放注意事项

- **投放平台完全不同**：Meta/Google 在大陆不可用，投放走抖音巨量引擎、小红书（聚光/蒲公英）、腾讯广告；海外投放经验要重新校准。
- **落地页门槛**：使用境内主机的网站需 ICP 备案才打得开；境外主机免备案但速度慢、且部分场景会被限制。多数品牌落地页直接用小红书店铺或天猫国际店替代。
- **素材语言**：简体中文+大陆审美与梗，台湾用语（「品质」「视频」「优惠」用法差异）会让用户出戏。
- **广告法红线**：极限词（最、第一、国家级）会被罚；功效宣称与注册分类绑定，没注册下来的宣称不能投。
- **预算参考**：冷启动建议先小红书 KOC 种草（单笔合作数百至数千人民币），跑出自然流量与口碑后再上付费投放。

## 八、文化禁忌与消费习惯

- **主权表述敏感**：地图、地名与地区标注须与官方口径一致，包装与官网要先自查，这是下架与舆情的第一雷区。
- **成分党成熟**：消费者会查成分表、看测评，功效宣称要有证据支撑。
- **全平台比价**：用户会在天猫、京东、拼多多、抖音比价，定价要全渠道一盘棋。
- **直播议价与赠品文化**：直播间砍价、要赠品是常态，定价要留出让利空间。
- **时效预期高**：习惯当日/次日达，跨境直邮 7-15 天的等待要在页面上管理预期。
- **简体为唯一书面语**：所有面向消费者的文字用简体中文，繁体会被视为不专业或代购号。

## 九、竞品分析参考

- **主要竞品：** 国际大牌（欧莱雅/雅诗兰黛系）、新锐国货（完美日记/花西子类）、成分党品牌（HFP/薇诺娜类）
- **价格带参考：** 美妆精华主力价格带约 ¥100-300；台湾品牌建议卡位「轻奢小众」区间，避免与国货白牌拼低价
- **渠道布局：** 天猫国际/京东国际（货架）、抖音（直播+短视频）、小红书（种草+店铺）

## 十、该市场的诊断侧重

- 品牌定位：中文品牌名与「小名」是否好念好记、有无负面谐音
- 官网健康度：大陆打开速度、ICP 备案、是否需要小程序商城
- 广告投放：投放平台与素材体系完全不同，海外 Pixel 经验不适用
- 私域流量：微信生态（公众号+企业微信+社群）是主力，搭配小红书群聊
- 法规合规：先确认走跨境电商（9610/1210，免注册、不可二次销售）还是一般贸易（注册/备案 4-16 个月、境内责任人），宣称文案会决定分类与时程
