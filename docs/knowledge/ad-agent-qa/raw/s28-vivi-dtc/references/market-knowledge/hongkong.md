# 香港 · 市场知识库

> 核心判断：香港市场小而精，消费者高度成熟、重效率、重性价比，对台湾品牌有天然好感。电商渗透率在成熟市场中偏低（习惯线下），但疫情后网购习惯已建立，DTC 品牌有机会。

## 一、市场概况

- 人口约 750 万，人均 GDP 高，消费力成熟。
- 线下零售极强（便利店、药妆店密度高），电商渗透率低于台湾，但 HKTVmall、淘宝、拼多多跨境正在改变习惯。
- 台湾品牌心智好：香港人对台湾食品、美妆、文创有「品质+文青」的正面联想。
- 语言：粤语为主，书面用繁体中文（港式用词），英文通用。
- 租金贵导致线下铺货成本高，反而给了 DTC 纯电商品牌空间。
- 广告 CPM 参考：Meta 香港 CPM 约 HK$60-120，与台湾接近或略高。

## 五、法规与合规

> 香港对化妆品采「上市后监管」，门槛远低于大陆，但宣称红线要守住。法规会变动，重大投入前请当地法规顾问确认最新要求。

| 检查项 | 内容 |
|---|---|
| 事前注册/备案 | **一般化妆品不需要**事前注册或备案，可直接上市；但含药性成分或宣称疗效的产品会被归为「药剂制品」，须向药剂业及毒药管理局注册 |
| 时程 | 一般化妆品无审批时程，可即上市；药剂制品注册以月计 |
| 当地主体/境内责任人 | 无强制境内责任人；进口商/经销商须承担《消费品安全条例》与《商品说明条例》下的责任 |
| 检验报告 | 非强制；建议备妥安全评估与重金属/微生物检验，以应对海关与消委会抽查 |
| 标签语言 | 中英文双语（安全警告与使用说明须中英并列）；成分表建议用 INCI |
| 广告宣称红线 | 《不良广告（医药）条例》：不可宣称治疗或预防疾病（如「治疗暗疮」「生发」属医药宣称）；《商品说明条例》禁虚假、误导性声称 |
| 分类升级陷阱 | 宣称「药用」「治疗」「医学级」或加入受管制成分，产品会落入药剂制品管理，须注册、时程以月计，等于从「即上市」变「数月起」 |

## 六、广告投放注意事项

- **粤语文案**：广告文案用书面粤语（「而家」「咁」「啲」）点击率明显高于普通话书面语；落地页可用标准繁体，但广告要够「港」。
- **台湾品牌故事**：「台湾制造」「台湾直送」本身是卖点，要放在素材前 3 秒。
- **比价精明**：香港消费者会在 HKTVmall、淘宝比价，独立站要给独家组合或会员价。
- **KOC 开箱**：香港 YouTube/IG 开箱文化强，中尾部 KOC（5k-50k 粉）合作性价比高。
- **预算参考**：冷启动每日 HK$300-500/组，受众池小，注意素材疲劳（同素材 2-3 周要换）。
- **Meta 政策**：与台湾类似，健康美妆宣称要收敛。

## 七、文化禁忌与消费习惯

- **效率至上**：网页慢 1 秒、结账多一步都直接走人；客服响应以「小时」计不是「天」。
- ** pragmatism 务实**：不买情怀账，「性价比」「功能」「快」比品牌故事更能打动，但台湾品牌故事是例外（有加分）。
- **差评文化直接**：不满意会在 LIHKG、FB 群组公开吐槽，危机处理要快且诚恳。
- **谐音与数字**：「4」不吉利、「8」吉利；礼盒定价可参考 HK$168、HK$228 这类吉利数字。
- **节庆**：农历新年、中秋、圣诞是礼盒高峰；母亲节/父亲节家庭消费强。
- **政治中立**：品牌避免触碰政治议题，保持中立最安全。
- **港式用词**：「质素」（品质）、「优惠」（折扣）、「速递」（快递），文案用词要港式，别出现「质量」「快递」「视频」这类内地/台湾用词。
