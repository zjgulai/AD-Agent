# DTC 跨境诊断框架

本框架用于评估 DTC 品牌跨境出海的准备度，共 6 大维度，总分 100 分。

## 评分总览（分阶段权重）

品牌所处阶段不同，权重不同。先用「品牌出海年限 + 复购情况」判断阶段，再套用对应权重。

| 维度 | 第一年（初期） | 第二年+（品牌黏着期） | 核心问题 |
|---|---|---|---|
| 1. 品牌定位 Brand Positioning | 15% | 25% | 你的品牌在目标市场有没有差异化？ |
| 2. 官网健康度 Website Health | 25% | 15% | 你的官网能不能承接跨境流量和订单？ |
| 3. SEO/AEO/GEO 准备度 | 15% | 15% | 你的内容能不能被 AI 和搜索引擎推荐？ |
| 4. 广告投放准备度 Ads Readiness | 25% | 15% | 你有没有准备好投放 Meta/Google 广告？ |
| 5. 私域流量 Private Domain | 10% | 20% | 你有没有建立可持续经营的客户关系？ |
| 6. 行动计划 Action Plan | 10% | 10% | 你知不知道自己接下来 30 天该做什么？ |

- **第一年（初期）**：重点是「能不能开始收钱」——官网与广告权重最高，先解决流量承接与投放基本功。
- **第二年+（品牌黏着期）**：重点是「客户会不会回来」——品牌与私域权重上调，靠复购摊平流量成本。

## 分级标准

| 分数 | 等级 | 定义 | 建议 |
|---|---|---|---|
| 0-59 | 🚨 待加强 | 基础建设不足，贸然出海风险高 | 先补齐基本功，再考虑投放广告 |
| 60-79 | ⚠️ 及格 | 有基础但缺乏竞争力，需要优化 | 针对弱项加强，可小预算测试 |
| 80-100 | ✅ 优秀 | 准备就绪，可积极拓展 | 加大投放，复制成功模式 |

## 1. 品牌定位 Brand Positioning（第一年 15% / 第二年+ 25%）

**核心问题：** 你的品牌在目标市场有没有差异化？

### 评分项目（每项 0-5 分）

| 项目 | 0 分 | 3 分 | 5 分 |
|---|---|---|---|
| 品牌名称差异化 | 与竞品完全同名或极相似 | 有差异但不易记忆 | 独特、易记、有联想 |
| 视觉识别一致性 | 无统一视觉 | 有基本视觉但不一致 | 高度一致且有辨识度 |
| 品牌主张独特性 | 与竞品无差异 | 有主张但不够聚焦 | 清晰、聚焦、打动目标客群 |
| 目标市场文化适配 | 完全未考虑 | 有考虑但未落地 | 深度适配当地文化与消费习惯 |
| 品牌故事可信度 | 无故事或虚假 | 有故事但平淡 | 真实、有温度、可信任 |

### 常见问题与建议

- **品牌名难念、与竞品过于相似** → 品牌名不一定要加后缀，但需要有一个「小名」，例如虚构品牌 Nordelle 后面加「小北」。不是每个人都会讲英文，小名可以让品牌更亲切、更好记。
- **视觉识别不够差异化** → 建议加入目标市场区隔色，强化品类联想
- **品牌主张模糊** → 建议聚焦单一痛点，用一句话说清楚「为什么选你」

## 2. 官网健康度 Website Health（第一年 25% / 第二年+ 15%）

**核心问题：** 你的官网能不能承接跨境流量和订单？

### 评分项目（每项 0-5 分）

| 项目 | 0 分 | 3 分 | 5 分 |
|---|---|---|---|
| 多币别与定价 | 仅单一币别 | 有多币别但定价策略不清 | 多币别+在地化定价 |
| 金流串接 | 仅支持信用卡 | 有 2-3 种支付 | 覆盖当地主流支付（GrabPay/TnG/Atome） |
| 物流选项 | 仅本地配送 | 有国际物流但选项少 | 多物流+运费计算器+追踪 |
| 行动装置优化 | 未优化 | 基本优化 | 完全优化（载入<3秒、一页式结账） |
| 页面载入速度 | >5 秒 | 3-5 秒 | <3 秒 |

### 常见问题与建议

- **缺少当地支付** → 建议串接 2C2P、iPay88 或 Atome
- **国际运费不透明** → 建议安装 Easyship 或类似运费计算器
- **手机体验差** → 建议改用 1:1 正方形商品图、简化结账流程

## 3. SEO/AEO/GEO 准备度（两个阶段皆 15%）

**核心问题：** 你的内容能不能被 AI 和搜索引擎推荐？

### 评分项目（每项 0-5 分）

| 项目 | 0 分 | 3 分 | 5 分 |
|---|---|---|---|
| 结构化内容 | 无结构 | 有基本结构 | FAQ Schema、HowTo 标记完整 |
| 开门见山结论 | 无 | 部分页面有 | 所有重要页面都有 TL;DR |
| 外部引用/专家背书 | 无 | 有 1-2 个 | 多个权威媒体/专家引用 |
| 图片 ALT 文字 | 无 | 部分有 | 所有图片都有描述性 ALT |
| 内部链接网络 | 无 | 有基本链接 | 内容集群（Content Cluster）完整 |

### 常见问题与建议

- **内容结构化不足** → 建议建立 FAQ 页面，加入 Schema 标记
- **缺少外部背书** → 建议争取产业媒体报道、KOL 开箱、专家推荐
- **图片无 ALT** → 建议格式：「产品名 - 品牌名 - 适用情境」

## 4. 广告投放准备度 Ads Readiness（第一年 25% / 第二年+ 15%）

**核心问题：** 你有没有准备好投放 Meta/Google 广告？

### 评分项目（每项 0-5 分）

| 项目 | 0 分 | 3 分 | 5 分 |
|---|---|---|---|
| Pixel/GA4 设定 | 未安装 | 已安装但未设定事件 | 完整设定+转换 API |
| 广告素材 | 仅产品图 | 有 2-3 种素材 | UGC+情境+教学+对比多种素材 |
| 受众设定 | 仅兴趣标签 | 有自订受众 | 多层受众+类似受众+再行销 |
| 预算与测试计划 | 无计划 | 有预算但无测试策略 | 有完整 A/B 测试计划 |
| 落地页一致性 | 广告与落地页不符 | 基本一致 | 高度一致+专属落地页 |

### 常见问题与建议

- **Pixel 未设定标准事件** → 建议设定 ViewContent、AddToCart、Purchase，并启用转换 API
- **缺少 UGC 素材** → 建议招募 10 位种子客户拍摄开箱/使用短影音
- **无再行销受众** → 建议建立网站访客 30 天、加购未结账 7 天、购买客户 180 天三组受众

## 5. 私域流量 Private Domain（第一年 10% / 第二年+ 20%）

**核心问题：** 你有没有建立可持续经营的客户关系？

### 评分项目（每项 0-5 分）

| 项目 | 0 分 | 3 分 | 5 分 |
|---|---|---|---|
| 私域平台覆盖 | 仅官网 | 有 1 个私域平台 | 覆盖 WhatsApp+LINE+Email |
| 会员制度 | 无 | 有基本会员 | 分级会员+专属优惠+生日礼 |
| 互动频率 | 无互动 | 每月 1-2 次 | 每周有价值内容+互动活动 |
| 回购引导 | 无 | 有基本回购提醒 | 包裹卡片+短信+私域专属优惠 |
| 用户生成内容 | 无 | 偶有 UGC | 系统性鼓励 UGC+有奖征件 |

### 常见问题与建议

- **仅有 LINE 但互动率低** → 建议推出会员分级，每月举办照片大赛或问答活动
- **无 WhatsApp** → 建议申请 WhatsApp Business API，尤其马来西亚市场
- **包裹无回购引导** → 建议加入「扫码加入私域领券」卡片

## 6. 行动计划 Action Plan（两个阶段皆 10%）

**核心问题：** 你知不知道自己接下来 30 天该做什么？

### 评分项目（每项 0-5 分）

| 项目 | 0 分 | 3 分 | 5 分 |
|---|---|---|---|
| 优先级清晰度 | 无计划 | 有想法但无优先级 | 清楚知道先做什么后做什么 |
| 资源盘点 | 不清楚 | 大概知道 | 清楚盘点人力/预算/时间 |
| 快速胜利项目 | 无 | 有 1 个 | 有 3 个以上 7 天内可完成项目 |
| 时程具体性 | 无排程 | 有大方向但无日期 | 30 天计划有逐周里程碑与检核点 |
| 风险意识 | 无 | 大概知道 | 清楚列出风险与备案 |

### 常见问题与建议

- **不知道先做什么** → 建议按「影响力 x 容易度」排序，先捡低垂果实
- **想一次做太多** → 建议 30 天内只聚焦 3 件事，其他先放着
- **没有预算概念** → 建议先从每日 300-500 元小预算测试开始

## 总分计算

- **第一年（初期）**：总分 = (品牌定位得分 x 15%) + (官网健康度得分 x 25%) + (SEO/AEO/GEO 得分 x 15%) + (广告投放得分 x 25%) + (私域流量得分 x 10%) + (行动计划得分 x 10%)
- **第二年+（品牌黏着期）**：总分 = (品牌定位得分 x 25%) + (官网健康度得分 x 15%) + (SEO/AEO/GEO 得分 x 15%) + (广告投放得分 x 15%) + (私域流量得分 x 20%) + (行动计划得分 x 10%)

每个维度满分 25 分（5 项 x 5 分），总分 100 分。
