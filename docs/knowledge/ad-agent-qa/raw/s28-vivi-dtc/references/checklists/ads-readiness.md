# 广告投放准备度检查清单

> 对应诊断框架维度 4（第一年权重 25% / 第二年+ 15%）。核心问题：你有没有准备好投放 Meta / Google 广告？
>
> 使用方法：逐项检查，符合记 1 分、部分符合记 0.5 分、不符合记 0 分。Pixel 与事件部分可用 Meta Pixel Helper 插件实测。

## 一、数据追踪基础

| 检查项目 | 检查方式 | 常见问题 | 建议工具 |
|---|---|---|---|
| Meta Pixel 已安装 | 用 Pixel Helper 插件检查 | 装了但 fire 不出来，或装了别人的 Pixel | Meta Pixel Helper |
| 标准事件已设定 | 实测触发各事件 | 只有 PageView，没有 ViewContent / AddToCart / Purchase | Pixel Helper + Events Manager |
| Purchase 事件含金额与币别 | 检查事件参数 | Purchase 事件没有 value 参数，ROAS 算不出来 | Events Manager 测试事件 |
| 转换 API（CAPI）已串接 | 检查 Events Manager 是否有伺服器事件 | iOS14 后只靠浏览器 Pixel，数据丢失 30-50% | Events Manager |
| 事件去重已处理 | 检查 browser + server 事件是否有 event_id | Pixel 和 CAPI 重复计算，数据虚高 | Events Manager |
| GA4 已安装且设定关键事件 | 检查 GA4 即时报表 | 装了 GA4 但没设任何转换事件 | GA4 DebugView |
| UTM 命名规范统一 | 抽查现有广告/社媒链接 | UTM 乱设或根本不设，事后无法归因 | GA4 流量报表 |

## 二、广告账户健康

| 检查项目 | 检查方式 | 常见问题 | 建议工具 |
|---|---|---|---|
| BM（商务管理平台）已验证 | 检查 BM 验证状态 | 用个人广告账户投，被封就全没了 | Meta Business Settings |
| 域名已验证 | 检查 BM 域名验证 | 未验证域名，iOS 转化事件设不了 | BM 品牌安全设置 |
| 广告账户无违规记录 | 检查账户品质 | 之前有违规被拒登，权重低 | 账户品质页面 |
| 已设定 8 个聚合事件优先级 | 检查 AEM 事件配置 | iOS 用户转化追踪不到 | Events Manager |
| 支付方式与额度正常 | 检查账单设置 | 额度太低跑不出量，或付款失败被停权 | 账单设置 |

## 三、素材准备

| 检查项目 | 检查方式 | 常见问题 | 建议工具 |
|---|---|---|---|
| 有 ≥ 5 组不同角度的素材 | 检查素材库 | 只有供应商给的产品白底图 | 素材库盘点 |
| 有 UGC（用户视角）素材 | 检查是否有真实用户拍摄内容 | 全是精修图，东南亚用户不吃这套 | IG / TikTok 素材 |
| 有视频素材（15-30 秒） | 检查视频素材数量 | 全是静态图，Reels/Stories 版位浪费 | 素材库盘点 |
| 视频 30 秒内讲完重点（12 秒也可以） | 抽查视频素材长度与信息密度 | 前 10 秒还在铺垫，完播率与 CTR 双低 | 视频素材抽查 |
| 素材类型多元：UGC（不一定有人脸）、Before & After | 盘点素材库类型 | 全是棚拍精修图；Before & After 通常是效果最好的类型，却没有（图可以用，要管的是文案：Meta 2026-07 起前后对比不再自动拒登，违规宣称才会被拒） | 素材库盘点 |
| 素材定期更新（每 2-4 周，或 CTR 下降 20% 即换） | 询问品牌方素材迭代节奏 + 看 CTR 趋势 | 一组素材跑三个月，受众疲劳 CTR 雪崩 | 广告报表 CTR 趋势 |
| IG / FB 文案格式差异：IG 没有标题栏，文案第一句话就是标题 | 抽查广告文案 | 把 FB 格式直接贴到 IG，第一句话是废话等于没有标题 | 素材文案检查 |
| 素材有当地语言版本 | 检查素材文案语言 | 广告文案简体中文直出，大马华人都不这样讲话 | 素材文案检查 |
| 不同尺寸适配（1:1 / 4:5 / 9:16） | 检查素材尺寸 | 只有横版图，手机版位显示超小 | 素材库盘点 |
| 素材有明确 Hook（前 3 秒） | 抽查视频素材前 3 秒 | 前 3 秒是 Logo 动画，用户直接滑走 | 视频素材抽查 |
| 竞品素材已调研 | 用 Meta Ad Library 看竞品在投什么 | 闭门造车，不知道竞品主打什么卖点 | Meta Ad Library |

## 四、受众与投放策略

| 检查项目 | 检查方式 | 常见问题 | 建议工具 |
|---|---|---|---|
| 有自订受众（网站访客/名单） | 检查受众管理器 | 完全没有自订受众，只能投兴趣标签 | Meta 受众管理器 |
| 有再行销受众分层 | 检查是否分层（30 天访客/7 天加购/180 天购买） | 所有访客塞同一组，无法再行销分层出价 | 受众管理器 |
| 有类似受众（Lookalike） | 检查是否建立 LAL | 种子客户太少建不了 LAL，说明先积累名单 | 受众管理器 |
| 兴趣受众已调研 | 检查兴趣标签是否与品类相关 | 乱选兴趣（卖宠物用品投「美妆」） | Meta Audience Insights |
| 有排除受众设定 | 检查是否排除已购买客户 | 一直对已购客户投新品广告，浪费预算 | 受众设定检查 |
| 受众与文案对应：不同受众讲不同文案和标题 | 抽查各广告组文案 | 冷受众、再行销受众、已购客户看到同一套文案标题，精准度全无 | 广告组抽查 |

## 五、预算与测试计划

| 检查项目 | 检查方式 | 常见问题 | 建议工具 |
|---|---|---|---|
| 有明确测试预算 | 询问品牌方预算规划 | 「先投看看」没有预算概念，一天烧完就停 | 访谈确认 |
| 日预算 ≥ 品类 CPM 要求 | 对比目标市场 CPM 基准 | 日预算 100 元想跑转化，数据量不够学习期 | 市场基准数据 |
| 有 A/B 测试计划 | 检查是否有测试框架 | 一次上 10 组广告没对照组，不知道哪个有效 | 测试计划文档 |
| 有明确的测试指标 | 检查是否定义成功标准 | 没有定义「多少 ROAS 算及格」，凭感觉加减预算 | 测试计划文档 |
| 有止损机制 | 检查是否设定停损规则 | 广告连烧两周亏钱还在跑 | 测试计划文档 |
| 开投前强制检查：Pixel / GA 已正确安装且事件通过 | 对照本清单「一、数据追踪基础」逐项确认 | 追踪没设好就烧预算，数据全废、无法优化 | Meta Pixel Helper、GA4 DebugView |

## 六、落地页一致性

| 检查项目 | 检查方式 | 常见问题 | 建议工具 |
|---|---|---|---|
| 广告承诺与落地页一致 | 抽查广告文案 vs 落地页 | 广告写「5 折」落地页找不到 5 折 | 广告+落地页对比 |
| 落地页载入速度合格 | 实测落地页速度 | 广告费花了，落地页 8 秒才开 | PageSpeed Insights |
| 落地页有明确 CTA | 检查首屏是否有购买按钮 | 落地页看完不知道要去哪里买 | 落地页截图 |
| 有专属活动落地页 | 检查大促是否有专属 LP | 所有广告都导流首页，转化率差 | 落地页盘点 |

## 评分换算

| 得分率 | 维度评分（0-5） |
|---|---|

| 10-29% | 1 |
| 10% 以下 | 0 |

## 快速诊断信号

- Pixel 没有 Purchase 事件 → 等于盲投，先修好再谈预算
- 素材全是供应商图 → 东南亚市场 CTR 通常 < 0.5%，必亏
- 素材超过 1 个月没换，或 CTR 掉了 20% 还在跑 → 受众疲劳，先换素材再谈加预算
- 没有 CAPI → iOS 转化数据丢失严重，ROAS 被低估
- 广告账户是个人账户 → 有封户风险，先建 BM
