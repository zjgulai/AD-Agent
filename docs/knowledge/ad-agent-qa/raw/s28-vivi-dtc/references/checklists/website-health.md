# 官网健康度检查清单

> 对应诊断框架维度 2（第一年权重 25% / 第二年+ 15%）。核心问题：你的官网能不能承接跨境流量和订单？
>
> 使用方法：逐项检查，符合记 1 分、部分符合记 0.5 分、不符合记 0 分，最后汇总换算为该维度的 0-5 分评分。可用 Browser/Playwright 实际跑一遍购物流程。

## 一、金流与支付

| 检查项目 | 检查方式 | 常见问题 | 建议工具 |
|---|---|---|---|
| 支持目标市场主流支付 | 实际下单走到支付页，看可选支付方式 | 只有 Visa/Mastercard，没有当地电子钱包 | Playwright 走完 checkout 流程 |
| 马来西亚：TnG / GrabPay / FPX | 检查支付列表 | 大马 60% 用户习惯 FPX 网银转账，没有就流失 | iPay88、2C2P |
| 新加坡：PayNow / GrabPay / Atome | 检查支付列表 | 缺少先买后付（BNPL），年轻客群转化率低 | Atome、Hoolah |
| 香港：FPS / AlipayHK / WeChat Pay HK | 检查支付列表 | 只支持信用卡，香港人习惯的 FPS 没有 | Stripe、PayDollar |
| 台湾：LINE Pay / 街口 / 超商取货付款 | 检查支付列表 | 没有货到付款（COD），新客不敢下单 | 绿界、蓝新 |
| 下单方式符合当地习惯（COD、PM 私讯下单） | 询问品牌方 + 实测下单流程 | 部分市场新客只敢 COD，或习惯 WhatsApp/LINE 私讯下单，官网没引导就流失这批客 | WhatsApp Business、LINE OA |
| 显示当地币别价格 | 切换 IP 或语言，检查价格币种 | 全站只显示 TWD，大马客户要自己心算汇率 | Shopify Markets、货币转换插件 |
| 价格含税与运费说明清楚 | 检查商品页是否标注税费/关税 | 结账才跳出关税，弃单率高 | 商品页文案检查 |

## 二、物流与履约

| 检查项目 | 检查方式 | 常见问题 | 建议工具 |
|---|---|---|---|
| 提供目标市场配送选项 | 下单流程检查配送方式 | 只写「国际快递 7-14 天」，没有具体选项 | 结账流程实测 |
| 运费计算器或免运门槛 | 检查购物车页是否有运费试算 | 运费要到结账最后一步才知道 | Easyship、ShipAny |
| 提供物流追踪 | 检查出货后是否有追踪号通知 | 客户下单后像石沉大海，客服被问爆 | 17Track 串接 |
| 配送时效承诺明确 | 检查官网是否写明各市场时效 | 完全不写时效，客户预期落空就给差评 | 物流政策页 |
| 退换货政策清楚 | 检查是否有 Return Policy 页 | 跨境退换货完全没写，客户不敢买 | 政策页检查 |
| 有当地仓或转运方案 | 询问品牌方履约方式 | 每单都走国际直邮，运费比商品还贵 | 了解是否用 Easyship/当地 3PL |

## 三、移动端体验

| 检查项目 | 检查方式 | 常见问题 | 建议工具 |
|---|---|---|---|
| 手机版首页正常显示 | 用手机或模拟器打开官网 | 桌面版硬缩放，字小到看不见 | Browser 移动端模拟 |
| 响应式设计（RWD），不需手动放大缩小 | 手机实测首页/商品页/结账页 | 客户要把网页拉大才看得到内容，多数人直接离开 | Browser 移动端模拟 |
| 商品图为 1:1 或 4:5 | 抽查商品列表页 | 横版图在手机上显示超小 | 页面截图 |
| 结账流程 ≤ 3 步 | 实测从加购到付款的点击次数 | 要填 15 个字段才能下单，弃单率 80% | Playwright 实测 |
| 支持访客结账 | 实测不注册能否下单 | 强制注册才能买，新客直接走人 | 结账流程实测 |
| 手机端按钮够大、可点 | 检查 CTA 按钮尺寸与间距 | 「立即购买」和「加入购物车」挤在一起误触 | 移动端截图检查 |
| 手机端无横向滚动 | 滑动各页面检查 | 表格超宽导致横滚，体验差 | 移动端模拟 |

## 四、速度与性能

| 检查项目 | 检查方式 | 常见问题 | 建议工具 |
|---|---|---|---|
| 首页载入 < 3 秒 | PageSpeed Insights 实测 | 首屏 8 秒才出来，广告费白烧 | Google PageSpeed Insights |
| 移动端性能分 ≥ 60 | PageSpeed 移动端评分 | 大量未压缩图片、第三方 JS 拖慢 | PageSpeed、GTmetrix |
| 图片已压缩且有 WebP | 检查图片格式与大小 | 一张 Banner 5MB 的 PNG 原图直出 | PageSpeed 报告 |
| 有 CDN 加速目标市场访问 | 从目标市场节点测速 | 主机在台湾，马来西亚访问 5 秒起跳 | Cloudflare、KeyCDN Tools |
| 无死链、无 404 | 爬一遍主要页面 | 分类页点进去 404，信任感崩塌 | Screaming Frog、Ahrefs |

## 五、信任要素

| 检查项目 | 检查方式 | 常见问题 | 建议工具 |
|---|---|---|---|
| 有 SSL（HTTPS） | 看网址列 | 还在用 HTTP，浏览器直接警告 | 浏览器检查 |
| 联络方式完整 | 检查是否有客服邮箱/电话/WhatsApp | 只有一个表单，客户有问题找不到人 | 联络页检查 |
| 公司信息透明 | 检查是否有公司名称、地址 | 完全匿名，像诈骗网站 | Footer、About 页 |
| 有客户评价模块 | 商品页是否有评价区 | 卖了两年官网零评价 | 商品页检查 |
| 支付安全标识 | 结账页是否显示安全认证图标 | 结账页光秃秃，客户输卡号时害怕 | 结账页截图 |
| 隐私权政策 | 检查是否有 Privacy Policy | 没有隐私政策，Meta 广告审核可能不过 | Footer 检查 |

## 六、内容与品牌呈现

| 检查项目 | 检查方式 | 常见问题 | 建议工具 |
|---|---|---|---|
| 图文分离：正文用 HTML 文字，不做在图片里 | 尝试圈选页面文字、用翻译软件测试 | 卖点全做在图片里，AI、搜索引擎和翻译软件都读不到，海外客户看不懂 | 浏览器圈选测试、Google 翻译 |
| 广告与落地页一致（投 A 商品，点进去就要看到 A 商品） | 抽查在投广告与落地页 | 广告投放 A 商品，落地页却是首页或 B 商品，转化率崩、还被判低质量落地页 | Meta Ad Library + 落地页对比 |
| 品牌摆设：官网像品牌提案企划，描述应用场景 | 看首页与商品页呈现方式 | 首页排满促销 banner，像电商平台一堆活动，品牌感全无只能拼低价 | 官网截图 |

## 评分换算

| 得分率 | 维度评分（0-5） |
|---|---|
| 90% 以上 | 5 |
| 70-89% | 4 |
| 50-69% | 3 |
| 30-49% | 2 |
| 10-29% | 1 |
| 10% 以下 | 0 |

## 快速诊断信号

- 结账要填超过 10 个字段 → 转化率头号杀手，优先修
- 没有当地支付方式 → 流量再多也收不到钱
- PageSpeed 移动端 < 30 分 → 先修速度再谈投广告
- 运费到结账才显示 → 弃单率通常 > 70%
- 广告投 A 商品、落地页却是首页 → 广告费直接打水漂，优先修
- 卖点全做在图片里 → 翻译软件读不到，等于自动放弃非中文客户
