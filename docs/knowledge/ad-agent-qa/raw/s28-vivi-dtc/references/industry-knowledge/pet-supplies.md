# 宠物用品 · 品类知识库

> 适用：诊断宠物食品、零食、用品、保健品品牌时使用。
> 核心判断：宠物赛道复购率高、客户终身价值（LTV）高，非常适合 DTC，但食品类有进口法规门槛。

## 一、品类特性

- **高复购、高 LTV**：主粮/零食/保健品是消耗品，客户一旦认可品牌，回购周期稳定（30-60 天）。做私域的价值极高。
- **「毛小孩」情感消费**：东南亚与台湾宠物人性化趋势明显，宠物被视为家人，愿意花溢价买「对毛孩好的」产品。情感营销比功能营销更有效。
- **猫经济崛起**：马来西亚、台湾城市化高，养猫比例快速上升（公寓养猫比养狗方便），猫用品增速 > 狗用品。
- **UGC 天然丰富**：宠物内容自带流量，客户愿意晒毛孩照片/视频，是最容易做 UGC 的品类。
- **决策者与使用者分离**：买单的是主人，用的是宠物。内容要同时打动主人（情感）和说服主人（成分/安全）。

## 二、跨境常见坑

| 坑 | 说明 | 解法 |
|---|---|---|
| 食品类进口法规 | 马来西亚宠物食品需 MAVS（兽医局）进口许可；含肉类成分可能被要求清真相关证明；台湾需防检局检疫 | 先确认产品成分是否含限制原料；考虑先从用品类切入，食品类走正规代理 |
| 清真敏感 | 马来西亚穆斯林养猫多，含猪成分的产品/生产线的宣传要非常小心 | 成分标示清楚， marketing 避开穆斯林敏感符号 |
| 重货物流成本 | 猫砂、主粮重量大，跨境直邮运费吃掉毛利 | 重货走海运备货当地仓，或选轻小高毛利品（零食、保健品、玩具）切入 |
| 信任门槛高 | 吃进肚子的东西，新品牌没有背书很难说服主人 | 先做 KOC 试吃、兽医师背书、成分检测报告公开 |
| 同质化严重 | 「天然」「无谷」「人用级」大家都在讲 | 找细分场景切入：老年犬关节、挑嘴猫、室内猫除臭 |

## 三、目标市场机会

| 市场 | 机会点 | 注意点 |
|---|---|---|
| 马来西亚 | 养猫比例高、中产增长快、宠物人性化刚开始，价格带仍有升级空间 | 需 MAVS 许可（食品）；华人+马来人双语言市场 |
| 新加坡 | 客单价高、消费者愿意买高端粮、Pet Expo 展会效应强 | 市场小、竞争密度高，进场成本高 |
| 香港 | 宠物渗透率高、猫经济成熟、消费者接受订阅制 | 租金高导致线下贵，DTC 电商接受度反而高 |
| 台湾 | 宠物数量 > 新生儿，市场成熟、复购稳定 | 本土品牌强（汪喵星球等），新品牌要有明确差异点 |

## 五、定价策略参考

- **价格带卡位**：不要打最低价（打不赢中国白牌），卡在「比超市粮贵 30-50%、比进口大牌便宜 20%」的中高端甜区。
- **首单钩子**：小包装试吃装（降低尝试门槛）+ 包邮，目标是拿名单和首购，不是赚钱。
- **订阅制**：主粮/猫砂适合订阅（每月定期配送 85-9 折），锁定 LTV。香港、新加坡接受度最高。
- **组合定价**：「主粮+零食+保健品」成长礼盒，拉客单价；按宠物年龄分（幼猫/成猫/老猫礼盒）。
- **跨境定价公式**：当地零售价 = (产品成本 + 头程物流 + 关税 + 平台/支付手续费) × 2.5-3.5 倍，再对照竞品价格带微调。
- **运费心理线**：马来西亚满 RM150 免运、新加坡满 S$60 免运是常见门槛，低于门槛的运费要显示在商品页而不是结账页。

## 六、该品类的诊断侧重

- 品牌定位：是否讲清楚「为哪类宠物、解决什么问题」（细分场景 > 泛泛天然）
- 广告素材：UGC 开箱/试吃反应视频是核心素材，没有就要先补
- 私域：该品类 LTV 高，私域权重可上调；重点查回购提醒和订阅机制
