# 廣告投放準備度檢查清單

> 對應診斷框架維度 4（第一年權重 25% / 第二年+ 15%）。核心問題：你有沒有準備好投放 Meta / Google 廣告？
>
> 使用方法：逐項檢查，符合記 1 分、部分符合記 0.5 分、不符合記 0 分。Pixel 與事件部分可用 Meta Pixel Helper 外掛實測。

## 一、資料追蹤基礎

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| Meta Pixel 已安裝 | 用 Pixel Helper 外掛檢查 | 裝了但 fire 不出來，或裝了別人的 Pixel | Meta Pixel Helper |
| 標準事件已設定 | 實測觸發各事件 | 只有 PageView，沒有 ViewContent / AddToCart / Purchase | Pixel Helper + Events Manager |
| Purchase 事件含金額與幣別 | 檢查事件引數 | Purchase 事件沒有 value 引數，ROAS 算不出來 | Events Manager 測試事件 |
| 轉換 API（CAPI）已串接 | 檢查 Events Manager 是否有伺服器事件 | iOS14 後只靠瀏覽器 Pixel，資料丟失 30-50% | Events Manager |
| 事件去重已處理 | 檢查 browser + server 事件是否有 event_id | Pixel 和 CAPI 重複計算，資料虛高 | Events Manager |
| GA4 已安裝且設定關鍵事件 | 檢查 GA4 即時報表 | 裝了 GA4 但沒設任何轉換事件 | GA4 DebugView |
| UTM 命名規範統一 | 抽查現有廣告/社媒連結 | UTM 亂設或根本不設，事後無法歸因 | GA4 流量報表 |

## 二、廣告賬戶健康

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| BM（商務管理平臺）已驗證 | 檢查 BM 驗證狀態 | 用個人廣告賬戶投，被封就全沒了 | Meta Business Settings |
| 域名已驗證 | 檢查 BM 域名驗證 | 未驗證域名，iOS 轉化事件設不了 | BM 品牌安全設定 |
| 廣告賬戶無違規記錄 | 檢查賬戶品質 | 之前有違規被拒登，權重低 | 賬戶品質頁面 |
| 已設定 8 個聚合事件優先順序 | 檢查 AEM 事件配置 | iOS 使用者轉化追蹤不到 | Events Manager |
| 支付方式與額度正常 | 檢查賬單設定 | 額度太低跑不出量，或付款失敗被停權 | 賬單設定 |

## 三、素材準備

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 有 ≥ 5 組不同角度的素材 | 檢查素材庫 | 只有供應商給的產品白底圖 | 素材庫盤點 |
| 有 UGC（使用者視角）素材 | 檢查是否有真實使用者拍攝內容 | 全是精修圖，東南亞使用者不吃這套 | IG / TikTok 素材 |
| 有影片素材（15-30 秒） | 檢查影片素材數量 | 全是靜態圖，Reels/Stories 版位浪費 | 素材庫盤點 |
| 影片 30 秒內講完重點（12 秒也可以） | 抽查影片素材長度與資訊密度 | 前 10 秒還在鋪墊，完播率與 CTR 雙低 | 影片素材抽查 |
| 素材型別多元：UGC（不一定有人臉）、Before & After | 盤點素材庫型別 | 全是棚拍精修圖；Before & After 通常是效果最好的型別，卻沒有（圖可以用，要管的是文案：Meta 2026-07 起前後對比不再自動拒登，違規宣稱才會被拒） | 素材庫盤點 |
| 素材定期更新（每 2-4 周，或 CTR 下降 20% 即換） | 詢問品牌方素材迭代節奏 + 看 CTR 趨勢 | 一組素材跑三個月，受眾疲勞 CTR 雪崩 | 廣告報表 CTR 趨勢 |
| IG / FB 文案格式差異：IG 沒有標題欄，文案第一句話就是標題 | 抽查廣告文案 | 把 FB 格式直接貼到 IG，第一句話是廢話等於沒有標題 | 素材文案檢查 |
| 素材有當地語言版本 | 檢查素材文案語言 | 廣告文案簡體中文直出，大馬華人都不這樣講話 | 素材文案檢查 |
| 不同尺寸適配（1:1 / 4:5 / 9:16） | 檢查素材尺寸 | 只有橫版圖，手機版位顯示超小 | 素材庫盤點 |
| 素材有明確 Hook（前 3 秒） | 抽查影片素材前 3 秒 | 前 3 秒是 Logo 動畫，使用者直接滑走 | 影片素材抽查 |
| 競品素材已調研 | 用 Meta Ad Library 看競品在投什麼 | 閉門造車，不知道競品主打什麼賣點 | Meta Ad Library |

## 四、受眾與投放策略

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 有自訂受眾（網站訪客/名單） | 檢查受眾管理器 | 完全沒有自訂受眾，只能投興趣標籤 | Meta 受眾管理器 |
| 有再行銷受眾分層 | 檢查是否分層（30 天訪客/7 天加購/180 天購買） | 所有訪客塞同一組，無法再行銷分層出價 | 受眾管理器 |
| 有類似受眾（Lookalike） | 檢查是否建立 LAL | 種子客戶太少建不了 LAL，說明先積累名單 | 受眾管理器 |
| 興趣受眾已調研 | 檢查興趣標籤是否與品類相關 | 亂選興趣（賣寵物用品投「美妝」） | Meta Audience Insights |
| 有排除受眾設定 | 檢查是否排除已購買客戶 | 一直對已購客戶投新品廣告，浪費預算 | 受眾設定檢查 |
| 受眾與文案對應：不同受眾講不同文案和標題 | 抽查各廣告組文案 | 冷受眾、再行銷受眾、已購客戶看到同一套文案標題，精準度全無 | 廣告組抽查 |

## 五、預算與測試計劃

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 有明確測試預算 | 詢問品牌方預算規劃 | 「先投看看」沒有預算概念，一天燒完就停 | 訪談確認 |
| 日預算 ≥ 品類 CPM 要求 | 對比目標市場 CPM 基準 | 日預算 100 元想跑轉化，資料量不夠學習期 | 市場基準資料 |
| 有 A/B 測試計劃 | 檢查是否有測試框架 | 一次上 10 組廣告沒對照組，不知道哪個有效 | 測試計劃文件 |
| 有明確的測試指標 | 檢查是否定義成功標準 | 沒有定義「多少 ROAS 算及格」，憑感覺加減預算 | 測試計劃文件 |
| 有止損機制 | 檢查是否設定停損規則 | 廣告連燒兩週虧錢還在跑 | 測試計劃文件 |
| 開投前強制檢查：Pixel / GA 已正確安裝且事件透過 | 對照本清單「一、資料追蹤基礎」逐項確認 | 追蹤沒設好就燒預算，資料全廢、無法最佳化 | Meta Pixel Helper、GA4 DebugView |

## 六、落地頁一致性

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 廣告承諾與落地頁一致 | 抽查廣告文案 vs 落地頁 | 廣告寫「5 折」落地頁找不到 5 折 | 廣告+落地頁對比 |
| 落地頁載入速度合格 | 實測落地頁速度 | 廣告費花了，落地頁 8 秒才開 | PageSpeed Insights |
| 落地頁有明確 CTA | 檢查首屏是否有購買按鈕 | 落地頁看完不知道要去哪裡買 | 落地頁截圖 |
| 有專屬活動落地頁 | 檢查大促是否有專屬 LP | 所有廣告都導流首頁，轉化率差 | 落地頁盤點 |

## 評分換算

| 得分率 | 維度評分（0-5） |
|---|---|
| 90% 以上 | 5 |

| 50-69% | 3 |

| 10-29% | 1 |
| 10% 以下 | 0 |

## 快速診斷訊號

- Pixel 沒有 Purchase 事件 → 等於盲投，先修好再談預算
- 素材全是供應商圖 → 東南亞市場 CTR 通常 < 0.5%，必虧
- 素材超過 1 個月沒換，或 CTR 掉了 20% 還在跑 → 受眾疲勞，先換素材再談加預算
- 沒有 CAPI → iOS 轉化資料丟失嚴重，ROAS 被低估
- 廣告賬戶是個人賬戶 → 有封戶風險，先建 BM
