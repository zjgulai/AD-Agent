# 官網健康度檢查清單

> 對應診斷框架維度 2（第一年權重 25% / 第二年+ 15%）。核心問題：你的官網能不能承接跨境流量和訂單？
>
> 使用方法：逐項檢查，符合記 1 分、部分符合記 0.5 分、不符合記 0 分，最後彙總換算為該維度的 0-5 分評分。可用 Browser/Playwright 實際跑一遍購物流程。

## 一、金流與支付

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 支援目標市場主流支付 | 實際下單走到支付頁，看可選支付方式 | 只有 Visa/Mastercard，沒有當地電子錢包 | Playwright 走完 checkout 流程 |
| 馬來西亞：TnG / GrabPay / FPX | 檢查支付列表 | 大馬 60% 使用者習慣 FPX 網銀轉賬，沒有就流失 | iPay88、2C2P |
| 新加坡：PayNow / GrabPay / Atome | 檢查支付列表 | 缺少先買後付（BNPL），年輕客群轉化率低 | Atome、Hoolah |
| 香港：FPS / AlipayHK / WeChat Pay HK | 檢查支付列表 | 只支援信用卡，香港人習慣的 FPS 沒有 | Stripe、PayDollar |
| 臺灣：LINE Pay / 街口 / 超商取貨付款 | 檢查支付列表 | 沒有貨到付款（COD），新客不敢下單 | 綠界、藍新 |
| 下單方式符合當地習慣（COD、PM 私訊下單） | 詢問品牌方 + 實測下單流程 | 部分市場新客只敢 COD，或習慣 WhatsApp/LINE 私訊下單，官網沒引導就流失這批客 | WhatsApp Business、LINE OA |
| 顯示當地幣別價格 | 切換 IP 或語言，檢查價格幣種 | 全站只顯示 TWD，大馬客戶要自己心算匯率 | Shopify Markets、貨幣轉換外掛 |
| 價格含稅與運費說明清楚 | 檢查商品頁是否標註稅費/關稅 | 結賬才跳出關稅，棄單率高 | 商品頁文案檢查 |

## 二、物流與履約

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 提供目標市場配送選項 | 下單流程檢查配送方式 | 只寫「國際快遞 7-14 天」，沒有具體選項 | 結賬流程實測 |
| 運費計算器或免運門檻 | 檢查購物車頁是否有運費試算 | 運費要到結賬最後一步才知道 | Easyship、ShipAny |
| 提供物流追蹤 | 檢查出貨後是否有追蹤號通知 | 客戶下單後像石沉大海，客服被問爆 | 17Track 串接 |
| 配送時效承諾明確 | 檢查官網是否寫明各市場時效 | 完全不寫時效，客戶預期落空就給差評 | 物流政策頁 |
| 退換貨政策清楚 | 檢查是否有 Return Policy 頁 | 跨境退換貨完全沒寫，客戶不敢買 | 政策頁檢查 |
| 有當地倉或轉運方案 | 詢問品牌方履約方式 | 每單都走國際直郵，運費比商品還貴 | 瞭解是否用 Easyship/當地 3PL |

## 三、移動端體驗

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 手機版首頁正常顯示 | 用手機或模擬器開啟官網 | 桌面版硬縮放，字小到看不見 | Browser 移動端模擬 |
| 響應式設計（RWD），不需手動放大縮小 | 手機實測首頁/商品頁/結賬頁 | 客戶要把網頁拉大才看得到內容，多數人直接離開 | Browser 移動端模擬 |
| 商品圖為 1:1 或 4:5 | 抽查商品列表頁 | 橫版圖在手機上顯示超小 | 頁面截圖 |
| 結賬流程 ≤ 3 步 | 實測從加購到付款的點選次數 | 要填 15 個欄位才能下單，棄單率 80% | Playwright 實測 |
| 支援訪客結賬 | 實測不註冊能否下單 | 強制註冊才能買，新客直接走人 | 結賬流程實測 |
| 手機端按鈕夠大、可點 | 檢查 CTA 按鈕尺寸與間距 | 「立即購買」和「加入購物車」擠在一起誤觸 | 移動端截圖檢查 |
| 手機端無橫向滾動 | 滑動各頁面檢查 | 表格超寬導致橫滾，體驗差 | 移動端模擬 |

## 四、速度與效能

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 首頁載入 < 3 秒 | PageSpeed Insights 實測 | 首屏 8 秒才出來，廣告費白燒 | Google PageSpeed Insights |
| 移動端效能分 ≥ 60 | PageSpeed 移動端評分 | 大量未壓縮圖片、第三方 JS 拖慢 | PageSpeed、GTmetrix |
| 圖片已壓縮且有 WebP | 檢查圖片格式與大小 | 一張 Banner 5MB 的 PNG 原圖直出 | PageSpeed 報告 |
| 有 CDN 加速目標市場訪問 | 從目標市場節點測速 | 主機在臺灣，馬來西亞訪問 5 秒起跳 | Cloudflare、KeyCDN Tools |
| 無死鏈、無 404 | 爬一遍主要頁面 | 分類頁點進去 404，信任感崩塌 | Screaming Frog、Ahrefs |

## 五、信任要素

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 有 SSL（HTTPS） | 看網址列 | 還在用 HTTP，瀏覽器直接警告 | 瀏覽器檢查 |
| 聯絡方式完整 | 檢查是否有客服郵箱/電話/WhatsApp | 只有一個表單，客戶有問題找不到人 | 聯絡頁檢查 |
| 公司資訊透明 | 檢查是否有公司名稱、地址 | 完全匿名，像詐騙網站 | Footer、About 頁 |
| 有客戶評價模組 | 商品頁是否有評價區 | 賣了兩年官網零評價 | 商品頁檢查 |
| 支付安全標識 | 結賬頁是否顯示安全認證圖示 | 結賬頁光禿禿，客戶輸卡號時害怕 | 結賬頁截圖 |
| 隱私權政策 | 檢查是否有 Privacy Policy | 沒有隱私政策，Meta 廣告稽核可能不過 | Footer 檢查 |

## 六、內容與品牌呈現

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 圖文分離：正文用 HTML 文字，不做在圖片裡 | 嘗試圈選頁面文字、用翻譯軟體測試 | 賣點全做在圖片裡，AI、搜尋引擎和翻譯軟體都讀不到，海外客戶看不懂 | 瀏覽器圈選測試、Google 翻譯 |
| 廣告與落地頁一致（投 A 商品，點進去就要看到 A 商品） | 抽查在投廣告與落地頁 | 廣告投放 A 商品，落地頁卻是首頁或 B 商品，轉化率崩、還被判低質量落地頁 | Meta Ad Library + 落地頁對比 |
| 品牌擺設：官網像品牌提案企劃，描述應用場景 | 看首頁與商品頁呈現方式 | 首頁排滿促銷 banner，像電商平臺一堆活動，品牌感全無只能拼低價 | 官網截圖 |

## 評分換算

| 得分率 | 維度評分（0-5） |
|---|---|
| 90% 以上 | 5 |
| 70-89% | 4 |
| 50-69% | 3 |
| 30-49% | 2 |
| 10-29% | 1 |
| 10% 以下 | 0 |

## 快速診斷訊號

- 結賬要填超過 10 個欄位 → 轉化率頭號殺手，優先修
- 沒有當地支付方式 → 流量再多也收不到錢
- PageSpeed 移動端 < 30 分 → 先修速度再談投廣告
- 運費到結賬才顯示 → 棄單率通常 > 70%
- 廣告投 A 商品、落地頁卻是首頁 → 廣告費直接打水漂，優先修
- 賣點全做在圖片裡 → 翻譯軟體讀不到，等於自動放棄非中文客戶
