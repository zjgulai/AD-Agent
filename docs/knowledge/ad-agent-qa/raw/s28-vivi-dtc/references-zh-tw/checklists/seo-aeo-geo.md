# SEO / AEO / GEO 檢查清單

> 對應診斷框架維度 3（權重 15%）。核心問題：你的內容能不能被 AI 和搜尋引擎推薦？
>
> 三個層次：
> - **SEO**：讓 Google 搜得到你
> - **AEO**（Answer Engine Optimization）：讓 AI 直接引用你當答案
> - **GEO**（Generative Engine Optimization）：讓 ChatGPT / Gemini / Perplexity 在生成回答時推薦你

## 一、技術 SEO 基礎

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 網站已被 Google 收錄 | 搜尋 `site:品牌域名` | 上線半年收錄 0 頁，Sitemap 沒提交 | Google Search Console |
| Sitemap 已提交 | 檢查 GSC Sitemap 狀態 | 沒有 sitemap.xml，或提交了全是錯誤 | GSC |
| 每頁有唯一 Title / Description | 抽查 10 個頁面的 meta 標籤 | 全站 Title 都是品牌名，或空白 | Screaming Frog、Ahrefs |
| URL 結構語義化 | 抽查商品頁與文章頁 URL | URL 是 `/product?id=12345`，看不出內容 | 網站抽查 |
| HTTPS + 無 mixed content | 瀏覽器檢查 | 部分圖片走 HTTP 導致安全警告 | 瀏覽器開發者工具 |
| robots.txt 未誤擋搜尋引擎 | 檢查 robots.txt | `Disallow: /` 把全站擋掉 | 直接訪問 /robots.txt |
| 多語言版本有 hreflang | 檢查多語言站的 hreflang 標籤 | 中英文版本互相搶排名 | Ahrefs、GSC |

## 二、內容結構（SEO 層）

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 有品牌部落格或內容專區 | 檢查官網是否有 Blog / 攻略區 | 只有商品頁，沒有任何內容 | 網站導航檢查 |
| 內容圍繞品類關鍵詞佈局 | 用關鍵詞工具查品牌內容覆蓋的詞 | 文章自嗨，沒人搜那些主題 | Ahrefs、Ubersuggest |
| 標題含目標關鍵詞 | 抽查文章標題 | 標題文藝但沒有搜尋量（如「生活的儀式感」） | 關鍵詞工具驗證 |
| 內容有內部連結網路 | 檢查文章是否互相連結 | 每篇文章都是孤島 | Screaming Frog |
| 內容叢集（Content Cluster） | 檢查是否有支柱頁+子主題結構 | 東寫一篇西寫一篇，沒有主題縱深 | Ahrefs Content Gap |
| 圖片有描述性 ALT | 抽查 20 張圖的 ALT 屬性 | ALT 全是「IMG_1234」或空白 | 瀏覽器檢查元素 |

## 三、AEO（答案引擎最佳化）

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 重要頁面有 TL;DR / 結論先行 | 抽查文章開頭 | 開頭 500 字才進入正題，AI 抓不到重點 | 頁面抽查 |
| 有 FAQ 頁面或區塊 | 檢查官網 FAQ | 完全沒有 FAQ，或 FAQ 藏在頁尾 | 官網檢查 |
| FAQ 使用 Schema 標記 | 檢查原始碼是否有 FAQPage schema | 有 FAQ 內容但沒標 schema，AI 讀不到結構化資料 | Google Rich Results Test |
| 問題用消費者的真實問法 | 對比 FAQ 問題與真實搜尋詞 | FAQ 寫的是官方話術（「請問貴司產品優勢」） | AnswerThePublic、Google 相關搜尋 |
| 答案簡潔直接（40-60 字給結論） | 抽查 FAQ 答案長度 | 答案繞來繞去不給結論 | 內容抽查 |
| HowTo 內容有步驟標記 | 檢查教學類內容 | 教學文是一大段文字，沒有步驟結構 | Rich Results Test |

## 四、GEO（生成式引擎最佳化）

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 品牌名+品類在 ChatGPT 能搜到 | 實際問 ChatGPT：「推薦 XX 品類的品牌」 | AI 完全不認識這個品牌 | ChatGPT / Gemini / Perplexity 實測 |
| 有權威媒體/平臺提及 | Google 搜尋品牌名看第三方結果 | 除了官網什麼都沒有，AI 沒有引用來源 | Google 搜尋品牌名 |
| 維基/百科類條目存在 | 搜尋品牌是否有百科條目 | 小公司建不了維基，但至少要有 Crunchbase/媒體報道 | Google 搜尋 |
| 資料與事實可被引用 | 內容是否含具體資料、研究、統計 | 全是形容詞沒有事實，AI 無法引用 | 內容抽查 |
| 專家署名與資歷 | 內容是否有作者與專業背景 | 文章署名「admin」，AI 判定可信度低 | 內容頁檢查 |
| 內容被外部網站引用/轉載 | 搜尋品牌內容是否被引用 | 零外部引用，GEO 權重低 | Ahrefs Backlink 檢查 |
| 評測/對比類內容存在 | 搜尋「品牌名 評價」「品牌 vs 競品」 | 沒有任何第三方評測內容 | Google 搜尋 |

## 五、在地化搜尋

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 有當地語言內容 | 檢查是否有馬來文/英文/粵語內容 | 馬來西亞站只有中文，丟掉 70% 搜尋量 | 網站語言版本檢查 |
| Google Business Profile 已建立 | 搜尋品牌名看是否有商家資料 | 有實體店/辦公室卻沒建 GBP | Google Maps 搜尋 |
| 當地關鍵詞有排名 | 用當地語言關鍵詞搜尋 | 品牌詞搜得到，品類詞完全沒排名 | Ahrefs 切換地區查排名 |
| 當地目錄/黃頁已收錄 | 檢查當地商業目錄 | 當地消費者常用的平臺找不到你 | 當地目錄網站搜尋 |

## 六、內容品質與轉化

| 檢查專案 | 檢查方式 | 常見問題 | 建議工具 |
|---|---|---|---|
| 內容新鮮度：每 3-6 個月更新一次 | 抽查文章釋出與更新日期 | 文章都是兩年前的，搜尋引擎判定為過期內容，排名下滑 | 頁面日期抽查 |
| 頁面標註最後更新日期 | 檢查文章頁是否顯示 updated date | 有更新但頁面沒標，搜尋引擎不知道內容還是新的 | 頁面抽查、Schema dateModified |
| 作者介紹：名稱、職稱、專業背景 | 檢查內容頁作者欄 | 署名「admin」，E-E-A-T 可信度低，AI 不引用 | 內容頁檢查 |
| 多媒體內容：影片、圖表、資訊圖表 | 抽查 10 篇內容 | 純文字牆，停留時間短，AI 摘要也缺少可引用素材 | 內容抽查 |
| 每篇內容有明確 CTA | 抽查文章結尾 | 看完沒有下一步（立即購買/瞭解更多/免費下載），流量白白流走 | 內容抽查 |
| 語義相關性：佈局問題型關鍵詞 | 檢查內容是否覆蓋「如何」「什麼是」「為什麼」類查詢 | 只做產品詞，問題型搜尋流量全讓給競品 | AnswerThePublic、Google 相關搜尋 |
| 長尾關鍵詞佈局 | 檢查是否有長尾內容（如「染燙後如何護色」） | 只搶大詞搶不過頭部，長尾詞才是新品牌的流量入口 | Ahrefs、Ubersuggest |

## 快速診斷訊號

- `site:域名` 收錄 < 20 頁 → 內容量嚴重不足
- 問 ChatGPT「推薦 XX 品牌」完全沒提到 → GEO 從零開始，但也代表競品可能也沒做，是機會
- FAQ 沒有 schema → 花 1 小時加上，是價效比最高的 AEO 快贏
- 全站只有商品頁沒有內容頁 → 自然流量天花板極低，只能靠廣告
