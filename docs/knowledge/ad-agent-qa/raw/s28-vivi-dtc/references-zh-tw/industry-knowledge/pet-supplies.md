# 寵物用品 · 品類知識庫

> 適用：診斷寵物食品、零食、用品、保健品品牌時使用。
> 核心判斷：寵物賽道復購率高、客戶終身價值（LTV）高，非常適合 DTC，但食品類有進口法規門檻。

## 一、品類特性

- **高復購、高 LTV**：主糧/零食/保健品是消耗品，客戶一旦認可品牌，回購週期穩定（30-60 天）。做私域的價值極高。
- **「毛小孩」情感消費**：東南亞與臺灣寵物人性化趨勢明顯，寵物被視為家人，願意花溢價買「對毛孩好的」產品。情感營銷比功能營銷更有效。
- **貓經濟崛起**：馬來西亞、臺灣城市化高，養貓比例快速上升（公寓養貓比養狗方便），貓用品增速 > 狗用品。
- **UGC 天然豐富**：寵物內容自帶流量，客戶願意曬毛孩照片/影片，是最容易做 UGC 的品類。
- **決策者與使用者分離**：買單的是主人，用的是寵物。內容要同時打動主人（情感）和說服主人（成分/安全）。

## 二、跨境常見坑

| 坑 | 說明 | 解法 |
|---|---|---|
| 食品類進口法規 | 馬來西亞寵物食品需 MAVS（獸醫局）進口許可；含肉類成分可能被要求清真相關證明；臺灣需防檢局檢疫 | 先確認產品成分是否含限制原料；考慮先從用品類切入，食品類走正規代理 |
| 清真敏感 | 馬來西亞穆斯林養貓多，含豬成分的產品/生產線的宣傳要非常小心 | 成分標示清楚， marketing 避開穆斯林敏感符號 |
| 重貨物流成本 | 貓砂、主糧重量大，跨境直郵運費吃掉毛利 | 重貨走海運備貨當地倉，或選輕小高毛利品（零食、保健品、玩具）切入 |
| 信任門檻高 | 吃進肚子的東西，新品牌沒有背書很難說服主人 | 先做 KOC 試吃、獸醫師背書、成分檢測報告公開 |
| 同質化嚴重 | 「天然」「無谷」「人用級」大家都在講 | 找細分場景切入：老年犬關節、挑嘴貓、室內貓除臭 |

## 三、目標市場機會

| 市場 | 機會點 | 注意點 |
|---|---|---|
| 馬來西亞 | 養貓比例高、中產增長快、寵物人性化剛開始，價格帶仍有升級空間 | 需 MAVS 許可（食品）；華人+馬來人雙語言市場 |
| 新加坡 | 客單價高、消費者願意買高階糧、Pet Expo 展會效應強 | 市場小、競爭密度高，進場成本高 |
| 香港 | 寵物滲透率高、貓經濟成熟、消費者接受訂閱制 | 租金高導致線下貴，DTC 電商接受度反而高 |
| 臺灣 | 寵物數量 > 新生兒，市場成熟、復購穩定 | 本土品牌強（汪喵星球等），新品牌要有明確差異點 |

## 五、定價策略參考

- **價格帶卡位**：不要打最低價（打不贏中國白牌），卡在「比超市糧貴 30-50%、比進口大牌便宜 20%」的中高階甜區。
- **首單鉤子**：小包裝試吃裝（降低嘗試門檻）+ 包郵，目標是拿名單和首購，不是賺錢。
- **訂閱制**：主糧/貓砂適合訂閱（每月定期配送 85-9 折），鎖定 LTV。香港、新加坡接受度最高。
- **組合定價**：「主糧+零食+保健品」成長禮盒，拉客單價；按寵物年齡分（幼貓/成貓/老貓禮盒）。
- **跨境定價公式**：當地零售價 = (產品成本 + 頭程物流 + 關稅 + 平臺/支付手續費) × 2.5-3.5 倍，再對照競品價格帶微調。
- **運費心理線**：馬來西亞滿 RM150 免運、新加坡滿 S$60 免運是常見門檻，低於門檻的運費要顯示在商品頁而不是結賬頁。

## 六、該品類的診斷側重

- 品牌定位：是否講清楚「為哪類寵物、解決什麼問題」（細分場景 > 泛泛天然）
- 廣告素材：UGC 開箱/試吃反應影片是核心素材，沒有就要先補
- 私域：該品類 LTV 高，私域權重可上調；重點查回購提醒和訂閱機制
