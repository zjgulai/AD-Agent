# 新加坡 · 市場知識庫

> 核心判斷：新加坡市場小但客單價高、消費者購買力強、對品質和品牌要求高。適合「高毛利、有故事」的品牌，不適合低價走量打法。

## 一、市場概況

- 人口約 600 萬，人均 GDP 東南亞最高，消費力對標發達國家。
- 電商成熟：Shopee 第一、Lazada 第二、Amazon.sg 與 TikTok Shop 分食。
- 消費者決策理性：會比價、看成分、看評價，「便宜」不是最強賣點，「值得」才是。
- 多元種族：華人 ~74%、馬來人 ~13%、印度人 ~9%，英文是主要商業語言。
- 市場小的含義：受眾池小，廣告容易快速觸及上限，素材疲勞快，要頻換素材。
- 廣告 CPM 參考：Meta 新加坡 CPM 約 S$15-35，區域最貴之一，轉化質量也最高。

## 六、法規與合規

> 新加坡對化妝品採「通報制、事後監管」，上市快但罰則重。法規會變動，重大投入前請當地法規顧問確認最新要求。

| 檢查項 | 內容 |
|---|---|
| 事前註冊/備案 | **要**。制度叫「化妝品通報」（Cosmetic Product Notification），經 HSA 的 PRISM 線上系統提交；HSA 不審查、確認函不代表官方背書。費用：一般化妝品每單品 S$13，眼周/唇部/口腔產品或含二胺類染髮劑 S$28，第 4 個起變體各 S$8。通報效期 1 年，繼續銷售須每年再通報 |
| 時程 | **近乎即時**：確認函由系統自動生成，收到即可開始銷售；官方未公佈工作日承諾（檔案準備時間另計） |
| 當地主體/境內責任人 | **要**。須由 ACRA 註冊的新加坡公司擔任「Person Responsible（責任人）」；外國公司不能直接通報，必須委託當地實體（可授權第三方服務商代操作）。標籤須標該公司在新加坡的名稱與地址 |
| 檢驗報告 | 上市前不強制提交；但須依 ASEAN 規範備妥 **PIF（產品資訊檔案）**（含安全評估員簽署的安全評估報告）供 HSA 調閱。汙染物限值：汞 ≤1 ppm、鉛 ≤20 ppm、砷 ≤5 ppm、鎘 ≤5 ppm、1,4-二惡烷 ≤10 ppm |
| 標籤語言 | **英文必須**（可加其他語言但內容須與英文一致）；成分表 INCI 命名、按含量降序 |
| 廣告宣稱紅線 | 任何治療/預防疾病、改變生理機能的宣稱均禁止（ASEAN 宣稱指南＋新加坡 SCAP 廣告守則）。罰則：未通報即銷售最高 S$20,000 罰款及/或 12 個月監禁；含違禁成分最高 S$100,000 及/或 3 年監禁 |
| 分類升級陷阱 | 以治療為目的（祛痘治療霜、溼疹、抗真菌藥膏）、區域性抗菌消毒類、含藥油膏 → 落入**治療性產品（Therapeutic Products）須註冊**，官方審評 60-270 個工作日（約 3 個月到 1 年以上），與即時通報天壤之別 |

**分類升級陷阱示例：** 同一瓶抗菌洗手液，寫「清潔雙手、清新體感」是化妝品（通報即賣）；寫「殺滅 99.9% 病菌、預防感染」就可能被歸治療性產品——從即時變成數月起。拿不準分類可向 HSA 提交官方分類判定申請。

## 七、廣告投放注意事項

- **英文為主、中文為輔**：主力受眾用英文素材，中文素材針對華人細分可加分。
- **素材質感要求高**：新加坡消費者對粗糙素材容忍度低，精修圖 + 原生 UGC 混合效果最佳。
- **受眾池小**：類似受眾（LAL）容易快速耗盡，建議用「廣泛受眾 + 好素材」讓系統自己找人。
- **重內容質量**：新加坡使用者教育程度高，成分黨、研究型消費者多，廣告落地頁的「證據鏈」（成分、資料、評價）要做足。
- **合規嚴格**：健康/美妝功效宣稱受 HSA 規範，減肥、醫療宣稱是 Meta + 當地法規雙重紅線。
- **預算參考**：冷啟動每日 S$50-100/組，CPM 高但轉化價值也高，重點看 ROAS 不是 CTR。

## 八、文化禁忌與消費習慣

- **規則意識強**：退換貨政策、配送時效、成分標示都要寫得清清楚楚，模糊會被投訴。
- **投訴文化**：新加坡消費者遇到問題會直接留差評或投訴 CASE（消費者協會），客服響應要快。
- **促銷節點**：Great Singapore Sale（6-7 月）、雙數大促、黑色星期五都有人跟，但折扣深度不用像大馬那麼誇張。
- **品質敏感 > 價格敏感**：「Cheap」在新加坡甚至是負面詞，文案用「value」「worth it」而非「cheapest」。
- **多元種族敏感**：素材注意種族平衡，別隻出現單一種族；宗教議題（清真、印度教）保持中性。
- **送禮文化**：企業送禮、節慶禮盒（聖誕、新年）客單價高，B2B 禮盒是值得開發的線。
