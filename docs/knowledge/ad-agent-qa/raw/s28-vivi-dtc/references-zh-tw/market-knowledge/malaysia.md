# 馬來西亞 · 市場知識庫

> 核心判斷：馬來西亞是東南亞 DTC 出海的首選試水市場——華人客群是天然切入點，電商基建成熟，廣告成本低於新加坡，但要做大必須跨出華人圈。

## 一、市場概況

- 人口約 3,400 萬：馬來人 ~60%、華人 ~23%、印度人 ~7%。
- 電商滲透率高，Shopee 是絕對龍頭，Lazada 第二，TikTok Shop 增速最快。
- 華人客群中高收入、網購習慣成熟、中文內容可直接觸達——是新品牌冷啟動的第一站。
- 馬來客群是大盤：要放量必須跨出華人圈，這意味著 Halal 認證、馬來文內容、馬來 KOL。
- 消費力分層明顯：吉隆坡/雪蘭莪消費力最高，東馬物流成本高。
- 廣告 CPM 參考：Meta 大馬 CPM 約 RM8-20，是區域裡價效比最高的市場之一。

## 六、法規與合規

> 美妝品類進馬來西亞的第一道門檻。法規會變動，重大投入前請當地法規顧問確認最新要求。

| 檢查項 | 內容 |
|---|---|
| 事前註冊/備案 | **要**。制度叫「化妝品通報」（Cosmetic Notification），依《1984 年藥品與化妝品管制條例》（CDCR 1984），未通報不得製造、銷售或進口。經 NPRA 的 QUEST3+ 線上系統提交，每個產品（含變體）規費 RM50，取得 NOT 編號，有效期 2 年、到期前需續展 |
| 時程 | 通報制非審批制：完成填表付款並透過合規篩查後即可自行生成通報單上市。官方未承諾天數；含檔案準備的業界經驗值約 3-4 周（經驗值，非官方承諾） |
| 當地主體/境內責任人 | **要**。Cosmetic Notification Holder（CNH）必須是馬來西亞註冊公司（SSM 登記）；品牌可委託當地第三方並出具授權書（LoA）。標籤必須標示 CNH 名稱與地址 |
| 檢驗報告 | 通報時不強制提交；但須完成安全評估並建立 **PIF（產品資訊檔案）**備查，NPRA 稽查隨時可調閱。上市後抽驗限值：汞 ≤1 ppm、鉛 ≤20 ppm、砷 ≤5 ppm、鎘 ≤5 ppm，微生物依 ASEAN 標準 |
| 標籤語言 | **馬來文（Bahasa Malaysia）和/或英文**；成分表用 INCI 命名、按含量降序。牛/豬來源成分須宣告動物來源 |
| 廣告宣稱紅線 | 不得醫療宣稱：治療/預防疾病、治痘、生髮、減肥瘦身、影響生理機能（Annex I Part 8 宣稱指引）；廣告另禁醫護人員形象背書、提及醫院、與競品比較、不實前後對比（Part 10 廣告指引） |
| 分類升級陷阱 | 宣稱越界（被當成可治療疾病）或含毒藥清單／ACD 禁用成分 → 落入**藥品管理**（須向 DCA 註冊、取得 MAL 編號），官方審評約 100-245 個工作天起（約 5-12 個月），且需先取得進口/批發執照 |

**分類升級陷阱示例：** 同一支去屑洗髮精，寫「減少頭屑外觀」是化妝品（通報即可上市）；寫「永久消除頭皮屑」就可能被判定藥品——從幾天變成半年起跳。

## 七、廣告投放注意事項

- **語言分層**：華人受眾投中文+英文，馬來受眾投馬來文，不要用同一組素材通投。
- **素材在地化**：全用歐美臉模特效果差；華人素材用華人面孔，馬來素材用戴頭巾的馬來模特。
- **節慶檔期**：開齋月（Ramadan）白天流量低但夜間暴漲；開齋節（Hari Raya）前 2-3 周是全年最大促銷檔之一，別隻盯農曆新年。
- **Meta 稽核**：美妝功效、減肥、健康宣稱稽核嚴格，被拒登常見，素材要走生活方式路線。
- **TikTok 素材**：大馬 TikTok 使用者對「硬廣」耐受度低，原生感、劇情式、開箱式素材 CTR 明顯更好。
- **預算參考**：冷啟動測試建議每日 RM100-200/組廣告，跑 5-7 天看資料。

## 八、文化禁忌與消費習慣

- **清真敏感**：豬肉、酒精相關的產品/圖片/用語避開穆斯林客群；Halal 認證是攻馬來大盤的門票。
- **顏色與符號**：綠色本身是伊斯蘭代表色但不是禁忌，重點是不宜在宗教語境下濫用宗教符號。
- **左手禁忌**：遞東西/吃飯用右手（馬來文化），素材細節要注意。
- **比價習慣重**：大馬消費者會在 Shopee 比價，官網獨立站要給出「為什麼不在 Shopee 買」的理由（會員價、贈品、獨家組合）。
- **促銷敏感**：雙數大促（9.9/10.10/11.11/12.12）+ 發薪日（每月 25 日-次月 5 日）是消費高峰，廣告預算要跟著走。
- **語言細節**：大馬中文有自己的詞彙（如「羅裡」=卡車），完全照臺灣/大陸用語會有距離感，但一般書面中文可通用。
