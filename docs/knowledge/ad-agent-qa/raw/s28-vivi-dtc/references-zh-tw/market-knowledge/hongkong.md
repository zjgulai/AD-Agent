# 香港 · 市場知識庫

> 核心判斷：香港市場小而精，消費者高度成熟、重效率、重性價比，對台灣品牌有天然好感。電商滲透率在成熟市場中偏低（習慣線下），但疫情後網購習慣已建立，DTC 品牌有機會。

## 一、市場概況

- 人口約 750 萬，人均 GDP 高，消費力成熟。
- 線下零售極強（便利店、藥妝店密度高），電商滲透率低於台灣，但 HKTVmall、淘寶、拼多多跨境正在改變習慣。
- 台灣品牌心智好：香港人對台灣食品、美妝、文創有「品質+文青」的正面聯想。
- 語言：粵語為主，書面用繁體中文（港式用詞），英文通用。
- 租金貴導致線下鋪貨成本高，反而給了 DTC 純電商品牌空間。
- 廣告 CPM 參考：Meta 香港 CPM 約 HK$60-120，與台灣接近或略高。

## 五、法規與合規

> 香港對化妝品採「上市後監管」，門檻遠低於大陸，但宣稱紅線要守住。法規會變動，重大投入前請當地法規顧問確認最新要求。

| 檢查項 | 內容 |
|---|---|
| 事前註冊/備案 | **一般化妝品不需要**事前註冊或備案，可直接上市；但含藥性成分或宣稱療效的產品會被歸為「藥劑製品」，須向藥劑業及毒藥管理局註冊 |
| 時程 | 一般化妝品無審批時程，可即上市；藥劑製品註冊以月計 |
| 當地主體/境內責任人 | 無強制境內責任人；進口商/經銷商須承擔《消費品安全條例》與《商品説明條例》下的責任 |
| 檢驗報告 | 非強制；建議備妥安全評估與重金屬/微生物檢驗，以應對海關與消委會抽查 |
| 標籤語言 | 中英文雙語（安全警告與使用説明須中英並列）；成分表建議用 INCI |
| 廣告宣稱紅線 | 《不良廣告（醫藥）條例》：不可宣稱治療或預防疾病（如「治療暗瘡」「生髮」屬醫藥宣稱）；《商品説明條例》禁虛假、誤導性聲稱 |
| 分類升級陷阱 | 宣稱「藥用」「治療」「醫學級」或加入受管制成分，產品會落入藥劑製品管理，須註冊、時程以月計，等於從「即上市」變「數月起」 |

## 六、廣告投放注意事項

- **粵語文案**：廣告文案用書面粵語（「而家」「咁」「啲」）點擊率明顯高於普通話書面語；落地頁可用標準繁體，但廣告要夠「港」。
- **台灣品牌故事**：「台灣製造」「台灣直送」本身是賣點，要放在素材前 3 秒。
- **比價精明**：香港消費者會在 HKTVmall、淘寶比價，獨立站要給獨家組合或會員價。
- **KOC 開箱**：香港 YouTube/IG 開箱文化強，中尾部 KOC（5k-50k 粉）合作性價比高。
- **預算參考**：冷啓動每日 HK$300-500/組，受眾池小，注意素材疲勞（同素材 2-3 周要換）。
- **Meta 政策**：與台灣類似，健康美妝宣稱要收斂。

## 七、文化禁忌與消費習慣

- **效率至上**：網頁慢 1 秒、結賬多一步都直接走人；客服響應以「小時」計不是「天」。
- ** pragmatism 務實**：不買情懷賬，「性價比」「功能」「快」比品牌故事更能打動，但台灣品牌故事是例外（有加分）。
- **差評文化直接**：不滿意會在 LIHKG、FB 羣組公開吐槽，危機處理要快且誠懇。
- **諧音與數字**：「4」不吉利、「8」吉利；禮盒定價可參考 HK$168、HK$228 這類吉利數字。
- **節慶**：農曆新年、中秋、聖誕是禮盒高峯；母親節/父親節家庭消費強。
- **政治中立**：品牌避免觸碰政治議題，保持中立最安全。
- **港式用詞**：「質素」（品質）、「優惠」（折扣）、「速遞」（快遞），文案用詞要港式，別出現「質量」「快遞」「視頻」這類內地/台灣用詞。
