# 中國大陸 · 市場知識庫

> 核心判斷：大陸是體量最大、但門檻也最高的市場。跨境電商路徑（9610/1210）可以免註冊備案先跑起來，但做不了線下鋪貨；要走一般貿易落地，必須先過法規註冊這一關。先想清楚「跨境電商試水」還是「一般貿易落地」，兩條路的時程與成本完全不同。

## 一、市場概況

- 人口約 14 億，電商滲透率全球最高之一，移動支付與物流基建成熟。
- 平臺生態與海外完全不同：天貓國際、京東國際、抖音電商、拼多多是主渠道；沒有 Meta/Google/Shopee。
- 客群特徵：一二線城市成分黨、精緻媽媽、功效黨成熟；下沉市場價格敏感度極高。
- 消費力分層：一二線願為品牌與成分付溢價；三四線及以下看價效比與直播議價。
- 臺灣品牌心智：「臺灣製造」在美妝保養、食品品類有品質聯想，但國貨品牌崛起快，不能只靠產地光環。
- 廣告成本參考：抖音/小紅書投放成本逐年上升，美妝類目競爭激烈，KOC 種草仍是價效比最高的冷啟動方式。

## 五、物流選項

| 方案 | 時效 | 說明 |
|---|---|---|

## 六、法規與合規

> 美妝品類進大陸的第一道硬門檻。法規會變動，重大投入前請當地法規顧問確認最新要求。

| 檢查項 | 內容 |
|---|---|
| 事前註冊/備案 | 一般貿易進口化妝品：**特殊化妝品要註冊，普通化妝品要備案**。跨境電商 9610/1210 路徑可免註冊備案 |
| 時程 | 特殊化妝品註冊 **12-16 個月**；普通化妝品備案 **4-6 個月** |
| 當地主體/境內責任人 | 一般貿易必須指定**境內責任人（RP）**；跨境電商路徑由平臺/境內服務商承擔對應責任 |
| 檢驗報告 | 註冊/備案需提交檢驗報告（微生物、重金屬、毒理等）；跨境路徑雖免註冊，平臺仍會抽檢 |
| 標籤語言 | 一般貿易：簡體中文標籤必標（成分表、備案/註冊編號、境內責任人資訊）；跨境電商商品可不貼中文標籤，但銷售頁面須有中文說明 |
| 廣告宣稱紅線 | 《廣告法》極限詞（「最」「第一」「國家級」）禁用；化妝品不可宣稱醫療作用（治療、消炎、生髮等）；美白、防曬屬特殊化妝品宣稱，註冊下來之前不能講 |
| 分類升級陷阱 | 見下方「文案決定分類」 |

**分類升級陷阱（文案決定分類）：** 同一支洗髮精，寫「護色／減少褪色」是普通化妝品（備案 4-6 個月）；寫成「補色／染色／上色」就可能被歸為染髮類＝特殊化妝品（註冊 12-16 個月）。時程從 4 個月變 16 個月，詳情頁、短影片指令碼、直播話術要一起管。

**特殊 vs 普通化妝品分界：** 染髮、燙髮、祛斑美白、防曬、防脫髮，以及宣稱新功效的產品＝特殊化妝品（註冊制）；其餘＝普通化妝品（備案制）。

**跨境電商路徑的限制：** 9610/1210 免註冊備案、上線快，但買家不得二次銷售——意味著做不了線下鋪貨與經銷。要走線下或招經銷，必須走一般貿易＋完成註冊/備案。

## 七、廣告投放注意事項

- **投放平臺完全不同**：Meta/Google 在大陸不可用，投放走抖音巨量引擎、小紅書（聚光/蒲公英）、騰訊廣告；海外投放經驗要重新校準。
- **落地頁門檻**：使用境內主機的網站需 ICP 備案才打得開；境外主機免備案但速度慢、且部分場景會被限制。多數品牌落地頁直接用小紅書店鋪或天貓國際店替代。
- **素材語言**：簡體中文+大陸審美與梗，臺灣用語（「品質」「影片」「優惠」用法差異）會讓使用者出戏。
- **廣告法紅線**：極限詞（最、第一、國家級）會被罰；功效宣稱與註冊分類繫結，沒註冊下來的宣稱不能投。
- **預算參考**：冷啟動建議先小紅書 KOC 種草（單筆合作數百至數千人民幣），跑出自然流量與口碑後再上付費投放。

## 八、文化禁忌與消費習慣

- **主權表述敏感**：地圖、地名與地區標註須與官方口徑一致，包裝與官網要先自查，這是下架與輿情的第一雷區。
- **成分黨成熟**：消費者會查成分表、看測評，功效宣稱要有證據支撐。
- **全平臺比價**：使用者會在天貓、京東、拼多多、抖音比價，定價要全渠道一盤棋。
- **直播議價與贈品文化**：直播間砍價、要贈品是常態，定價要留出讓利空間。
- **時效預期高**：習慣當日/次日達，跨境直郵 7-15 天的等待要在頁面上管理預期。
- **簡體為唯一書面語**：所有面向消費者的文字用簡體中文，繁體會被視為不專業或代購號。

## 九、競品分析參考

- **主要競品：** 國際大牌（歐萊雅/雅詩蘭黛系）、新銳國貨（完美日記/花西子類）、成分黨品牌（HFP/薇諾娜類）
- **價格帶參考：** 美妝精華主力價格帶約 ¥100-300；臺灣品牌建議卡位「輕奢小眾」區間，避免與國貨白牌拼低價
- **渠道佈局：** 天貓國際/京東國際（貨架）、抖音（直播+短影片）、小紅書（種草+店鋪）

## 十、該市場的診斷側重

- 品牌定位：中文品牌名與「小名」是否好念好記、有無負面諧音
- 官網健康度：大陸開啟速度、ICP 備案、是否需要小程式商城
- 廣告投放：投放平臺與素材體系完全不同，海外 Pixel 經驗不適用
- 私域流量：微信生態（公眾號+企業微信+社群）是主力，搭配小紅書群聊
- 法規合規：先確認走跨境電商（9610/1210，免註冊、不可二次銷售）還是一般貿易（註冊/備案 4-16 個月、境內責任人），宣稱文案會決定分類與時程
