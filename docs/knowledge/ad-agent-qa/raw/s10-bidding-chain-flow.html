广告平台竞价全链路流程图（v2 工业界标准）

一次广告展示背后的 14 步：从离线索引构建到数据回传驱动模型迭代（含 Pacing / GSP / SKAN / MMP / RTB）
紫色标签 = 关键广告配置字段（将影响该环节输出结果的后台可配字段）
① 离线索引与请求
② 召回与初筛
③ 预估与竞价
④ 扣费与渲染
⑤ 曝光点击
⑥ 回传闭环
0

硬状态预过滤（离线索引构建）

离线 / 近线倒排索引

在广告请求到达之前，离线/近线阶段就已从在线检索库中剔除：账户被封、余额不足、素材审核拒绝/下线、计划已暂停、投放时段未开始/已结束。这些硬状态不随单次请求变化，提前剔除省算力。

输入：全量广告计划 + 账户/素材审核状态 + 投放时段输出：在线检索库中状态可投的广告索引
关键广告配置字段：账户资质日预算/总预算（是否耗尽）素材审核状态法定年龄/地域硬门槛投放时段（dayparting）
1

用户访问与广告请求发起

端上 SDK / App / 网页

用户打开 App 或浏览网页，刷到一个广告位；客户端 SDK 发出广告请求，携带 device_id/IDFA、版位 ID、隐私授权状态（iOS ATT 是否授权、Web 同意弹窗）、设备信息。

输入：用户触发动作 + 隐私授权状态输出：带 device_id / 版位 ID / ATT 状态的广告请求
关键广告配置字段：无（端上行为；隐私授权状态决定后续信号可用度，但由系统/用户决定，非广告主配置）
2

用户画像与频控记录拉取

DMP / 用户画像服务 / 频控存储

广告服务器根据 device_id 拉取用户画像：年龄、性别、地域、设备、历史行为、兴趣标签、已转化/已点击记录；同时拉取该用户的频控历史（已看过哪些广告、看了几次）。iOS ATT 未授权时 IDFA 缺失，降级为 SKAN 模式。

输入：device_id、版位 ID、当前时间、隐私授权状态输出：用户画像包 + 频控历史 + 隐私信号等级
关键广告配置字段：无（DMP 拉全量画像；频控历史在 Step 4 用于过滤，广告主定向在 Step 3 用于匹配）
3

多路召回：定向与候选集抽取

召回引擎：定向 / 兴趣 / Lookalike / 关键词 / 向量检索

从在线检索库中，通过兴趣、行为、Lookalike、关键词、向量检索等多路并行，召回 "计划×创意"组合候选约 1000 个。智能投放系统（Meta Adv+、巨量全域推广、Google PMax）中，创意本身就是重要召回特征，没有具体创意就没有确定的 pCTR/pCVR。

输入：用户画像、版位、历史点击/转化输出：候选"计划×创意"组合集合（约 1000 个）
关键广告配置字段：定向（兴趣/行为/Lookalike/地域/年龄/性别）关键词及匹配方式排除人群投放版位投放目标
💡 投放目标决定召回通道："转化"目标走 Lookalike / 再营销召回，"曝光"目标走品牌通道，确实改变本环节输出。
4

实时过滤：频控与版位硬约束剔除

频控模块 + 预算模块 + 版位规格校验

对召回的 1000 个候选做实时硬过滤：①频控上限（同一用户对该广告已看 N 次则剔除，如 3 次/7 天）；②版位素材规格不符；③预算余额实时双检（防止召回期间预算花完）。频控前置到召回阶段可大幅降低后续精排算力损耗。

输入：候选组合 + 频控历史 + 实时预算余额 + 版位规格输出：通过硬约束的候选（几百个）
关键广告配置字段：频控上限日预算/总预算（实时余额）版位素材规格
5

多目标预估：pCTR / pCVR / pValue

深度学习预估模型（融合用户+广告创意+上下文特征）

对每个"计划×创意"组合，深度学习模型同时预估：点击率 pCTR、转化率 pCVR、转化价值 pValue。模型融合三类特征：用户特征、广告/创意特征、上下文特征。没有具体创意就没有确定的 pCTR/pCVR——这是和旧版"先无创意计划精排"的核心区别。

输入：候选"计划×创意"组合 + 用户特征 + 上下文特征输出：每个组合的 pCTR、pCVR、pValue
关键广告配置字段：转化事件投放目标转化价值（客单价）
6

智能出价与 eCPM 换算（含 Pacing 与质量分）

自动出价 / Pacing / 质量分调控

后台出价并非固定值：系统根据预算消耗速度（Pacing）、全天时段、冷启动/学习期动态微调（消耗过快降价、冷启动提价）。再按 eCPM 公式换算为曝光级竞价分，并叠加广告质量分（Ad Quality Score）作为调控项。

输入：pCTR/pCVR/pValue + 后台出价 + Pacing 状态 + 质量分输出：每个候选的综合竞价得分 Total Score
关键广告配置字段：出价方式（CPC/CPM/oCPM/tCPA/tROAS）出价金额/目标 CPA/tROAS投放目标
工业界标准 eCPM / Total Score 公式：
CPC 出价：eCPM = 出价 × pCTR × 1000
oCPM / tCPA 出价：eCPM = Target CPA × pCTR × pCVR × 1000 × PacingFactor
tROAS 价值出价：eCPM = (pValue / Target ROAS) × pCTR × pCVR × 1000
Total Score = eCPM + Ad Quality Score（用户体验/素材质量/历史转化等质量分调控项）
7

粗排 → 精排双层排序

粗排（轻量模型）→ 精排（深度模型）

粗排用轻量模型快速把几百个压到几十/一百个；精排用深度模型重新打分，按 Total Score 从高到低排序，取 Top 1（或 Top 1–3）胜出。

输入：候选 Total Score、质量分、预算余额输出：胜出的 1 条"计划×创意"组合
关键广告配置字段：质量度（素材/相关性）投放目标
8

扣费结算：GSP / VCG 次高价

广义第二价格 / VCG

胜出广告按广义第二价格（GSP）或 VCG 机制计费——实际扣费 = 下一名 eCPM × 换算系数 + 调价，而非自己的出价。这保证广告主不虚高出价。CPC/oCPM 扣费都基于此机制。

输入：胜出广告 + 次高 eCPM + 计费方式输出：本次曝光/点击的实际扣费
关键广告配置字段：计费方式（CPC/CPM/oCPM）
9

创意组合与端上渲染（DCO / RSA）

程序化创意 / 动态创意优化

程序化创意（DCO/RSA）动态组合标题×封面×视频，下发到客户端渲染。Pin 固定位素材优先。这一步是端上最终渲染，不重新排序——精排阶段（Step 5–7）已完成创意级 pCTR/pCVR 预估。

输入：胜出的"计划×创意"组合 + 程序化创意配置输出：最终下发到端上的素材 + 文案 + CTA
关键广告配置字段：程序化创意 / RSAPin 固定位素材池Adv+ Creative
10

素材展示与曝光计费（CPM 点）

端上曝光监测

素材在屏幕上展示并满足有效曝光定义（停留 1 秒 / 可见 50% 等），客户端上报曝光事件。这是 CPM 计费点，也是后续归因起点。

输入：素材成功渲染并满足曝光定义输出：曝光日志（user × ad × creative × 时间）
关键广告配置字段：计费方式（CPM 曝光计费）投放版位曝光定义
💡 投放版位决定曝光判定规则：信息流停留 1 秒、开屏展示完成、Banner 可见 50% 等，版位配置直接改变"什么时候算曝光"。
11

用户点击与链路下发（CPC 点）

端上点击监测 / DeepLink

用户对素材产生交互（点击/滑动/播放），客户端上报点击事件（CPC 此时计费）；同时携带 click_id、UTM、DeepLink 跳转落地页/App。

输入：用户手势输出：点击日志 + 跳转 URL（含 click_id / UTM / DeepLink）
关键广告配置字段：计费方式（CPC 点击计费）CTA 按钮创意形式UTM 参数深度链接
12

转化发生与 MMP / CAPI 归因

Pixel / CAPI / S2S / 第三方 MMP（AppsFlyer / Adjust）

用户在落地页/App 内发生转化（注册/付费/激活）。第三方 MMP 或广告主 CAPI 捕获事件，跨渠道去重（自然量 vs 付费量、Google vs Meta），在归因窗口内匹配到之前的曝光/点击。iOS ATT 未授权时走 SKAN，延迟 24–48h 且无单用户 click_id。

输入：转化事件 + click_id/device_id + 隐私信号等级输出：带归因的转化日志（跨渠道去重后）
关键广告配置字段：转化归因（Pixel/CAPI/S2S/MMP）转化事件归因窗口时区币种转化价值
13

模型更新与自动扩量闭环

实时流计算（Flink）+ 预估模型在线更新（Online Learning）

归因后的"曝光-点击-转化"完整样本流进入模型训练体系，实时更新 pCTR/pCVR 特征权重，并触发自动扩量（Adv+ Lookalike）算法。

输入：归因好的完整样本输出：更新后的 pCTR / pCVR / 出价模型
关键广告配置字段：转化数据质量/完整性自动扩量开关
↑ 第 13 步的模型更新，会实时反哺第 2 步（用户画像与兴趣更新）、第 3 步（智能扩量与召回更准）、第 5 步（pCTR/pCVR 预估更准）、第 8 步（DCO 素材组合优选）——形成算法自我进化的飞轮
优化师与算法工程师必须掌握的四大核心机制：
① 创意即召回（Creative as Targeting）：在智能广告时代（Meta Adv+ / 巨量全域），第 3 步召回与第 8 步创意优选已深度融合。好的创意素材本身就是最好的定向标签。
② eCPM 与 GSP 次高价扣费：第 6 步按 eCPM 得分竞价争夺 Top 1 排名，但第 7 步结算时采用广义第二价格（GSP）扣费，实际扣费取决于第二名的 eCPM + $0.01。
③ Pacing 动态调价因子：竞价公式中的 Pacing 因子会根据预算消耗进度动态调控出价。早晨消耗太快会触发降价，临近结算消耗太慢会触发提价。
④ 数据回传（CAPI）决定模型上限：第 12 步的回传完整度直接决定第 13 步模型的训练质量。接入 CAPI 服务端回传及设置正确的归因窗口，是提升 oCPM/tCPA 效果的底层基石。
注：本图已融合国内外主流平台（Meta、Google、巨量引擎、腾讯广告、TikTok 及 OpenRTB 程序化竞价）的通用技术底层规范。
