# Amazon Listing Alexa 优化检查器

> 适配 Alexa for Shopping / AI 购物时代的亚马逊 Listing 检查与优化 Skill

## 这是什么

一个用于在 **Alexa for Shopping / AI 购物时代**下，对亚马逊 Listing 做全面检查与优化的 Skill。核心目标：

> 让 Listing 从"关键词堆砌"升级为"可理解的商品信号"，使 AI 导购能**理解、引用、比较并推荐**该产品。

## 为什么需要

亚马逊购物入口正在变化：

- **2026 年** Amazon 正式推出 **Alexa for Shopping**，整合原 Rufus 产品知识 + Alexa+ 个性化上下文
- **2026/3/25** Sponsored Products/Bands **AI Prompts** 在美国站正式可用
- **2026/7/27** 美国站大多数非媒体类目**标题收紧到 ≤ 75 字符**，新增 **Item Highlights（≤ 125 字符，可搜索）**

传统"堆关键词"写法已不适用。AI 导购推荐的不是关键词最多的产品，而是：**它能理解、能解释、能比较、能让用户放心下单的产品**。

## 何时触发

当用户出现以下意图时自动触发：

- 提供 Listing 内容（标题/五点/Item Highlights/A+/后台属性等）请求"检查""优化""诊断""评分""改写"
- 询问标题 75 字符新规、Item Highlights、Alexa for Shopping 相关 Listing 调整
- 提供竞品 Listing 请求对比分析
- 询问 Listing 是否"被 Alexa 推荐""适合 AI 购物"

## 核心检查框架：8 大维度

每维度 0-10 分，换算 100 分制。

| # | 维度 | 关键检查点 |
|---|------|-----------|
| 1 | 买家问题清单 | Listing 能否回答买家真实会问的 10-20 个问题（含边界问题） |
| 2 | 标题 | ≤75 字符；公式：品牌+核心产品词+关键属性+核心场景；前 50 字符说清产品 |
| 3 | Item Highlights | ≤125 字符；覆盖材料/用途/场景/兼容/差异点/人群尺寸 |
| 4 | 五点描述 | 问题回答结构（用途/场景/功能/材质安全/边界）；边界信息必填 |
| 5 | A+ 页面 | 场景证明（谁用/在哪用/为什么/怎么用/区别）；结构化信息 |
| 6 | Q&A 与评论 | 高频正面词强化、负面词处理、训练信号 |
| 7 | 后台属性 | 结构化字段完整性（材质/尺寸/容量/兼容/功率/电压/防水等） |
| 8 | 关键词与 Prompts | 分层组织（核心→标题/场景→Highlights/痛点→五点/长尾→A+后台）；Prompts 复盘 |

## AI 四问（检查基准）

AI 看完 Listing 后必须能回答：

1. 你到底是什么产品？
2. 你适合什么人、什么场景？
3. 你解决了什么具体问题？
4. 你和同类产品相比，凭什么值得推荐？

四个问题回答不清楚，Alexa 很难把该产品放进推荐。

## 输出报告格式

执行检查后输出结构化报告：

1. **执行摘要** —— 综合得分、等级、核心结论、AI 四问覆盖度
2. **各维度评分表** —— 8 维度得分与状态（✅/⚠️/❌）
3. **详细问题清单** —— 按 P0/P1/P2 优先级排序，含位置/现状/问题/影响/建议
4. **改写示例** —— 标题/Item Highlights/五点的新旧对照（含字符数与理由）
5. **买家问题清单** —— 10-20 个问题逐条标注是否能回答
6. **7 天行动清单** —— 结合实际问题定制的落地计划
7. **误区排查** —— 五大常见误区逐条核对
8. **参考资源** —— 指向各 reference 文件

## 关键硬性规则

| 规则 | 参数 |
|------|------|
| 标题字符数 | ≤ 75 字符（美国站非媒体类目，2026/7/27 起） |
| 标题前缀 | 前 50 字符说清产品 |
| Item Highlights | ≤ 125 字符，可搜索、可展示 |
| 标题公式 | 品牌名 + 核心产品词 + 关键属性 + 核心场景 |
| 五点结构 | 1.核心用途 2.适用场景 3.关键功能 4.材质安全 5.注意事项与边界 |
| 关键词分层 | 核心词→标题 / 场景词→Item Highlights / 痛点词→五点 / 长尾词→A+Q&A后台 / 属性词→后台字段 |

## 五大常见误区（检查时必排查）

1. ❌ 拿到 Amazon's Choice 就一定被 Alexa 推荐
2. ❌ AI 购物来了关键词就不重要了
3. ❌ Listing 写得越像聊天越好
4. ❌ 标题变短流量一定会掉
5. ❌ Prompts 是广告团队的事 Listing 不用管

## 如何使用

直接向 AI 提供 Listing 内容即可，例如：

```
帮我检查这个 Listing：
标题：[你的标题]
五点：
1. ...
2. ...
品牌：[品牌名]
类目：[产品类目]
目标市场：美国站
后台属性：[已填字段]
```

Skill 会自动触发并输出完整诊断报告与改写建议。

## 重要约束

- 不给出"这样写一定被 Alexa 推荐"的绝对承诺。亚马逊未公开"Alexa 优先推荐算法公式"
- 所有建议基于已确认的变化：标题 75 字符新规、Item Highlights 字段、AI Prompts、Alexa for Shopping 能力整合
- 改写示例具体到字符数和措辞，不只说"建议优化标题"
- 报告必须包含买家问题清单（维度 1），这是整个检查的基础
- 边界信息（兼容性/限制/注意事项）缺失要重点提示——AI 推荐最怕信息不清
