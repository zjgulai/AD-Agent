## 1. 欧洲旅行转换插头

### 旧写法（关键词堆砌型）
**标题：**
```
European Travel Plug Adapter USB C International Power Adapter US to Europe Adapter for Italy France Spain Germany Iceland Portugal Greece with 2 Outlets 3 USB Ports
```
问题：关键词很全但超过 75 字符；国家名堆砌；信息挤；AI 难判断场景。

### 新写法（AI 友好型）
**标题：**
```
HANYCONY European Travel Plug Adapter with USB-C
```
（约 50 字符）

**Item Highlights：**
```
For Italy, France, Spain and Germany travel; 2 outlets and USB-C ports for phones, tablets and cameras.
```
（约 110 字符）

**五点建议：**
1. US to Europe 转换插头，适用于 Italy、France、Spain、Germany 等国家
2. 适合旅行场景，带 2 个 AC 插孔和 3 个 USB 口，可同时充手机/平板/相机
3. **不支持电压转换**，仅适用于双电压设备（如手机/相机充电器）
4. 小巧轻便，适合放行李箱和背包
5. 注意：不适用于需要电压转换的大功率电器（如吹风机/卷发棒）

**边界信息（重点）：**
- 是不是电压转换器 → 必须说清"不支持电压转换"
- 适用国家 → Item Highlights 列出
- 兼容设备 → 双电压设备

### AI 四问覆盖
1. 是什么产品？→ US to Europe 转换插头 ✅
2. 适合谁/什么场景？→ 去意大利/法国/西班牙/德国旅行的人 ✅
3. 解决什么问题？→ 给手机/平板/相机充电 ✅
4. 凭什么推荐？→ 2 outlets + 3 USB，小巧 ✅

## 2. 65W GaN USB-C 充电器

### 旧写法
**标题：**
```
65W USB C Charger Fast Charger for MacBook Pro iPad iPhone Samsung Type C Wall Charger Foldable Plug GaN Charger Adapter
```
问题：同义词堆砌（Charger 重复 3 次）；超过 75 字符；信息挤。

### 新写法
**标题：**
```
VoltPro 65W GaN USB-C Charger, Foldable Plug
```
（约 42 字符）

**Item Highlights：**
```
Compact travel charger for MacBook, iPad, iPhone and Samsung USB-C devices.
```
（约 73 字符）

**五点建议：**
1. 65W 快充，适合 MacBook、iPad 等笔记本和平板
2. GaN 小体积，适合出差和旅行
3. 折叠插脚，放包里不刮设备
4. 兼容设备：MacBook/iPad/iPhone/Samsung USB-C 设备；不支持需要超过 65W 的设备
5. 安全保护：过充/过热/短路保护；包装内容：充电器 ×1，说明书 ×1

**A+ 场景拆解：**
- 办公桌充电场景
- 机场/酒店旅行场景
- MacBook + 手机同时充电场景
- 尺寸对比图
- 兼容设备表

### AI 场景匹配示例
用户问："我出差想找一个可以同时给 MacBook 和手机充电的小充电器。"
Alexa 要找：65W + GaN + USB-C + 适合 travel + foldable plug + 兼容 MacBook 和 iPhone + 小巧 + 安全 + 评价支持。
→ 新写法全部覆盖 ✅

## 3. 宠物旅行水杯

### 旧写法
**标题：**
```
Dog Water Bottle for Walking, Portable Dog Bowl, Dog Travel Water Bottle, Puppy Water Cup, Outdoor Pet Drinking Bottle
```
问题：同义词堆砌（dog/water/bottle 重复）；超过 75 字符；无场景信号。

### 新写法
**标题：**
```
PawGo Leakproof Dog Water Bottle for Travel
```
（约 44 字符）

**Item Highlights：**
```
One-hand water release, leakproof lock, 19oz capacity for walks, hiking and car trips.
```
（约 88 字符）

**五点建议：**
1. 19oz 容量，适合日常遛狗和短途旅行
2. 一键出水，多余水可回流，减少浪费
3. 防漏锁扣，适合放背包和车里
4. BPA-free 材质，容易拆洗
5. **适合小型犬和中型犬，大型犬建议选择更大容量**

**边界信息（重点）：**
- 容量：19oz
- 适用犬型：小型犬、中型犬；大型犬建议更大容量
- 材质：BPA-free
- 场景：遛狗、徒步、开车旅行

### AI 场景匹配示例
- 用户问"hiking with dog bottle that doesn't leak" → 系统能理解 ✅
- 用户问"water bottle for small dogs travel" → 系统能理解 ✅
- 用户问"can I put it in backpack" → 有答案（防漏锁扣）✅

## 4. 露营灯

### 买家问题清单（维度 1 示例）
1. 适合停电用吗？
2. 续航多久？
3. 亮度够不够一个帐篷？
4. 可以充手机吗？
5. 防水吗？
6. 适合车里应急吗？
7. 和手电筒有什么区别？
8. 能挂起来吗？
9. 有几个亮度档位？
10. 电池类型是什么？能换电池吗？

### 新写法要点
**标题公式：** 品牌名 + 露营灯 + 关键属性（如 rechargeable/LED）+ 核心场景（如 camping/emergency）

**Item Highlights：** 覆盖续航时数、亮度档位、防水等级、充电功能、适用场景

**五点结构：**
1. 核心用途：帐篷/桌面照明
2. 适用场景：露营/停电/车载应急/户外
3. 关键功能：续航 X 小时、X 档亮度、可挂
4. 材质安全：防水 IPX4、耐摔
5. 边界：能否充手机、电池能否更换、最大照明范围

**A+ 场景拆解：**
- 帐篷场景
- 停电场景
- 车载应急场景
- 户外桌面场景
- 续航和亮度对比

## 5. 男士护肤套装

### 买家问题清单示例
1. 适合敏感肌吗？
2. 适合什么肤质？
3. 包含哪些产品？
4. 适合多大年纪？
5. 有香味吗？
6. 含酒精吗？
7. 早晚都能用吗？
8. 适合油性皮肤吗？

### 新写法要点
**边界信息（重点）：**
- 肤质：适合油性/混合性/敏感性（要明确）
- 年龄：建议年龄段
- 成分：是否含酒精、是否无香
- **避免医疗宣称**（如"治疗""治愈""药物"）—— AI 推荐最怕信息不清，护肤品越把边界讲清楚越敢推荐

## 6. 改写通用原则

### 标题改写公式
```
品牌名 + 核心产品词 + 关键属性 + 核心场景
```
- ≤ 75 字符
- 前 50 字符说清产品是谁
- 不堆同义词、竞品词

### Item Highlights 改写要点
覆盖以下中至少 4-5 项：
- 材料
- 推荐用途
- 适用场景
- 兼容范围
- 核心差异点
- 人群或尺寸

### 五点改写结构
| 第几点 | 内容 | 关键 |
|--------|------|------|
| 1 | 产品核心用途 | 说清"是什么" |
| 2 | 适用场景 | 说清"给谁用/在哪用" |
| 3 | 关键功能 | 说清"解决什么问题" |
| 4 | 材质和安全 | 说清"凭什么信任" |
| 5 | 注意事项和边界 | 说清"限制和适用边界"——最重要 |

### 边界信息必填清单（按品类）

| 品类 | 必填边界信息 |
|------|-------------|
| 转换插头 | 是否支持电压转换、适用国家、兼容设备类型 |
| 充电器 | 兼容设备、功率限制、是否支持快充协议 |
| 宠物用品 | 容量、适用宠物体型/体重、材质安全性 |
| 露营灯 | 续航时数、防水等级、电池类型、能否充手机 |
| 护肤品 | 适用肤质、年龄段、是否含酒精/香精、避免医疗宣称 |
| 电子产品 | 兼容型号、功率、电压、包装内容 |

### 改写前后对照检查
改写后必须确认：
- [ ] 标题 ≤ 75 字符
- [ ] Item Highlights ≤ 125 字符
- [ ] 五点每条回答一个问题
- [ ] 边界信息完整
- [ ] 关键词分层组织（不堆砌）
- [ ] AI 四问全部能回答
- [ ] 后台属性填完整
