## 1. 已确认的变化（截至 2026/7/14）

### 变化一：Alexa for Shopping 正式推出

Amazon 在 2026 年正式推出 Alexa for Shopping，把原来的 Rufus 产品知识能力和 Alexa+ 的个性化上下文结合起来。

- 入口：Amazon App、网页搜索框、Echo Show 等
- 用户可问购物问题，如"什么男士护肤流程比较好""帮我比较这几款产品""我上次什么时候买过电池"
- 结合：产品知识 + 网页信息 + 用户偏好 + 购物历史 + 历史对话 + 浏览和购买行为
- 能力：产品比较、购物建议、价格历史、自动补货、购物提醒
- 本质：亚马逊搜索从"关键词搜索"走向"问题式购物"和"助手式推荐"

### 变化二：AI Prompts 正式可用

Amazon Ads 在 2026/3/25 把 Sponsored Products Prompts 和 Sponsored Brands Prompts 在美国站推向正式可用。

- AI Prompts 根据商品详情页、Brand Store、广告活动数据等自动生成产品相关问题或对话入口
- 点击后可能打开 Rufus/Alexa 对话，或直接在页面上回答用户问题
- Listing 是 AI 广告的素材库；广告是 AI 对话的流量入口

### 变化三：标题 75 字符新规

2026/7/27 起，亚马逊美国站大多数非媒体类目的标题要求收紧到 75 个字符以内。

- 同时新增 Item Highlights，最多 125 字符
- Item Highlights 展示材料、适用场景、推荐用途等
- 官方明确：Item Highlights 可搜索，显示在搜索结果和详情页

### 变化四：Rufus 与 Alexa+ 整合

Rufus 和 Alexa+ 已整合成 Alexa for Shopping，不再是两套分开的购物入口。

## 2. 已过时的认知（检查时要标记）

以下说法已过时，若 Listing 优化策略基于这些认知，要在报告中提示：

- ❌ "Alexa 购物只发生在 Echo 音箱里" —— 过时
- ❌ "只要拿到 Amazon's Choice 就一定能吃语音购物流量" —— 太老
- ❌ "Listing 只要堆关键词就能被 AI 推荐" —— 不符合现在趋势
- ❌ "Rufus 和 Alexa 是完全分开的两套购物入口" —— 已整合

## 3. 底层逻辑：亚马逊为什么押注 AI 购物

传统搜索有三个问题，Alexa for Shopping 是答案：

### 问题一：买家不会表达
很多买家不知道产品专业词。不会搜 `European Type C Plug Adapter with 2 USB-C Ports`，只会说"去欧洲旅行要买什么插头？"以前要自己翻搜索结果、看评论、对比参数；现在 Alexa 直接理解问题，把商品信息整理成建议。

### 问题二：商品太多，选择成本太高
一个关键词搜出几千个结果，买家看不过来。亚马逊要解决的不是"给用户更多选择"，而是"帮用户更快做选择"。

### 问题三：移动端和语音场景下，长标题、堆关键词、复杂页面都不适合
- 手机上：标题太长看不完
- 语音场景：标题太乱听不懂
- AI 对话：信息不结构化就不好引用

**本质：购物从"搜索结果页竞争"推进到"AI 答案竞争"。**
以前争搜索结果第几名；以后还要争 AI 回答用户问题时会不会引用、比较、推荐你。

## 4. Listing 核心理念转变

| 旧时代 | AI 购物时代 |
|--------|------------|
| 核心是"覆盖关键词" | 核心是"建立可理解的商品信号" |
| 写给搜索框看 | 写给 AI 导购理解 |
| 主关键词塞标题 | 核心词放标题，场景词放 Item Highlights |
| 核心词塞五点 | 痛点词放五点（回答问题） |
| 长尾词塞后台 | 长尾词放 A+/Q&A/后台 Search Terms |
| 竞品词偷偷塞 | 属性词填后台结构化字段 |
| 能重复就重复 | 不要无脑重复关键词 |
| 标题承担所有信息 | 标题说清"是谁"，其他字段补充场景/边界 |

### "可理解的商品信号"定义

AI 看完页面后能回答四个问题：
1. 你到底是什么产品？
2. 你适合什么人、什么场景？
3. 你解决了什么具体问题？
4. 你和同类产品相比，凭什么值得推荐？

### AI 导购推荐什么样的产品

不是关键词最多的。不是标题最长的。而是：**它能理解、能解释、能比较、能让用户放心下单的产品。**

## 5. 新规关键参数速查

| 项目 | 参数 | 生效/状态 |
|------|------|-----------|
| 标题字符数 | ≤ 75 字符（美国站非媒体类目） | 2026/7/27 起 |
| 标题前缀 | 前 50 字符说清产品 | 建议 |
| Item Highlights | ≤ 125 字符 | 已上线 |
| Item Highlights 可搜索 | 是 | 已确认 |
| Item Highlights 展示位 | 搜索结果 + 详情页 | 已确认 |
| AI Prompts（SP/SB） | 美国站正式可用 | 2026/3/25 |
| Prompts 报告字段 | prompt text、关联广告、展示、点击、订单 | 可暂停单个 prompt |

## 6. 关键词分层组织原则

关键词仍然重要，但角色变了——从"堆"变成"组织语义"：

| 关键词类型 | 放置位置 |
|-----------|----------|
| 核心词 | 标题 |
| 场景词 | Item Highlights |
| 痛点词 | 五点 |
| 长尾词 | A+、Q&A、后台 Search Terms |
| 属性词 | 后台结构化字段 |

## 7. Amazon's Choice 的新定位

仍有参考价值（代表某搜索词下的信任信号），但不是唯一答案。还要看：
- 产品信息是否完整
- Review 是否支持卖点
- 价格是否有竞争力
- 配送是否稳定
- 页面是否回答了用户问题
- 广告 Prompts 有没有带出有效对话
- 标题和 Item Highlights 是否能被搜索和 AI 正确理解
