# 8 维度详细评分标准

本文件定义每个维度的 0-10 分评分细则。打分时阅读。

## 目录
- 评分总则
- 维度 1：买家问题清单
- 维度 2：标题
- 维度 3：Item Highlights
- 维度 4：五点描述
- 维度 5：A+ 页面
- 维度 6：Q&A 与评论
- 维度 7：后台属性
- 维度 8：关键词与 Prompts
- 加分项机制
- 综合得分换算
- 改写示例与风险措辞约束

## 评分总则

- 每维度 0-10 分
- 8 维度满分 80 分，换算为 100 分制：`综合得分 = (维度总分 / 80) × 100 + 加分项`
- 最终分不超过 100

### 等级锚点（v2，2026/8/5 修订）

| 综合得分 | 等级 | 说明 |
|----------|------|------|
| 85-100 | 优秀 | 新规完全适配 + 信号丰富 + 市场基础强 |
| 70-84 | 良好 | 市场头部品或内容质量高，有微调空间 |
| 55-69 | 需优化 | 中等品，存在信号缺口 |
| 40-54 | 需改进 | 明显短板，影响 AI 推荐与转化 |
| <40 | 高风险 | 信号严重不全 + 无市场基础 |

> 修订原因：旧锚点（75 才进良好、<60 即高风险）在 2026/7/27 新规过渡期内容易把市场头部品（4.7★ / 5 万评论 / 子类 #1）误判为高风险，区分度接近 0。新锚点把"良好"下移到 70，"高风险"上移到 40，让市场头部品能进入"良好"，让真正差的 Listing 仍落入"高风险"。

### 单维度状态

| 分数 | 状态 |
|------|------|
| 8-10 | ✅ 达标 |
| 5-7 | ⚠️ 需优化 |
| 0-4 | ❌ 严重问题 |

### 过渡期规则（2026/7/27 – 2026/9/30）

新规字段（标题 75 字符、Item Highlights）刚生效，市场上大多数 Listing 尚未适配。过渡期内：

- 标题 75-150 字符但产品身份清晰、核心信号可提取 → 给 4-5 分（不直接 0-2）
- Item Highlights 未填 → 给 4 分（标注"待补"），不直接 0-2
- 2026/9/30 后恢复严格评分

### N/A 字段处理（重要）

无法从外部抓取或用户未提供的字段（如 A+ 完整内容、后台 Search Terms、Prompts 报告）：

1. 在报告中标注 "N/A — 未提供"
2. 按 **5/10 中性分** 计入总分（不假设最差、不假设最好）
3. 在"行动清单"中提示用户核实
4. 不得因 N/A 而触发红线或一票否决

> 修订原因：旧规则把"未提供"等同于"严重缺陷"，导致评分被 N/A 字段拖低。N/A 应中性处理。

### 评分锚点原则

评分必须以**市场基准**为参照，避免把"市场头部品"和"差品"打成同一分：

- 4.5★+ 且 ≥10,000 评论 → 维度 6 应得 9-10 分
- BSR 大类 Top 1000 或子类 Top 10 → 加分项 +3
- Amazon's Choice 标签 → 加分项 +3
- 4.0★ 以下或评论 <10 条 → 不能进入"良好"等级

## 维度 1：买家问题清单（Intent Coverage）

检查 Listing 是否能回答买家真实会问的问题。这是整个检查的基础。

### 评分细则

| 分数 | 标准 |
|------|------|
| 9-10 | 列出 15-20 个买家问题，≥90% 在 Listing 中有明确答案，边界问题（兼容/限制/容量/适用人群）全覆盖 |
| 7-8 | 列出 10-15 个问题，70-89% 有答案，边界问题基本覆盖 |
| 5-6 | 列出 5-10 个问题，50-69% 有答案，边界问题部分缺失 ｜ 或后台关键字段错误导致 AI 被误导（见下） |
| 3-4 | 问题清单不全，<50% 有答案，关键边界问题缺失 ｜ 或后台关键字段错误严重误导 AI 推荐方向 |
| 0-2 | 未做问题清单，Listing 无法回答多数买家场景问题 |

### 后台关键字段错误判定（v2.1，2026/8/5 修订）

后台关键字段错误会**主动误导 AI 推荐**，不能等同于"信息部分缺失"，应判为更严格的状态：

- **关键字段错误会误导 AI 推荐方向**（如年龄上限、兼容型号、电压等）→ AI 四问覆盖度判为 **❌ 错误信号**（而非 ⚠️ 部分覆盖），维度 1 最多 5-6 分
- **关键字段错误严重误导**（如"仅适合 3 岁"实际适合 10 岁+）→ 维度 1 最多 3-4 分
- **非关键字段错误**（如颜色字段不规范但不影响推荐）→ 仍按 ⚠️ 部分覆盖判定

"关键字段"指会直接影响 AI 过滤推荐的字段：
- 适用年龄（Manufacturer Minimum/Maximum Age）
- 兼容型号（Compatible Devices / Compatible Phone Models）
- 电压/功率（Input Voltage / Wattage）
- 防水等级
- 包装内容（Item Package Quantity）

> 修订原因：Disney Buzz 后台 Max Age 36 months 是错误信号，会让 AI 误判"仅适合 3 岁孩子"，实际适合 10 岁+。这种"错误信号"比"信息缺失"更严重——缺失只是不推荐，错误是错误推荐。旧规则判为 ⚠️ 部分覆盖过宽。

### 检查方法
1. 根据品类列出买家最可能问的 10-20 个问题（参考评论、Q&A、竞品差评、搜索词报告）
2. 逐条核对 Listing 中是否有对应答案
3. 重点检查边界问题：
   - 兼容性（适配什么设备/国家/犬型/肤质）
   - 容量/尺寸/功率
   - 使用限制（不支持电压转换/不适合某人群）
   - 注意事项
4. 标注每个答案的位置（标题/五点X/A+/后台字段）

### 红线（扣到 4 分以下，但不再一票否决整体）
- Listing 无法回答"我这种场景能不能用"
- 关键边界信息完全缺失（如转换插头没说是否支持电压转换）

## 维度 2：标题（Title）

### 评分细则（v2，含过渡期）

| 分数 | 标准 |
|------|------|
| 9-10 | ≤75 字符；符合"品牌+核心产品词+关键属性+核心场景"公式；前 50 字符说清产品；无堆砌；人机可读 |
| 7-8 | ≤75 字符 + 基本符合公式 ｜ **或** 76-100 字符但产品身份清晰、核心信号可提取 |
| 5-6 | 100-150 字符但产品身份清晰 ｜ 或 ≤75 字符但有少量堆砌 ｜ 或公式不完整 |
| 3-4 | 150-200 字符 + 堆砌明显 ｜ 或 ≤75 字符但公式缺失严重 ｜ 或有限制词当卖点（如"Non-PPS"） |
| 0-2 | >200 字符且无法识别产品 ｜ 或标题与产品不符 ｜ 或纯堆砌无任何核心信号 |

### 过渡期补充（2026/7/27 – 2026/9/30）
- 75-150 字符但产品身份清晰：给 4-5 分（不直接 0-2）
- 150-200 字符且堆砌明显：给 3-4 分
- 2026/9/30 后：超 75 字符最多给 5 分

### 检查项
- [ ] 字符数 ≤ 75（美国站非媒体类目，2026/7/27 起）
- [ ] 前 50 字符能否说清产品是谁
- [ ] 是否符合公式：品牌名 + 核心产品词 + 关键属性 + 核心场景
- [ ] 是否同义词重复（如 Charger / Fast Charger / Wall Charger / Adapter 重复）
- [ ] 是否堆竞品词、无关词
- [ ] 标题是否承担了所有信息（应该分配到其他字段）
- [ ] 是否有限制词当卖点（如 "Non-PPS"、"Not for..."）
- [ ] 是否有拼写错误（需核实是否品牌缩写）

### 红线
- 标题承担所有信息且超 200 字符
- 标题与产品不符
- 限制词当卖点暴露短板

## 维度 3：Item Highlights

### 评分细则（v2，含过渡期）

| 分数 | 标准 |
|------|------|
| 9-10 | ≤125 字符；覆盖材料/用途/场景/兼容/差异点/人群尺寸中 ≥5 项；比标题堆词更有价值 |
| 7-8 | ≤125 字符；覆盖 4 项；信息有价值 |
| 5-6 | ≤125 字符但覆盖不全（≤3 项）；或接近字数上限 |
| 3-4 | 仅重复标题内容 ｜ 或过渡期内未填写（2026/9/30 前） |
| 0-2 | 过渡期后（2026/9/30 后）仍未填 ｜ 或填写内容与产品完全不符 |

### 过渡期补充（2026/7/27 – 2026/9/30）
- 未填写：给 4 分（标注"待补"），不直接 0-2
- 已填写但仅重复标题：给 3-4 分
- 2026/9/30 后：未填按 0-2 分

### 检查项
- [ ] 字符数 ≤ 125
- [ ] 覆盖：材料 / 推荐用途 / 适用场景 / 兼容范围 / 核心差异点 / 人群或尺寸
- [ ] 是否比在标题里堆国家名/型号更有价值
- [ ] 是否可搜索、可展示

### 红线
- 填写内容与产品完全不符
- 重复标题内容且无新增信息

## 维度 4：五点描述（Bullets）

### 评分细则

| 分数 | 标准 |
|------|------|
| 9-10 | 5 条结构清晰（用途/场景/功能/材质安全/边界）；每条回答一个问题；无空话；边界信息完整 |
| 7-8 | 5 条结构基本清晰；边界信息较完整；偶有空话 |
| 5-6 | 5 条但结构混乱；空话较多；边界信息不足 |
| 3-4 | 不足 5 条或全是卖点堆砌；无边界说明 |
| 0-2 | 全是"high quality/easy to use/perfect gift"等空话 |

### 建议结构
1. 产品核心用途
2. 适用场景
3. 关键功能
4. 材质和安全
5. **注意事项和边界**（最重要）

### 检查项
- [ ] 是否避免"high quality / easy to use / perfect gift"等空话
- [ ] 边界信息是否清楚：
  - 转换插头：是不是电压转换器
  - 宠物水杯：容量和适用犬型
  - 充电器：兼容设备和功率限制
  - 护肤品：避免医疗宣称
- [ ] 每条是否只回答一个问题
- [ ] 是否重复标题内容
- [ ] 是否包含 emoji 或特殊字符（违反亚马逊政策，必须扣分）
- [ ] 是否包含竞品品牌名（违反亚马逊政策，必须扣分）

### 红线
- 五点全是形容词
- 没有边界说明
- 重复标题
- 包含 emoji / 特殊字符 / 竞品品牌名（政策违规）

## 维度 5：A+ 页面（场景证明）

### 评分细则（v2，含 N/A 处理）

| 分数 | 标准 |
|------|------|
| 9-10 | 覆盖谁用/在哪用/为什么用/怎么用/和普通款区别；多场景拆解；有对比表/兼容表/尺寸图等结构化信息 |
| 7-8 | 覆盖大部分场景；有部分结构化信息 |
| 5-6 | 有场景但不够拆解；结构化信息不足 ｜ **或 A+ 内容未提供（N/A 中性分）** |
| 3-4 | 纯图片无文字说明；无场景拆解 |
| 0-2 | 无 A+ 或 A+ 无实质内容（需用户提供截图确认） |

### N/A 处理
- 第三方无法抓取 A+ 完整内容时：标注 "N/A — 未提供"，按 5/10 中性分计入
- 用户已提供 A+ 截图但内容不全：按已提供部分打分
- 不得因"未提供 A+ 截图"而假设 A+ 不存在或质量差

### 检查项
- [ ] 谁在用 / 在哪里用 / 为什么用 / 怎么用 / 和普通款有什么区别
- [ ] 场景拆解（如露营灯：帐篷/停电/车载应急/户外桌面/续航亮度对比）
- [ ] 结构化信息：对比表、兼容设备表、尺寸图
- [ ] 文字说明是否可被 AI 总结
- [ ] 是否符合 A+ 政策（**不得直接列出竞品 ASIN/品牌名做对比**，只能用 "vs leading competitor"）

### 红线
- 纯图片无文字说明（需确认）
- 无场景拆解
- 直接列竞品 ASIN/品牌名（政策违规）

## 维度 6：Q&A 与评论（训练信号）

### 评分细则（v2，以市场表现为锚点）

| 分数 | 标准 |
|------|------|
| 9-10 | 4.5★+ 且 ≥10,000 评论 ｜ 或 4.6★+ 且 ≥1,000 评论 + 负面已治理 ｜ 高频正面词已强化进 Listing |
| 7-8 | 4.3★+ 且 ≥500 评论 ｜ 或 4.5★+ 且 ≥100 评论 ｜ 正面词部分强化；负面词有处理 |
| 5-6 | 4.0★+ 且 ≥50 评论 ｜ 或评论少但无重大负面 ｜ 只看星级不看内容 |
| 3-4 | <4.0★ ｜ 或评论 <10 条 ｜ 负面高频问题未在 Listing 中说明 |
| 0-2 | <3.5★ ｜ 或差评高频主题严重暴露产品问题 ｜ 无 Q&A 管理 |

### 检查项
- [ ] 高频正面词是否被强化进 Listing（如"不漏水""适合徒步""放背包没问题"）
- [ ] 高频负面词是否已用于优化产品和页面说明（如"尺寸不准""说明不清""不适合某设备"）
- [ ] Q&A 是否回答了边界问题
- [ ] 是否定期整理评论

### 红线
- 只看星级不看内容
- 负面高频问题未在 Listing 中说明 **且** 评论星级低于 4.0

> 修订原因：旧规则把 4.7★ / 5 万评论的 Disney 头部品只给 8 分，未以市场表现为锚点。新规则让前 0.1% 的评论基础得到 9-10 分。

## 维度 7：后台属性（结构化字段）

### 评分细则

| 分数 | 标准 |
|------|------|
| 9-10 | 品类相关字段 100% 填写且准确；与前台文案一致 |
| 7-8 | ≥90% 字段填写；基本准确（**封顶规则见下**） |
| 5-6 | 70-89% 字段填写；部分不准或留空 ｜ 或满足封顶规则 |
| 3-4 | <70% 字段填写；乱填或与前台矛盾 |
| 0-2 | 后台属性大量缺失或乱填 |

### 封顶规则（v2.1，2026/8/5 修订）

为避免"字段数量多但错误也多"的后台获得虚高分，新增封顶规则：

- **≥3 处字段错误/不规范** → 维度 7 评分**封顶 6 分**（即使字段填写率 ≥90%）
- **≥5 处字段错误/不规范** → 维度 7 评分**封顶 4 分**

"字段错误/不规范"包括：
- 字段值与产品实际不符（如玩具 Max Age 36 months 实际适合 10 岁+）
- 字段值与前台硬性矛盾（如标题 65W、后台 30W 且无解释）
- 字段值不规范（如 Color 字段填"Toy Story"而非实际颜色）
- 字段值明显存疑未核实（如塑料人偶 Item Weight 1 kg）
- 同一字段在后台有 2 套不一致数值且无解释

> 修订原因：Disney Buzz 后台有 Max Age 36 错误 + Item Weight 1kg 存疑 + Color "Toy Story" 不规范 + 两套尺寸不一致 共 4 处问题，但旧规则给 7/10，明显高于实际质量。封顶规则让"问题多的后台"得分回归合理。

### 必填字段（按品类适用）
材质 / 尺寸 / 颜色 / 容量 / 适配型号 / 适用年龄 / 功率 / 电压 / 是否防水 / 包装数量 / 目标人群 / 使用场景

### 检查项
- [ ] 逐项核对缺失字段
- [ ] 字段值是否准确（不是乱填或留空）
- [ ] 与前台文案是否一致
- [ ] **矛盾判定要谨慎**：如标题写"68W combined"、后台 Wattage 写"50W"——若 bullet 解释了双口模式下 USB-C 降至 50W，则不算矛盾，应判为"字段值反映了双口模式最大输出"

### 红线
- 后台属性大量乱填（≥30% 字段错误）
- 与前台文案硬性矛盾（如标题 65W、后台 30W 且无解释）

## 维度 8：关键词与 Prompts

### 评分细则（v2，Prompts 改为可选）

| 分数 | 标准 |
|------|------|
| 9-10 | 关键词分层清晰（核心词标题/场景词 Item Highlights/痛点词五点/长尾词 A+Q&A后台/属性词后台字段）；无重复堆砌；**若提供 Prompts 报告**则已复盘 |
| 7-8 | 关键词分层较好；无严重堆砌 |
| 5-6 | 关键词部分分层；有重复堆砌 ｜ 或关键词全堆标题但产品身份清晰 |
| 3-4 | 关键词全堆标题；后台 Search Terms 重复前台词 |
| 0-2 | 无关键词策略；标题无法识别核心产品 |

### Prompts 报告处理
- **Prompts 报告未提供**：不影响评分（标注 N/A），仅在行动清单中提示"如跑 SP/SB 广告建议复盘"
- **已提供 Prompts 报告**：按报告内容加分或扣分
- 不得因"未提供 Prompts 报告"而扣分到 0-2 分

### 检查项
- [ ] 关键词是否分层组织：
  - 核心词 → 标题
  - 场景词 → Item Highlights
  - 痛点词 → 五点
  - 长尾词 → A+/Q&A/后台 Search Terms
  - 属性词 → 后台结构化字段
- [ ] 是否无脑重复关键词
- [ ] Prompts 报告（如提供）：
  - AI 生成问题是否准确
  - 哪些有点击订单
  - 哪些烧钱不转化
  - 是否暴露 Listing 信息不清

### 红线
- 关键词全堆标题且无法识别核心产品
- 后台 Search Terms 完全重复前台词
- Prompts 暴露严重信息缺口且未修复（仅当 Prompts 报告已提供时）

## 加分项机制（v2 新增）

为避免把"市场头部品"误判为"高风险"，新增加分项：

| 加分项 | 分值 | 说明 |
|-------|------|------|
| Amazon's Choice 标签 | +3 | 信任信号 |
| BSR 大类 Top 1000 或子类 Top 10 | +3 | 市场表现锚点 |
| 4.6★+ 且 ≥10,000 评论 | **+4** | 评论护城河（市场前 0.1% 梯队，比 +2 档拉开差距） |
| 4.5★+ 且 ≥1,000 评论 | +2 | 评论基础好 |
| 已开通 A+ 且有结构化对比模块 | +2 | 信号丰富 |
| 已填 Item Highlights 且覆盖 ≥5 项 | +2 | 新规适配 |
| 已开通 Vine 计划 | +1 | 评论增长机制 |

**加分上限 10 分，最终分不超过 100**。

## 综合得分换算

```
基础分 = (维度1 + 维度2 + ... + 维度8) / 80 × 100
最终分 = min(基础分 + 加分项, 100)
```

### 一票否决项（v2，改为叠加触发）

**必须同时满足 2 项以上才降级**（不再因单项红线直接降级）：

- 标题 > 150 字符 **且** 后台属性大量缺失
- 边界信息完全缺失 **且** 评论 < 4.0★
- Listing 基于过时认知 **且** 无任何新规适配字段
- 后台属性与前台硬性矛盾 **且** 评论 < 4.0★

> 修订原因：旧规则单项红线就一票否决，导致 Disney / Amazon Basics 这种"标题虽长但产品身份清晰、市场表现强"的头部品被误判为高风险。新规则要求多项红线叠加才降级。

## 改写示例与风险措辞约束（v2 新增）

### 改写示例合规性检查（必读）

改写示例必须遵守亚马逊 Style Guide，**不得出现以下内容**：

1. **竞品品牌名 / ASIN / 型号**
   - ❌ "Compare with Xvive U2, Getaria M5, Boss WL-20"
   - ❌ "Amazon Basics 68W vs Anker 735 vs UGREEN 65W"（A+ 也不允许）
   - ✅ "Compare with leading 2.4GHz wireless systems"
   - ✅ "vs leading competitor"（A+ 允许）

2. **未验证的技术参数**
   - ❌ 推测充电时间"~2-hour recharge"（原 Listing 没说）
   - ❌ 推测电池容量"3.7V 600mAh"（未核实）
   - ✅ 仅使用原 Listing 已确认的参数
   - ✅ 如必须建议补参数，标注 "[需卖家实测]"

3. **医疗 / 安全宣称**
   - ❌ "治疗""治愈""抗菌""防病毒"
   - ✅ 仅使用亚马逊允许的中性描述

4. **特殊字符与 emoji**
   - ❌ ™ ® © ✔ ✅ ❌ 🎸 等
   - ✅ 纯文本 + 首字母大写

5. **促销语言**
   - ❌ "Best Seller""Free Shipping""Sale""Guaranteed"
   - ✅ 中性参数化表达

### 风险措辞约束

报告中的"风险预警"段落必须**有事实依据**，不得夸大：

| 禁止措辞 | 理由 | 替代表述 |
|---------|------|---------|
| "可能触发 CPSC 合规风险" | CPSC 要求窒息警告在包装上，不强制 bullets | "建议在包装和说明书上加窒息警告（CPSC 16 CFR 1500.19）" |
| "可能引发 EU 站点批量下架" | 一条 1★ 评论不会触发批量下架 | "建议关注 FR 站评论主题，若涉及频段合规可补充区域说明" |
| "确定被搜索权重压制" | 亚马逊未公开算法细节 | "新规生效后超长标题可能影响搜索表现，建议 A/B 测试" |
| "AI 不会推荐" | 无确凿证据 | "AI 推荐可能因信号不全而受限" |

### 数据未核实处理

凡报告基于第三方聚合数据（device.report / bigbangprice 等）：

1. 在"执行摘要"标注 "数据基于第三方，A+/Item Highlights/后台 Search Terms 等字段需用户登录 Seller Central 核实"
2. 评分时按 N/A 处理（见评分总则）
3. 行动清单第一项必须是 "登录 Seller Central 核实本报告标注的 N/A 字段"

### 行动清单合理化

7 天行动清单必须：

1. **按优先级分批**：P0 必做、P1 建议做、P2 长期做——不要求 7 天全做完
2. **大品牌卖家标注跨团队动作**：如"标题修改需合规团队审、A+ 修改需品牌团队配合"
3. **中小卖家标注最低执行项**：列出"如果只有 3 天时间，必须做这 3 项"
4. **Prompts 报告建议有前置条件**：先问"是否跑 SP/SB 广告"再决定是否建议复盘
5. **首项必须是数据核实**：核实 N/A 字段后再做修改
