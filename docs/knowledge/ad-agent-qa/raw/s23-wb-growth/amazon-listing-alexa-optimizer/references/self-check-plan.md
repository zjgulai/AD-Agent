# 7 天自查表与五大误区

本文件提供 7 天落地行动计划与误区排查清单。生成行动清单时阅读。

1. 行动清单合理化原则（v2 新增）

## 1. 行动清单合理化原则（v2 新增）

旧版 7 天 21+ 项行动清单对中小卖家不现实，对大品牌卖家涉及跨团队协作也难以 7 天做完。v2 改为按优先级分批：

### 优先级分层

| 优先级 | 时间 | 含义 | 适用对象 |
|-------|------|------|---------|
| **P0** | 48 小时内 | 必做，影响合规或核心转化 | 所有卖家 |
| **P1** | 1-2 周内 | 建议做，明显改善 AI 信号 | 有时间的卖家 |
| **P2** | 1 个月内 | 长期做，进一步优化 | 资源充足的卖家 |

### 卖家类型标注

生成行动清单时必须根据 ASIN 性质标注：

- **大品牌卖家**（Amazon Basics / Disney Store / Anker 等）：标注跨团队动作
  - "标题修改需合规团队审"
  - "A+ 修改需品牌团队配合"
  - "后台属性修改需 PIM 团队执行"
- **中小卖家**：标注最低执行项
  - "如果只有 3 天时间，必须做这 3 项 P0"
- **新品卖家**：标注前置依赖
  - "评论 <10 条时，先开 Vine 再做 Listing 优化"

### 数据核实前置

行动清单**第一项必须是数据核实**：

> 第 0 天：登录 Seller Central 核实本报告标注的 N/A 字段（A+ 完整内容、Item Highlights 是否填写、后台 Search Terms、Prompts 报告是否可用），再开始 P0 动作。

### Prompts 报告建议有前置条件

不要无脑建议"拉取 Prompts 报告"。先问用户是否跑 SP/SB 广告：
- 跑广告 → 建议复盘 Prompts 报告
- 不跑广告 → 跳过 Prompts 建议，仅在"长期优化"中提及

### 改写示例合规性

行动清单中如包含改写建议，必须符合亚马逊 Style Guide：
- 不点竞品名（用 "vs leading competitor"）
- 不用未验证参数（标注 "[需卖家实测]"）
- 不用 emoji / 特殊字符
- 不用促销语言

## 2. 7 天自查表

以下是卖家重做 Listing 的 7 天行动计划。在报告中结合本 Listing 实际问题定制具体动作。

### 第 1 天：标题检查
**目标：** 标题合规且清晰

- [ ] 检查标题有没有超过 75 个字符（美国站非媒体类目，2026/7/27 起）
- [ ] 是否能在前 50 个字符说清楚产品
- [ ] 是否符合公式：品牌名 + 核心产品词 + 关键属性 + 核心场景
- [ ] 是否有同义词重复、竞品词、无关词
- [ ] 标题是否承担了所有信息（应分配到其他字段）

**输出：** 新标题草稿（≤75 字符）

### 第 2 天：买家问题清单
**目标：** 列出买家真实问题

- [ ] 从评论中提取 20 个买家真实问题
- [ ] 从 Q&A 中补充问题
- [ ] 从竞品差评中提取痛点问题
- [ ] 从搜索词报告中补充长尾问题
- [ ] 按场景分类（兼容性/容量/尺寸/使用限制/注意事项）

**输出：** 20 个买家问题清单，标注当前 Listing 是否能回答

### 第 3 天：关键词分层
**目标：** 关键词从"堆"变成"组织语义"

- [ ] 把关键词分成五类：核心词、场景词、痛点词、属性词、长尾词
- [ ] 不要混在一起堆
- [ ] 分配位置：
  - 核心词 → 标题
  - 场景词 → Item Highlights
  - 痛点词 → 五点
  - 长尾词 → A+/Q&A/后台 Search Terms
  - 属性词 → 后台结构化字段
- [ ] 检查是否无脑重复关键词

**输出：** 关键词分层分配表

### 第 4 天：Item Highlights 重写
**目标：** 补充场景与边界信号

- [ ] 重写 Item Highlights（≤125 字符）
- [ ] 补充：材料、用途、场景、兼容性
- [ ] 确保比标题里堆词更有价值
- [ ] 确认可搜索、可展示

**输出：** 新 Item Highlights（≤125 字符）

### 第 5 天：五点优化
**目标：** 从"卖点堆砌"改为"问题回答"

- [ ] 优化五点，每一点回答一个明确问题
- [ ] 第一点：产品核心用途
- [ ] 第二点：适用场景
- [ ] 第三点：关键功能
- [ ] 第四点：材质和安全
- [ ] 第五点：注意事项和边界（最重要）
- [ ] 删除"high quality/easy to use/perfect gift"等空话
- [ ] 补充边界信息（兼容性/限制/容量/适用人群）

**输出：** 新五点描述

### 第 6 天：后台属性、A+、Q&A 补齐
**目标：** 补齐系统能理解的结构化信息

- [ ] 检查后台属性是否填完整（材质/尺寸/颜色/容量/适配型号/适用年龄/功率/电压/是否防水/包装数量/目标人群/使用场景）
- [ ] 后台属性值是否准确、与前台文案一致
- [ ] A+ 页面是否做场景拆解（谁用/在哪用/为什么用/怎么用/和普通款区别）
- [ ] A+ 是否有结构化信息（对比表/兼容表/尺寸图）
- [ ] Q&A 是否回答了边界问题
- [ ] 高频正面词是否强化进 Listing
- [ ] 高频负面词是否已用于优化产品和页面说明

**输出：** 后台属性补齐清单、A+ 优化方案、Q&A 补充清单

### 第 7 天：Prompts 与搜索词报告复盘
**目标：** 验证 Listing 信号是否清楚

- [ ] 查看 Prompts 报告（如在美国站跑 Sponsored Products/Bands）
  - AI 生成的问题是否准确
  - 哪些 Prompts 有点击和订单
  - 哪些问题在烧钱但不转化
  - Prompts 是否暴露了 Listing 信息不清楚
  - 用户最关心的是兼容/尺寸/材质/使用场景/价格
- [ ] 查看搜索词报告
  - AI 生成的问题
  - 用户点击的问题
  - 真实成交词
- [ ] 对比：AI 生成问题、用户点击问题、真实成交词是否一致

**判断标准：**
- ✅ 一致 → Listing 信号清楚
- ❌ 不一致 → 系统理解你的方式和你想表达的不一样，要赶紧调整

**输出：** 信号一致性报告 + 调整清单

## 2. 五大常见误区详解

### 误区一：拿到 Amazon's Choice 就一定被 Alexa 推荐

**为什么错：**
早期语音购物场景里，Amazon's Choice 确实经常被认为和语音推荐有关。但现在 Alexa for Shopping 已经变成更复杂的 AI 购物助手，会做比较、总结、价格历史、个性化推荐，还会结合用户历史和上下文。

**正确认知：**
Amazon's Choice 仍然重要（代表某搜索词下的信任信号），但不是唯一答案。还要看：
- 产品信息是否完整
- Review 是否支持卖点
- 价格是否有竞争力
- 配送是否稳定
- 页面是否回答了用户问题
- 广告 Prompts 有没有带出有效对话
- 标题和 Item Highlights 是否能被搜索和 AI 正确理解

**排查项：**
- [ ] Listing 是否只依赖 Amazon's Choice 标签而忽略信息完整度
- [ ] 是否有除标签外的场景/边界信号

### 误区二：AI 购物来了关键词就不重要了

**为什么错：**
关键词仍然重要，只是角色变了。

**正确认知：**
- 以前：关键词是用来堆的
- 现在：关键词是用来组织语义的

| 关键词类型 | 放置位置 |
|-----------|----------|
| 核心词 | 标题 |
| 场景词 | Item Highlights |
| 痛点词 | 五点 |
| 长尾词 | A+、Q&A、后台 Search Terms |
| 属性词 | 后台结构化字段 |

不是不要关键词，而是不要无脑重复关键词。

**排查项：**
- [ ] 关键词是否分层组织
- [ ] 是否无脑重复
- [ ] 后台 Search Terms 是否重复前台词

### 误区三：Listing 写得越像聊天越好

**为什么错：**
Alexa 是对话式购物，但 Listing 不是朋友圈文案。

**正确认知：**
Listing 既要自然，也要结构化。既要人能读懂，也要机器能提取。既要场景化，也要有明确参数。

**反例：** "非常适合旅行" —— 太空
**正例：** "适合欧洲旅行。适用于 Italy、France、Spain、Germany。带 2 个 AC 插孔和 3 个 USB 口。不支持电压转换。适合手机、平板、相机等双电压设备。"

**排查项：**
- [ ] 是否有"非常适合""很好用""完美"等空话
- [ ] 是否有具体参数（国家/容量/功率/尺寸/兼容设备）
- [ ] 是否结构化（可被 AI 提取）

### 误区四：标题变短流量一定会掉

**为什么错：**
标题变短，不代表信息消失。

**正确认知：**
Amazon 新规的逻辑：标题负责说清楚产品是谁，Item Highlights 负责补充材料、用途和关键卖点。

- 如果只把标题砍短，其他地方不补 → 流量可能掉
- 如果把信息重新分配到标题/Item Highlights/五点/A+/后台字段 → 反而更适合移动端和 AI 理解

**排查项：**
- [ ] 标题砍短后，信息是否分配到其他字段
- [ ] Item Highlights 是否补充了场景信息
- [ ] 五点是否补充了边界信息
- [ ] 后台属性是否填完整

### 误区五：Prompts 是广告团队的事 Listing 不用管

**为什么错：**
Amazon Ads 官方已说明，Sponsored Products Prompts 和 Sponsored Brands Prompts 会利用商品详情页、Brand Store、广告活动数据等一手信号来生成相关对话和产品信息。

**正确认知：**
- Listing 写得不清楚 → AI Prompts 也很难问出好问题、答出好内容
- 未来广告和 Listing 不是两件事
- **Listing 是 AI 广告的素材库**
- **广告是 AI 对话的流量入口**
- **转化靠的是页面信息能不能支撑推荐**

**排查项：**
- [ ] 是否查看 Prompts 报告
- [ ] AI 生成问题是否暴露 Listing 信息缺口
- [ ] 烧钱不转化的 Prompts 是否对应 Listing 信息不清

## 4. 一句话总结

Alexa for Shopping 不是让卖家放弃关键词，而是让卖家从"关键词堆砌"升级到"意图表达"。

未来 Listing 的核心不是写得更长，而是写得更清楚：

| 字段 | 职责 |
|------|------|
| 标题 | 说清楚你是谁 |
| Item Highlights | 说清楚你适合什么场景 |
| 五点 | 回答买家为什么买你 |
| A+ | 证明你的使用场景 |
| Q&A 和评论 | 强化信任 |
| 后台属性 | 帮助系统分类 |
| 广告 Prompts | 放大 AI 对话入口 |

**买家问得出来，系统读得懂，页面能转化。这才是 Alexa 购物时代 Listing 优化真正的底层逻辑。**
