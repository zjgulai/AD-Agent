# 单品类垂直分层投放 Playbook（清洗机实例）

## 核心问题

一个单品类（清洗机）从认知到复购的投放怎么按用户决策深度分层？受众定向、关键词、素材各层怎么匹配？多产品矩阵下生命周期怎么承接？

## 系统解答

### 1. 文档定位

S1《广告agent梳理》附件 docx《用户链路测试》，以**清洗机**为例的垂直分层投放方案：单品类中短期链路三层分层 + 全周期四阶段链路 + 素材-层级匹配 + 多产品生命周期承接 + 三组人群测试计划。是「受众分层 × 渠道 × 素材」的可复用打法模板 `[推断]`。

### 2. 中短期链路：浅/中/深三层分层

按用户对品类的认知深度分三层，Meta/TikTok 与 Google 受众策略完全不同：

| 层级 | Meta/TikTok 受众 | Google 受众 | 核心逻辑 |
|------|------------------|-------------|----------|
| **浅层** | 兴趣定向：bottle feeding、newborn care、baby essentials、母婴博主；年龄 25-40；排除已购清洗机用户 | 通用词："baby bottle cleaner"、"bottle sterilizer"、"how to clean baby bottles" | 还在手动洗奶瓶，不知道有全自动解决方案——教育需求 |
| **中层** | 自定义受众：30 天访问清洗机产品页≥1 次未购；30 天浏览婴儿喂养/护理品类≥3 次；LAL 1-3%（基于清洗机购买用户） | 品类词+品牌词："bottle washer machine"、"best bottle sterilizer 2026"、"momcozy bottle washer"、"baby brezza vs momcozy" | 已意识到需求，主动搜索对比——种草+对比需求 |
| **深层** | 自定义受众：14 天加购未购、7 天访问清洗机页≥3 次、看过评价/退换政策；30 天购买过吸奶器/奶瓶等喂养品类 | 再营销：30 天访问清洗机页未购；Shopping 再营销；品牌词精准匹配 | 决策临门一脚，需要优惠/信任消除最后顾虑——促单需求 |

**分层规律** `[推断]`：浅层=兴趣定向+通用词（大盘教育），中层=行为信号定制受众+品类/品牌词（主动考虑），深层=高意向行为+再营销（临门促单）。兴趣→行为→再营销的信号强度递进。

### 3. 全周期链路：四阶段受众策略

| 用户生命周期 | Meta/TikTok 受众 | Google 受众 | 核心逻辑与营销目标 |
|--------------|------------------|-------------|---------------------|
| **孕早期** | 兴趣：怀孕宣布、孕期瑜伽、孕妇装、孕期营养补充剂；25-40 女性；人生大事（近期结婚/怀孕） | 信息检索词："pregnancy timeline"、"early pregnancy symptoms"、"first time mom tips" | 刚怀孕只关注自身变化，未考虑奶瓶清洗。**不以转化为核心**，科普内容种草、沉淀 Pixel 数据、拉入品牌受众池 |
| **孕晚期（备产囤货）** | 兴趣：Baby shower、Baby registry、待产包、婴儿房布置、母婴大件品牌；自定义：90 天互动过孕早期素材的再营销 | 品类与清单词："baby registry must haves 2026"、"bottle sterilizer vs boiling"、"newborn essentials" | 筑巢期疯狂做攻略集中采购。意识到清洗需求但痛点不深，打"预防针"：强调"待产包必入神器"、"为产后节省睡眠时间" |
| **产后 0-6 月（痛点爆发）** | 兴趣：母乳喂养、吸奶、纯吸奶、新生儿护理、配方奶粉；自定义：已购品牌吸奶器/温奶器（高转化交叉销售）、30 天访问清洗机页待产用户；LAL 基于高价值清洗机买家 1-3% | 精准品类/品牌词："baby bottle washer machine"、"how to clean breast pump parts fast"、"momcozy vs baby brezza bottle washer"；购物广告高竞价抢底部流量 | 痛点顶峰：睡眠剥夺，每天水槽手洗十几次奶瓶配件。**不再教育**，直接抛解决方案+对比+限时优惠，冲动+刚需购买 |
| **产后 6 月+（辅食期长尾）** | 兴趣：婴儿辅食、断奶、吸管杯；自定义：180 天互动未转化受众 | 长尾场景词："how to sterilize baby pacifiers/sippy cups"、"dishwasher vs baby bottle washer" | 奶瓶使用量下降但增加辅食碗/吸管杯/安抚奶嘴清洗需求。强调多功能性和长效价值，收割观望的晚期用户 |

### 4. 素材-层级匹配

| 层级 | 核心目标 | 素材类型 | 具体内容 |
|------|----------|----------|----------|
| 浅层 | 唤醒痛点+给出存在解决方案 | 对比视频 | 前：深夜手洗奶瓶腰酸水溅耗时；后：清洗机拯救妈妈，更多陪孩子休息时间 |
| | | 痛点图文 | 数字冲击："8 bottles a day × 5 min = 40 min/day → 29,200 min/year"，配堆满奶瓶的水槽图 |
| | | 红人口播 | 真实妈妈"我前 3 个月都手洗，直到老公买了这个，后悔没早买"——用"后悔没早买"制造 FOMO |
| 中层 | 卖点教育（证明"真能洗干净+值得买"） | 功能演示 | 360°喷淋→高温蒸汽消毒→热风烘干一镜到底；洗完奶瓶干净透亮 |
| | | 信任背书 | 医用级 316 不锈钢内胆、食品级材质、消毒率 99.99%、认证标志；"儿科医生推荐"类话术 |
| | | 对比图 | 三列对比：手洗（费时/有死角）vs 蒸锅消毒（麻烦/不能洗）vs Momcozy（一键三合一）；或与竞品比价格/容量/功能 |
| 转化 | 促单转化 | 限时折扣 | 倒计时+使用场景，"本周优惠"/"限时免邮" |
| | | 套装优惠 | 清洗机+专用清洁片/奶瓶刷/储奶瓶 bundle，"套装省 $X" |
| | | 评价合集 | 3-5 条真实妈妈评价截图+星级+前后对比（水槽从堆满到空） |

### 5. 多产品生命周期承接

品类矩阵按生命周期分工，一个阶段一个核心承接产品，阶段间用户流动：

| 生命周期 | 用户核心痛点与状态 | 阶段目标 | 承核心产品 | 人群标签要点 |
|----------|-------------------|----------|------------|--------------|
| **孕早期** | 关注自身孕期不适与睡眠质量，对产后喂养无概念 | 通过孕早期产品锁定用户，建立初期信任、扩大种子流量入口 | 孕妇枕、托腹带、瑜伽球、防妊娠纹霜 | 兴趣：怀孕宣布/孕期瑜伽/孕妇装/营养补充剂；人生大事受众 |
| **孕晚期** | 筑巢期集中采购，关注效率和实用性 | 抢占"待产包"核心心智，潜在需求提前转化为备产订单 | 吸奶器、哺乳内衣、待产包 | 兴趣：Baby shower/registry/婴儿房布置；搜索"best breast pump 2026"、"newborn essentials checklist"；90 天浏览孕早期产品用户 |
| **产后 0-6 月** | 高频喂养、睡眠剥夺；吸奶器配件损耗需除垢 | 直击"解放双手与缓解焦虑"，主推刚需家电（清洗机/监视器），耗材补充提升复购 | 清洗机、吸奶器、监视器 | 兴趣：母乳喂养/纯吸奶/新生儿护理/婴儿睡眠；180 天浏览孕期产品用户；LAL 1-3% |
| **产后 6 月+** | 宝宝引入辅食，母乳减少，需要外出水杯和辅食工具 | 延长 LTV，完成"新生儿居家喂养"→"大宝宝辅食与户外出行"场景跨越 | 早期所有喂养产品：推车、辅食机 | 兴趣：婴儿辅食/里程碑/户外亲子；搜索"best baby stroller for travel"、"how to start solid foods"；180 天前购孕晚期/产后初期产品的历史老客 |

### 6. 测试计划（三组自定义人群）

| 测试组 | 自定义人群定义 | 承接产品 |
|--------|---------------|----------|
| **过去孕早期已购人群** | 180 天加购/已购孕妇枕、托腹带、瑜伽球、防妊娠纹霜；类似受众 1-3%；180 天浏览孕早期产品>3 次 | 吸奶器、哺乳内衣、清洗机、监视器 |
| **产后 0-6 月已购人群 1（吸奶器/哺乳内衣）** | 30-90 天购买过吸奶器；高意向未购（30 天加购未购/浏览>3 次）；180 天吸奶器高净值购买用户 1-3% LAL | 清洗机、监视器等 |
| **产后 0-6 月已购人群 2（清洗机）** | 30-90 天购买过清洗机；高意向未购（同上口径）；180 天清洗机购买用户 1-3% LAL（此类人群消费能力较强） | 吸奶器、监视器、辅食机、推车 |

## 高频问答索引

- **Q：浅/中/深三层分别投什么受众和关键词？** → 见 §2 表格。浅层兴趣定向+通用词、中层行为定制受众+品类品牌词、深层高意向行为+再营销。
- **Q：孕早期为什么不投清洗机？** → 用户刚怀孕只关注自身变化，清洗机需求未觉醒。此阶段目标是种草+沉淀 Pixel 数据+拉入品牌受众池，为后续承接蓄水（§3）。
- **Q：产后 0-6 月为什么可以直接转化？** → 痛点顶峰（睡眠剥夺+每天手洗十几次），不再需要教育，直接抛解决方案+对比+限时优惠（§3）。
- **Q：素材怎么匹配投放层级？** → 浅层唤醒痛点（对比视频/数字冲击/红人 FOMO）、中层卖点教育（功能演示/信任背书/对比图）、转化层促单（限时/套装/评价合集）（§4）。
- **Q：多产品矩阵下各阶段卖什么？** → 孕早期卖孕期品（枕/托腹带）→孕晚期卖备产品（吸奶器/内衣/待产包）→产后卖刚需家电（清洗机/监视器）→辅食期卖场景扩展（推车/辅食机）（§5）。
- **Q：已购人群怎么交叉销售？** → 三组测试：孕早已购→孕晚品、吸奶器已购→清洗机/监视器、清洗机已购→吸奶器/辅食机/推车（§6）。
