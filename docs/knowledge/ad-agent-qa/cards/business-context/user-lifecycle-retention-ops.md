# 用户生命周期与留存运营 · 五阶段模型、流失阈值、自动化序列与 EDM/社群体系

## 核心问题

付费流量买回来的用户怎么不浪费？复购率上不去怎么破？EDM 自动化、私域社群、RFM 分层、忠诚度计划怎么搭？本卡蒸馏 CBE `user-lifecycle-ops`（1056 行）——**流量承接层**：获客成本持续攀升的今天，留存即增长。KB 此前只有「怎么买流量」，没有「怎么把流量变成可运营用户资产」。

## 系统解答

### 1. 来源与口径

- **来源**：`github.com/noique/cross-border-ecommerce-skills` → `brand-strategy/user-lifecycle-ops.md`（CC BY-NC 4.0，`raw/s22-cbe-skills/`）。方法论归属：王治国（神策）生命周期分层 × Simon（EcoFlow）AICPL 旅程 × 刘帅（MambaSMS）EDM 体系 × 私域社群复购方法论。
- **口径翻译**：源文面向跨境 DTC 全域。**Momcozy 适配**：快消耗材（吸奶器/母婴用品）复购周期短→天然适配订阅制+补货提醒；美国市场→EDM+SMS 为主，WhatsApp/LINE 不适用（东南亚市场才用）；母婴人群决策链长→Welcome Flow 教育内容权重应上调。

### 2. 五阶段生命周期模型（数据定义先行）

| 阶段 | 数据定义 | 典型行为 | 运营目标 |
|---|---|---|---|
| Stage 0 前客 Prospects | 访问未注册/购买 | 浏览/加购未转化 | 转化首购 |
| Stage 1 新客 | 首购 0-30 天 | 体验期 | 建立认知推动二购 |
| Stage 2 成长期 | 2-3 次购买，30-180 天 | 尝试多 SKU | 扩大钱包份额 |
| Stage 3 成熟期 | 4+ 次购买，LTV>均值 | 主动推荐/高频互动 | 维护+激发裂变 |
| Stage 4 衰退/流失 | 超 X 天无购买 | 互动减少/退订增加 | 挽回或优雅告别 |

**流失阈值 = 复购周期倍数，不是拍脑袋**：留存曲线拐点法（陡降后平缓拐点=预警阈值）；行业基准——快消品（美妆/食品/保健品）复购周期 30-60 天，预警=1.5×周期、正式流失=2×、深度流失=4×；半耐用品 60-120 天（2.5×）；订阅制看到期未续。**Momcozy 耗材：若复购周期 ~60 天→预警 90 天、流失 150 天**。

**成熟期识别是加权评分不是单看频次**：购买频次（4+次/360天，30%）+ LTV>均值1.5×（25%）+ 品类宽度 2+（15%）+ 互动深度（邮件打开>30%点击>5%，15%）+ 推荐行为（15%）。分级：Super VIP 前1% LTV / VIP 前5% / Loyal 前15%。

**衰退检测五信号交叉验证**：复购间隔>1.5×历史均值（周检）/ 连续3封邮件未打开 / 30天0访问（月检）/ 退货率>品类均值2× / 任何退订（实时）。

### 3. AICPL 旅程：70% 品牌忽略的上层

A 认知（我为什么需要）→ I 了解（有哪些选择）→ C 对比（为什么选你）→ P 下单（哪里买划算）→ L 复购（还有什么值得买）。大多数品牌只做 C-P 段——**A-I 段是场景化教育/品类教育/评测对比内容**，恰是 GEO/内容卡的用武之地。各阶段配套着陆页类型与转化目标不同（教育型页→订阅、指南型页→下载、对比页→信任背书）。

### 4. 渠道触达矩阵与弹窗

| 渠道 | 触达率 | 打开率基准 | 成本 | 最佳场景 |
|---|---|---|---|---|
| EDM | 95%+ | 15-25% | 极低 | 教育/促销/生命周期主力 |
| SMS | 98%+ | 90%+ | 中 | 紧急/限时/购物车挽回 |
| Web Push | 变化大 | 5-15% | 极低 | 实时提醒 |
| WhatsApp | 98%+ | 85%+ | 中-高 | 东南亚客服/对话式 |
| App Push | 60-80% | 3-10% | 极低 | 应用内行为 |

**弹窗是价值交换不是干扰**（优化后订阅率+30-40%）：6 类型转化率基准——首访欢迎 3-8%、退出意图 5-12%、购物车 8-15%、滚动 4-10%；多步骤弹窗（先问「为谁挑」→「最关心什么」→再要邮箱）提升数据质量 30-40%；移动端不遮全屏（Google 处罚风险）、已订阅者不再弹。

### 5. 核心自动化序列

**35 天 Welcome Flow = 全体系 ROI 最高序列**（12 节拍）：Day0 欢迎+优惠码（打开>50%）→ Day1 品牌故事 → Day3 社会证明 → Day5 教育 → Day7 场景种草 → Day10 卖点 → Day14 痛点方案 → Day18 用户故事 → Day21 个性化推荐 → Day25 专属优惠 → Day28 到期提醒 → Day35 分流（已购→Post-Purchase / 有互动→培育 / 零互动→休眠月更）。分支逻辑：期间购买即退出 Welcome 流、加购插 Cart Abandonment、未互动降频延隔。

**六大标准序列要点**：
- **Browse Abandonment**：浏览>30秒未加购→1h Web Push→24h EDM→72h EDM+激励（回访 8-15%/5-10%/转化 2-4%）
- **Cart Abandonment**：加购→1h EDM 无折扣→24h EDM+SMS 社会证明→48h 5-10%折扣→72h 最大折扣。**铁律：第一封绝不给折扣**——否则训练用户「放弃=拿折扣」
- **Post-Purchase**：确认→发货→送达指南→+3天使用教程→+7天 NPS/评价→+14天交叉推荐→复购周期前补货提醒
- **Win-back**：预警阈值触发「想念你」无折扣→7天调研+10%→14天 15%→30天 20%+赠品→60天标记流失停止触达
- **VIP Exclusive**：分层欢迎/新品提前48h/生日/季度报告/大事件专属
- **Referral**：NPS 9-10 触发推荐计划、好评用户、社媒分享、3+次购买升级奖励——双向奖励设计

### 6. EDM 基础设施与合规

**三支柱**：域名信誉（SPF/DKIM/DMARC 配置验证，DMARC 从 p=none 起步）/ IP 信誉（**新 IP 预热 30 天表**：Day1-3 50-100 封→Day30+ 全量；失败=域名永久拉黑，头号崩溃原因）/ 发送实践 SOP。

**发送频率按活跃度分层**：高活跃（30天互动）每周 2-3 封、内容 60% 价值+40% 促销；中活跃每周 1-2 封；低活跃每周 0.5-1 封；不活跃每月 1 封。**列表卫生**：硬退信即清、软退信连3次清、180 天无互动→Sunset 列表、半年全量清洗（ZeroBounce）、投诉率>0.1% 暂停。

**合规罚则**：CAN-SPAM（美国，$16,000/封——物理地址+退订链接+10 天内处理）/ GDPR（欧盟，营收 4% 或 €20M）/ CASL（加拿大 $10M）/ LGPD（巴西 2%）。必备：同意记录（timestamp+IP+consent text）、退订即时处理、主题行不欺骗。

### 7. 社群私域：公域→私域转化漏斗

平台决策树：日本→LINE 必选；18-30→Discord/IG；25-45→FB Group+WhatsApp；35+→FB Group。**Momcozy 美国市场=Facebook Group 为主**。

**0→5000 三阶段**：种子期 0-500 人 4-8 周（购后邮件/包裹卡片/客服引导，转化 5-20%）→ 成长期 500-5000 人 3-6 月（日更内容+周主题+月活动，UGC 收集）→ 成熟期 5000+（80% UGC+20% 官方、月活>30%、社群收入占比>15%、月自然增长>10%）。

**转化漏斗各层基准**：公域→半私域 3-5% → 社群 0.5-1% → 核心私域（WhatsApp 1对1/VIP群）0.05-0.1% → 品牌大使 0.01-0.03%。内容矩阵：教育 30%/UGC 25%/互动 20%/品牌动态 15%/专属优惠 10%。

### 8. RFM 分层与指标

RFM 评分（R:7天/30天/90天/180天+，F:10+/6-9/3-5/2/1 次每年，M:金额分位）→ 8 分群策略映射：重要价值（555）VIP+裂变 / 重要发展 提频 / 重要保持 紧急挽回 / 重要挽留 高价值 offer / 一般价值 提客单 / 一般发展 培育 / 一般保持 低成本挽回 / 流失 清洗。**<200K 用户用行为触发分层（3-5 群），>200K 才上 RFM**——小列表过度分层统计无意义。

**一级指标**：留存率 20-40% / 复购率 20-35% / LTV:CAC>3:1 / 邮件列表增长 2-5%/月 / 社群活跃 20-40%。**二级预警**：打开率<12%、点击率<1.5%、退订率>0.8%、购物车恢复<3%、Welcome 转化<3%。Cohort 按获客渠道/首购品类/首购金额/地区切片复盘。

## 高频问答索引

- **Q：流失阈值怎么定？** A：复购周期倍数——快消品预警=1.5×周期、流失=2×、深度=4×；留存曲线拐点法校准。Momcozy 耗材 60 天周期→预警 90 天。
- **Q：购物车挽回第一封能给折扣吗？** A：不能。1h 先提醒无折扣→24h 社会证明→48h 才 5-10%→72h 最大折扣。先折扣=训练用户放弃等折扣。
- **Q：新 IP 发邮件为什么危险？** A：IP 预热失败是 EDM 崩溃头号原因——30 天阶梯预热（50-100封起步），急发大量=域名永久拉黑。
- **Q：标签系统越多越好吗？** A：500+ 低利用率标签反而拖累运营——精简到 50-100 个核心标签，每个必须映射明确运营动作，月度审计使用率。
- **Q：社群从 0 怎么起？** A：种子期 4-8 周冲 500 人（购后邮件/包裹卡/客服引导），成长期日更+周主题+月活动，成熟期 80% UGC。
