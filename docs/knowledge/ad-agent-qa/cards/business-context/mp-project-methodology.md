# MP 项目管理方法论（投放需求→可复盘交付全链路）

## 核心问题

上游投放需求或内部专题复盘怎么变成一次**可交付、可复盘、可沉淀**的方法论输出？MP（Marketing Plan）在全链路中起什么作用？哪些环节已识别为 AI 系统化机会？

## 系统解答

### 1. 文档定位

S1 附件两份 PDF：《立项阶段动作梳理》（正文，1255 词）+《DTC 广告优化师投放工作流程图》（流程骨架图）。目的：把「上游/内部投放需求」或「专题复盘」变成可交付、可复盘、可沉淀的方法论输出。**本卡部分回填 S14 调研框架中被权限墙挡住的 MP 环节知识** `[推断]`。

### 2. 两类触发与主流程

**两类触发（显式区分）**：

- **A 类 · 投放需求驱动**：投放需求清单/Brief →（必要时预研/方案论证）→ 项目 MP 执行 → 项目复盘/洞察报告。关键输入 = 原始 Brief（需求合同/成功标准/边界）+ 项目 MP（执行版/变更记录）+ 过程数据 + 动作留痕 + 素材/落地页版本变更。
- **B 类 · 专题复盘**：围绕一个专题做一次性分析/总结/验证，沉淀可复用打法（复盘不伴随新投放任务）。需补「迷你 Brief」：目标/范围/口径/资源/交付物 + 可用历史数据。

**主流程（DTC 工作流程图骨架）**：

```
投放需求清单/Brief（上游/内部：DTC/品牌/用户运营/测试需求）
  → 复杂度评估（过高→需求澄清/前置评估/预研方案论证）
  → 广告 MP / 策略制定 ──迭代优化模板──┐
  → 广告新建 / 上线 ──重建/复制/上新──┤
  → 广告调节优化 ←── 异常/机会触发 ←─ 日常看数/监控
  → 验证效果 → 周期性复盘（日/周/月/季度）→ 项目复盘/洞察报告
```

循环节奏：日常循环 T+1–T+7、周期循环周/月/季度、项目循环按项目周期。横切底座四件套贯穿全程（§3）。

### 3. 横切底座：0.x 四件套

| 编号 | 底座 | 核心内容 |
|------|------|----------|
| **0.1** | 统一标签/命名/项目ID（含费用归属） | 业务标签（国家/品线/场景/策略）+财务归属标签（承担部门/预算上限/生效期）；命名规范至少能解析国家/品线/项目/漏斗层级/关键策略；项目ID 在 MP/投放对象/报表/复盘一键追溯。交付物：标签字典+命名规范+项目ID规则（版本化） |
| **0.2** | 追踪与事件合同/归因口径/数据质量 | 事件合同（触发条件/必要参数/去重键/验收方式，版本化）；归因口径（时间窗/数据源优先级/例外）；数据质量检查项（事件断流/重复计数/币种金额异常/UTM 缺失/关键参数缺失）。多数据源对照：广告端 vs GA4 vs Shopify vs UTM 视角 |
| **0.3** | 资产库（素材/受众/落地页：版本+回流） | 素材（版本号/角度标签/形式/合规状态/适用场景+投后表现回流可对上广告ID）；受众（来源/更新时间/适用范围/排除关系/可否模板化）；落地页与 Offer（URL/页面类型/促销信息/关键变更时间点）。对象级变更日志：谁改了什么、什么时候、改完发生什么 |
| **0.4** | 权限与审计（Log 系统） | 广告对象级审计日志与变更追踪，可查询/可导出/可引用到复盘；高危操作预警（二次验证或 AI 熔断）；上线前广告合法性核验（AI 语义化检验，利用可变规则+固定规则判定 MP/投放受众/素材/URL 信息是否一一对应、有无非法因素） |

**作用**：Brief→MP→投放对象→报表/复盘用同一套「可追溯主键」串联，支持按国家/品线/项目/场景聚合与费用归属。

### 4. 阶段详解

**① 广告 MP / 策略制定**
- 输入：上游投放需求清单（背景/目标KPI/投放范围/目标事件/节奏周期/可用资源/约束）+ 时间节奏日历
- 关键动作：定节奏（蓄水/预热/正式/返场打法与资源重点）→ 定预算拆分与 pacing（放量/控量规则+应急预案）→ 定人群策略（核心/扩量/再营销/排除，避免重叠污染，人群包=资产注明来源/更新时间/适用范围）→ 定素材策略（素材清单：角度/卖点/形式/更新频率/淘汰阈值）→ 定测量计划（口径/看板维度/告警规则/复盘维度）→ 定广告结构蓝图（哪些 Campaign/Adset/Ad 承载哪些策略：规模盘 vs 测试盘、顶/中/底层漏斗角色、品牌词保护/类目词收割/再营销）
- 交付物：MP 版本文档（目标+节奏+预算拆分+结构模板+资源清单+KPI/阈值），版本与变更可追溯至广告 ID

**② 广告新建 / 上线**
- 按 MP 搭建广告结构（显式标注漏斗层级/策略）；裂变式批量自动化搭建：笛卡尔积（如 3 人群×5 素材=15 个广告组合对象）+ 固定层级结构模式（"1-3-3 测素材"/"1-1-1 测受众"/ASC+ 自动，可自定义 x-x-x）
- 资产组装：受众模板组合化直接选取；历史文案/素材按产品+URL 检索引用
- 绑定落地页与追踪信息（UTM 齐全/URL 正确/优化事件正确）；Preflight 上线前校验（命名/标签合规、缺失项/高风险项）
- AB Test：测试组对象管理，控制变量规则，自动化补位测试（固定预算下批量测素材/人群/文案，旧组迭代需更替红线）；可选 MAB 测试模式；高危操作需审批+人工多次核验（大促放量预算变动大/结构大改/高风险素材）

**③ 广告调节优化**
- 看数逻辑固定：先看大盘（消耗进度/转化/核心 KPI 是否可接受→决定是否紧急处理）→ 再下钻（层级/系列/组/人群/素材/产品贡献或掉量）→ 素材与人群维度控制变量分析（素材疲劳信号：频次升 CTR 降 CVR 降；人群 CPM/CPC/CVR 与历史及 MP 目标对比）
- 异常归类：预算/广告策略/素材/追踪/站内承接/其他外部变量 → 形成异常清单/机会清单（动作建议+验证时间点 T+1/T+3/周）
- 动作铁律：人群排除一致执行避免重叠污染；AB Test 明确对照组与变量；动作留痕（改了什么/为什么/预期验证窗口/结果）；测试类强制记录实验 ID 与结论；结构错配或学习受限严重时执行复制/重建/拆分合并
- AI 自动化：广告调节动作快照化（记录动作时所有指标状态+AI 语义化留痕）；accept edits on 模式允许 AI 在选定广告对象上自动优化；高危操作预警/AI 熔断

**④ 投放资产**
- 素材/文案/卖点原子化、组合化、模板化——建广告时「引用资产」而非「重复配置」
- 投放资产复用：产品使用过的文案与素材资产信息自动配置；多模态素材理解自动将素材信息打标至对应广告对象；广告素材系统与内容中台互通、一键多渠道分发
- AIGC 生产广告资产（图片/视频/文案），利用广告系统上下文

**⑤ 周期性复盘 / 素材复盘**
- 复盘链路：定题与范围界定（类型/范围/交付对象/评价维度：目标达成+pacing+驱动拆解+数据可信度+沉淀回灌）→ 建立复盘基线（原始 Brief=需求合同基线、执行版 MP 含变更记录=实际打法基线、外部变量清单、资产版本）→ 拉数&口径校验 → 拆结果（目标 vs 实际/分阶段/分渠道漏斗/分层拆解）→ 拆过程（关键动作时间线/转折点/动作→指标→原因）→ 归因洞察 → 交付 → 回灌沉淀
- 交付物：日报/周报要点（机会点/达标/异常→原因→动作→验证窗口）；复盘报告（结论/可复制打法/风险清单/下一周期动作建议/素材需求清单）+ 结论资产化
- 素材复盘：按素材角度/形式/生命周期总结有效与无效原因，产出下一批素材需求清单；淘汰低效/疲劳素材、换角度换形式解决「看不懂/不信任/不想买」

**⑥ 项目类、长周期洞察报告**
- 对上游投放或复盘需求/项目投放情况的评估与复盘；项目进行时产出的日报/周报等前置复盘文档二次利用
- 归因框架：可控项（广告结构/人群/素材/节奏/操作质量）/ 半可控项（站内承接：支付/运费/页面性能/优惠表达）/ 不可控项（外部流量/竞品/政策/库存）；数据指向承接问题时触发站内排查与协同

### 5. 系统化机会清单（文档识别的 AI/自动化方向）

| 环节 | 系统化机会 |
|------|-----------|
| MP 制定 | MP 模板化+版本化与广告 ID Mapping；历史 MP 向量知识库化（RAG 检索+对当前 MP 诊断）；KPI 达成概率预测与变量敏感性分析；Pacing 预算节奏曲线预设与生成；Brief 信息 AI 语义提取 |
| 咨询/分析 | Ad-hoc AI 咨询助手（Agent+Text-to-SQL+RAG，多轮探索）；上游投放/复盘需求单管理（登记→澄清→排期→交付→复盘）；复盘模板版本化+结论原子化索引 |
| 看数报表 | 自定义报表生成（自然语言取数意图→SQL→定时更新）；广告外归因（竞品/运营动作纳入「生意全盘归因」，时间轴标记外部事件）；AI 生成自然语言日报（LLM 读数据+操作日志出 Draft Report）；异常警报（账户余额等）；异常/机会清单效果自动跟踪（PDCA）；多维归因树（ROAS 拆 CPM/CPC/CVR）；预算进度看板；流量类型分层展现（顶/中/底层漏斗标注+分层质量指标） |
| 广告搭建 | 裂变式批量自动化搭建（笛卡尔积）；AB 测试组系统化管理（可选 MAB）；投放实验全生命周期管理（状态接管/自动裁决/语义化结论留痕）；热补丁实验（调节阶段新增测试组+更替红线） |
| 调节优化 | 预设调节规则+AI 分析给建议+accept edits on 自动执行；动作留痕自动化（快照+语义化）；高危操作预警/AI 熔断；广告对象级审计日志 |
| 资产 | 素材系统与内容中台互通；受众管理系统（媒介渠道人群+CDP 人群综合管理）；再营销人群时间窗信息；原子化/组合化/模板化资产库 |
| 复盘 | 全链路数据对账时间轴报告（MP 数据+测试组+优化日志+外部事件自动聚合叙事）；元素级广告数据归因（素材角度/文案/卖点/人群维度交叉分析）；资产数据自动化回传素材系统；MP 校准/知识库校准；语义化结论入库（向量库，避免噪音）；复盘文档模板占位（自动拉数填骨架） |
| 项目管理 | 项目对象模型管理（500 Campaign+40 落地页+1 MP 文档+复盘文档挂同一 Project ID，含「11月1日-11月30日」时间轴动作 LOG） |

## 高频问答索引

- **Q：投放需求怎么进入系统？** → A 类走完整链路（Brief→澄清/预研→MP→上线→调节→复盘），B 类专题复盘需先补「迷你 Brief」（§2）。
- **Q：MP 文档必须包含什么？** → 目标+节奏+预算拆分+结构模板+资源清单+KPI/阈值，版本化且可追溯至广告 ID（§4①）。
- **Q：怎么保证复盘时能解释「为什么中途改了」？** → 执行版 MP 含变更记录作为实际打法基线+对象级变更日志+动作留痕（§3 0.3/0.4、§4⑤）。
- **Q：广告新建怎么批量化又不失控？** → 笛卡尔积裂变+固定层级结构模板（1-3-3 测素材等）+Preflight 校验+高危操作审批/AI 熔断（§4②）。
- **Q：AB Test 怎么系统化管理？** → 测试组对象+控制变量规则+自动化补位（固定预算依次新建，旧组迭代需更替红线）+可选 MAB 自动裁决（§4②）。
- **Q：看数的固定顺序是什么？** → 先大盘（是否需紧急处理）→下钻（谁在贡献/掉量）→素材疲劳信号+人群指标对比→异常归类（预算/策略/素材/追踪/站内承接/外部）（§4③）。
- **Q：哪些数据口径问题会让复盘失真？** → 事件断流/重复计数/币种金额异常/UTM 缺失/关键参数缺失；多源对照广告端 vs GA4 vs Shopify vs UTM 末次/多归因（§3 0.2）。
- **Q：文档识别的 AI 机会最多在哪？** → MP 模板化+RAG、Ad-hoc 咨询（Text-to-SQL）、自定义报表、裂变式搭建、accept edits 自动调节、全链路时间轴报告、元素级归因、语义化结论入库（§5）。
