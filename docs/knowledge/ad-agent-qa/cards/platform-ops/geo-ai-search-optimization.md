# GEO / AI 搜索优化 · 质量模型、意图体系、监测归因与 30/60/90 落地

## 核心问题

用户不再只搜 Google——越来越多决策问题直接问 ChatGPT/Perplexity/Gemini，AI 给出带引用的答案。**GEO（Generative Engine Optimization）= 让品牌和产品在 AI 答案中被准确提及、引用、推荐**。本卡蒸馏 wepr-growth-skills 的 GEO 套件（15 个专项 skill），是 KB 在「AI 搜索流量入口」域的第一张深度卡——此前只有 S28 落的 AEO/GEO 概念节点。

## 系统解答

### 1. 来源与口径

- **来源**：`github.com/ShenyuanNext/wepr-growth-skills`（MIT，`raw/s29-wepr-geo/`）。蒸馏自 `wepr-geo-suite`（编排契约）、`panorama-audit`（诊断）、`intent-miner`（意图）、`page-blueprint`/`content-refiner`（生产）、`effect-monitor`（监测）、`tracking`（归因）、`execution-roadmap`（落地）、`knowledge-base-builder`/`citation-lab`（证据底座）。
- **口径翻译**：源文面向国内市场（DeepSeek/豆包/千问/Kimi/元宝 + 企微/口令/问卷承接）。**Momcozy 是 US DTC，主战场是海外平台 ChatGPT/Gemini/Perplexity**——承接方式映射为：专属落地页 UTM、表单 hidden field、post-purchase 自报来源、品牌词搜索趋势。国内平台机制仅作对照保留。
- **与既有卡分工**：SEO 管「关键词排名」，GEO 管「AI 答案提及/引用/推荐」——互补不替代；归因方法论与 `attribution-measurement`（S22）三角框架同族，本卡补「AI 引荐」这个新渠道的可观测性边界。

### 2. GEO 质量模型（8 维 × 1-5 分）

对任一页面/内容资产打分，**每项必须给证据或扣分原因**：

| 维度 | 高分表现 | 低分信号 |
|---|---|---|
| 语义密度 | 实体/事实/关系/场景/数值密集不堆词 | 空泛形容词多、主体不明 |
| 结构规范性 | 答案优先、模块清晰、可快速抽取 | 大段软文、结论埋后面 |
| 可引用性 | 关键事实可追溯、引用区清楚、有日期 | 无来源/无日期/模糊代词 |
| 权威信号 | 官方信息、资质、客户案例可核验 | 只有营销口号 |
| 可读性 | 术语有解释、句段节奏好 | 概念混乱 |
| 鲁棒性 | 同义/口语/长尾改写后仍能找到答案 | 只覆盖单一关键词表达 |
| 新颖性 | 有具体场景/方法/数据/观点 | 同质化模板堆砌 |
| 跨域贡献 | 能支持多跳问题和场景推荐 | 只停留在品牌自述 |

**判定规则**：任一维 <3 → 进修复清单；平均 <4 → 不建议投放或大规模内容扩张；**反幻觉是红线不是评分项**——虚构数据/客户/引用直接判不通过。评分前先过 7 个观测项：官网覆盖、实体清晰、断言可抽取、来源支持、事实准确、问题覆盖、外部背书。

### 3. 全景诊断：12 域 + 三级核验 + 证据分级

**12 个必查诊断域**（不能只看「官网有什么页面」）：官网抓取覆盖 / 品牌实体消歧（同名品牌！）/ 产品服务模型 / 价格商业口径 / 客户案例证据（授权状态）/ 内容深度（9 类用户问题覆盖矩阵）/ 技术可抓取性（robots/sitemap/JS渲染/PDF文本化）/ 结构化数据（Organization/Product/FAQ/CaseStudy Schema）/ 权威与信任信号 / 竞品替代对标 / 站外证据生态（媒体/百科/社区/行业报告）/ 风险与假设台账。

**断言核验三级**：①官网页内一致 → ②官方多源一致（帮助文档/新闻稿/投资者页）→ ③第三方佐证（媒体/百科/行业报告）。冲突必须写「采用口径+冲突来源+待确认动作」。

**证据成熟度分级**：A 官方已证实 / B 第三方可佐证 / C 品牌自述待佐证 / D 需补证（进 pending 区）/ E 禁止使用（未授权客户名/未公开数据/虚构指标）。

### 4. 意图挖掘体系

- **双层意图**：任务层 3 类（信息/导航验证/交易行动）× GEO 操作层 9 类（信息/推荐/比较/交易/风险/价格/替代/场景/品牌验证）。
- **五段式查询重写**：`user_question`（保留口语）→ `standalone_rewrite`（追问改独立问题）→ `retrieval_rewrite`（平台可能检索的短语）→ `evidence_query`（找案例/价格/资质用）→ `title_seed`（选题输入）。
- **追问链路**：每条 follow-up 带 `root_question_id/parent_question_id/context_dependency/platform_fit`——AI 搜索是多轮的，词库要覆盖追问不是只覆盖首问。
- **十维评分**：商业价值、AI 答案触发概率、内容缺口、品牌植入空间、证据可得性、竞争难度、对话延展、决策阶段、平台覆盖、合规风险。
- **纪律**：机械槽位组合只做召回池；正式词库必须过语义质检（去重同义、竞品问题中性表达、保留最口语最具体的展示问法）。

### 5. 页面与内容生产要点

- **页面蓝图模块序**：首屏直接答案 → 结构化摘要 → 核心事实卡 → 判断框架 → 对比表 → 实体关系 → 证据区 → FAQ → 案例 → 来源 → 转化 CTA（**CTA 不得干扰答案和证据区**）。
- **AI 可抽取设计**：键值对、表格、步骤、原子事实、实体关系、`@id` Schema 连接——让答案片段可被整段抽走而不丢上下文。
- **内容改造（refiner）**：先按 8 维给原文打分 → 提取原子事实卡（主体/属性/数值/时间/来源/边界/核验状态）→ 补直接回答/摘要/H2-H3/表格/FAQ/步骤/来源 → 删注水和不可核验强断言。**不机械加字数和 FAQ**——研究表明相关性≠因果。
- **query fan-out**：围绕主问题展开定义/对比/风险/价格/替代/实施/案例/FAQ 子问题并映射到页面模块。

### 6. 监测体系（effect-monitor）

- **六层分析模型**：覆盖可见性 / 事实性 / 证据性 / 稳定性 / 竞争性 / 治理归因——不允许只看单维指标。
- **核心指标**：品牌出现率、候选率、推荐率、排序、竞品出现率、负面表述率、描述准确率、事实错误率、引用召回率、引用准确率、答案稳定性。
- **采样分级**（证据等级从高到低）：授权 API/连接器 > 人工真实样本（记录平台/时间/设备/地区/联网状态/Prompt 版本/答案原文/截图）> 浏览器辅助合规采样 > 合成回放（**只能标合成样例，不能标真实采样**）。
- **Prompt 库 7 组**：推荐/比较/替代/价格/风险/品牌验证/场景问法，每组含核心+长尾+对照+追问问法。
- **谨慎归因**：设基线窗口+观察窗口+对照 Prompt+竞品对照；**默认结论是「观察相关」，证据充分才升级置信度**。

### 7. 归因：三层价值与可观测边界（tracking）

- **三层价值**：①品牌层（AI 把品牌作为推荐/引用/对比对象 = 高信任第三方背书，缩短后续成交信任成本）②直接效果（专属承接动作可计量）③间接效果（趋势指标佐证）。
- **直接承接手段**（海外 DTC 版）：GEO 专属落地页+UTM 参数、表单 hidden field（channel_group/ai_platform/keyword_theme）、post-purchase 自报来源问卷、优惠码、AI 专属 CTA。Referer 在 App 内链路经常丢失——口令/问卷/自报是低成本补丁。
- **间接指标**：品牌词检索量、官网/落地页 UV、CTA 点击率、注册/预约/成交率变化、自报 AI 来源占比。间接指标不能单独证明 GEO 贡献，需与关键词主题+页面变化+承接动作一起解释；长决策链成交率滞后于流量线索。
- **可观测性三层**：`Observed`（直接观测）/ `Recoverable`（可部分恢复）/ `Unobservable`（暂不可观测）。**保守规划假设：刚部署监测时可直接观测转化约占总贡献 20-30%**（海外官网承接强可更高，国内多触点更低）——这是规划边界不是普适事实，禁拿固定倍数推总 ROI。

### 8. 落地节奏：30/60/90 + 纠偏闭环

- **30 天快赢**：页面技术修复（robots/Schema/可抽取结构）、事实底座 A/B 级断言补齐、首批监测 Prompt 库、基线采样。
- **60 天资产建设**：知识库/事实卡体系、内容矩阵（对比页/榜单页/FAQ/案例页）、站外证据（媒体/百科/社区背书）。
- **90 天闭环优化**：监测仪表盘、纠偏闭环运转、复盘迭代。
- **纠偏闭环**：错误事实→知识库修订；缺失证据→补采任务；弱页面→页面改造；负面表达→口径修正；引用缺口→站外发布。每个纠偏任务落到负责人+验收口径。
- **北极星指标**至少选 3 项：品牌推荐率 / 被引用率 / 答案准确率 / 核心问题覆盖率 / 证据支持率 / 线索贡献。

### 9. 红线与边界

- 不把 SEO 排名/官网流量/品牌知名度直接等同 GEO 优先级。
- 不把「官网有页面」等同「AI 可准确引用」——要查可抽取的定义/表格/FAQ/来源/更新时间/断言级事实。
- 不把引用链接数量等同可信度——引用必须真实支持对应断言。
- 合成 Prompt/推断竞品/生成示例**不得**表述为真实平台数据。
- 不承诺排名、引用、推荐、线索或营收数字。
- 采样要低频、可见、授权、可审计；不绕过平台限制批量滥采。

## 高频问答索引

- **Q：GEO 和 SEO 有什么区别？**
  A：SEO 管传统搜索排名，GEO 管 AI 答案中的品牌提及/引用/推荐——互补不替代，共享事实底座。
- **Q：GEO 页面质量怎么评？**
  A：8 维 × 1-5 分（语义密度/结构规范/可引用/权威信号/可读性/鲁棒性/新颖性/跨域贡献），任一维 <3 进修复清单，平均 <4 不投放不扩张；反幻觉是红线。
- **Q：全景诊断查哪些域？**
  A：12 个必查域——抓取覆盖/实体消歧/产品服务/价格口径/案例授权/9 类问题覆盖/技术可抓取/结构化数据/权威信任/竞品对标/站外证据/风险台账。
- **Q：意图词库和 SEO 关键词有何不同？**
  A：双层意图（任务 3 类 × GEO 操作 9 类）+ 五段式重写 + 追问链路 + 十维评分；机械组合只做召回池。
- **Q：GEO 转化能归因多少？**
  A：三层价值模型；刚部署监测时可直接观测约占总贡献 20-30%（规划假设非普适事实），默认结论「观察相关」。
