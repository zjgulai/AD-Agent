# Amazon 评论洞察 VOC（6 类痛点分类 + 严重度分级 + 三向反哺）

## 核心问题

差评突然变多怎么办？评论数据怎么变成可执行的产品/Listing/广告改进？1-3 星差评该怎么分类归因？VOC 怎么反哺 Listing 卖点和广告素材？

## 系统解答

### 1. 文档定位

蒸馏自 S23 `review-analysis`（SKILL v7.0 六维框架 + painpoint_taxonomy）。**与 `amazon-keyword-listing-ops` 的 VOC 挖词分工**：那张卡讲「从评论/QA 挖关键词反哺 Listing」；本卡讲「差评深度归因」——把 1-3 星评论按痛点分类→严重度分级→根源方向→三向输出（产品改进/客服话术/Listing 优化）。Momcozy 类目评论洞察的直接方法论。

### 2. 分析对象与流程

**对象**：1-3 星差评（4-5 星好评另作正面词库）。流程：拉取评论数据 → 提取差评 → 按 6 大类别归类 → 统计占比/严重程度 → 输出 Pareto 排名报告。

**6 大痛点类别**（v7.0 新增服务维度）：

| # | 类别 | 覆盖范围 |
|---|------|---------|
| 1 | 结构/组装问题 | 零件破损、密封失效、接口断裂、孔位偏差、组装困难、结构不稳 |
| 2 | 电子模块故障 | USB/充电失效、LED 不亮、APP 连接失败、蓝牙断连、电路问题 |
| 3 | 设计/功能缺陷 | 尺寸不合理、功能缺失、操作复杂、人体工程学问题 |
| 4 | 外观/材质问题 | 异味、材质过敏、色差、划痕、生锈、表面处理差 |
| 5 | 描述不符 | 尺寸预期偏差、功能与描述不符、颜色/款式与图片不一致 |
| 6 | 服务/物流问题 | 客服响应慢、退换货困难、物流延迟、发错货、配件缺失、**收到二手/瑕疵品**、包装破损 |

**服务维度细分**（类 6 内部）：收到二手/瑕疵品=**高**（used/dirty/scratch/opened/previous owner）、配件缺失=**高**、发错货=中、退换货困难=中、客服响应慢/态度差=中、物流延迟/包装差=低。

### 3. 严重度分级

| 程度 | 标准 | 示例 |
|------|------|------|
| 高 | 影响核心功能或安全隐患 | 破损、泄漏、过敏、漏电、装不起来、收到二手品 |
| 中 | 影响使用体验 | 操作复杂、触感不佳、尺寸偏差、发错货 |
| 低 | 外观细节/个人偏好 | 轻微划痕、包装瑕疵 |

### 4. 每个痛点的三向输出

对每个痛点类别必须产出：

1. **根源方向分析**——区分设计问题（公差/电路设计）、生产问题（质检/工艺）、包装问题（配件清单/防护）、供应问题（元件/材料供应商）、软件问题（APP 兼容）
2. **产品/供应链改进方案**——**必须具体可执行**（如「封口宽度从 3mm 增至 6mm」），笼统描述（「提高质量」）不可接受
3. **客服话术 + Listing 优化建议**——客服邮件模板（守 Amazon 合规）+ Listing 文案/图片改进点

### 5. 报告结构（Pareto 化）

```
痛点排名表：类别 | 数量 | 占比 | 严重程度（降序）
每类详情：典型差评引用×2 + 根源分析（设计/生产/包装/供应/软件）
         + 改进建议 + 客服话术 + Listing 建议
```

**反哺闭环**：差评高频主题 → Listing 五点「边界说明」补强（评分细则维度 4/6 的直接数据源）→ 广告素材避开已暴露问题 → QA 板块预埋答案 → 产品开发排期。

### 6. 与广告/Listing 的连接点

- **Listing**：高频负面词必须在页面说明（评分细则维度 6 红线：负面高频未说明且星级<4.0 → 3-4 分以下）；「描述不符」类差评直接指向 Listing 文案/图片失真
- **广告**：差评暴露的真实痛点 = 广告素材的「诚实边界」——投放素材承诺不能超出产品实际能力（否则差评加速）
- **QA**：差评高频问题 = QA 板块必答清单（答案型内容，见 semantic-ops 卡第 8 步）

## 高频问答索引

- **Q：差评怎么分类？**
  A：6 大类——结构/组装、电子模块、设计/功能缺陷、外观/材质、描述不符、服务/物流（v7.0 新增，含收到二手品/配件缺失等细分）。每类再按高/中/低严重度分级。
- **Q：评论分析报告输出什么？**
  A：Pareto 排名表（类别×数量×占比×严重度）+ 每类典型差评引用 + 根源方向（设计/生产/包装/供应/软件）+ 具体可执行改进方案 + 客服话术 + Listing 优化建议。
- **Q：VOC 怎么反哺 Listing？**
  A：高频负面词→五点「边界说明」补强；「描述不符」差评→文案/图片纠偏；差评高频问题→QA 必答清单；高频正面词→强化进 Listing（评分维度 6 的直接依据）。
- **Q：收到「二手品/瑕疵品」差评怎么处理？**
  A：这是服务维度**最高严重度**——不是产品问题是履约问题，优先查仓储/贴标/翻新流程，客服话术按「高危」级响应，Listing/广告素材不受影响但需监控是否批量出现。
- **Q：差评分析和关键词 VOC 挖掘什么关系？**
  A：互补——keyword 卡的 VOC 挖词从评论提取**搜索词**反哺 Listing 关键词；本卡从差评提取**痛点**反哺产品改进+边界说明+QA。一个管「被找到」，一个管「被相信」。
