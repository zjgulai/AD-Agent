# 广告平台「算法自动」优化字段详解（跨平台）

## 核心问题

广告平台后台那些「交给算法自动优化」的字段（预算分配、智能出价、受众扩量、版位分配、关键词扩展、素材组合、创意即定向、动态文案、全托管模式）分别是什么逻辑？各自依赖什么输入、产出什么？在巨量/腾讯/快手/百度/Meta/TikTok/Google 上有什么差异？什么情况下不该放权给算法？

## 系统解答

### 1. 文档定位

HTML 可视化文档（飞书文件 `广告平台算法自动优化字段 逻辑详解.html`，token `KUujbzWhtotHlhxddLuctbwdnjS`），覆盖 7 个平台。每个字段按四要素组织：**①优化逻辑（蓝）②关键输入（紫）③关键输出（绿）④跨平台差异与变更 case（橙）**。10 个字段分四组：A 预算与竞价 / B 定向与人群 / C 素材组合与找人 / D 全托管模式。

这是**平台机制层知识**——解释 S7/S4 诊断逻辑中「为什么算法会这样跑」的底层依据，也是判断「哪些动作该人工做、哪些该放权」的参照系。

### 2. 组 A · 预算与竞价（算法决定「花多少、出多少」）

**① 预算分配（跨组/跨计划挪钱）**
- 逻辑：实时预测各广告组转化概率与价值，总预算动态倾斜给「赢家组」；探索期留少量预算测新组防掐死；模型成熟后逐步加钱
- 输入：系列总预算、转化回传、出价目标值、组内素材表现、组级剩余预算
- 输出：各组实时预算分配比例（总预算不变、内部再分配）
- 平台差异：Meta CBO 组级预算锁死失效、新组有 7 天学习期保护；Google 默认 ABO、PMax 全托管；巨量支持系列预算自动分配（千川常用）；腾讯/快手默认 ABO、跨组分配弱需手动

**② 智能出价（每拍实时调价）**
- 逻辑：每次拍卖前按设备/时段/地点/查询词/画像预测转化概率与价值，在 tCPA/tROAS 约束内计算期望价值出价——高意向出高价抢、低意向出低价或不抢
- 输入：出价目标值、转化回传事件、拍卖上下文、预算余额
- 输出：每次拍卖实际出价（目标值上下浮动）
- 平台差异：Google tCPA/tROAS 最成熟（需 30 天 30 转化）；Meta Cost cap 锁成本上限/Bid cap 锁单次出价/Lowest cost 不设限；巨量 OCPM 新计划约 20 转化过学习期、频繁改预算出价重启学习；TikTok tROAS 类似 Meta；百度 OCPM 需转化回传稳定

### 3. 组 B · 定向与人群（算法决定「投给谁、在哪投」）

**③ 受众扩量/自动定向**
- 逻辑：人工勾选的兴趣/行为/Lookalike 从「硬筛条件」降级为「种子信号」；算法在种子内外做探索-利用；地域与法定年龄下限仍锁死
- 平台差异：Meta Adv+ Audience 画像变「建议」可关；Google 优化型受众搜索广告专属；巨量智能推荐定向基于视频内容+互动找相似人群；TikTok SPC 最激进人几乎不选；百度信息流有人群扩量、搜索以词为核心扩量弱

**④ 版位自动分配**
- 逻辑：Feed/Reels/Stories/AN/穿山甲/优量汇间按各版位转化性价比实时分预算——CPA 低多花、质量差砍
- 平台差异：Meta Adv+ Placements 全版位自动但 AN 流量质量差需单独监控；巨量优选广告位跨抖音/头条/西瓜/穿山甲（新手建议手动关穿山甲）；腾讯跨朋友圈/公众号/小程序/优量汇（朋友圈贵而精、优量汇便宜但杂）；Google 版位控制粗、搜索位由质量度决定

**⑤ 关键词匹配扩展（广泛匹配，搜索广告专属）**
- 逻辑：从种子词自动扩展到同义/相关/错拼/口语化查询并按词调价，否定词兜底
- 平台差异：Google 最激进必须每周看搜索词报告加否定词；百度智能匹配相对保守、强监管行业慎用；信息流平台无此概念，对应能力是受众扩量

### 4. 组 C · 素材组合与找人（算法决定「用哪条素材、给谁看」）

**⑥ 素材自动组合（程序化创意/RSA/DCO）**
- 逻辑：人传素材池（多视频/图/标题/描述），算法自动排列组合 N 变体实时测试 CTR/CVR/ROAS；Pin 位不参与组合
- 平台差异：Google RSA 最多 15 标题+4 描述、Pin 锁关键信息、搜索专属；巨量程序化创意千川标配；Meta Adv+ Creative 还自动裁比例/叠字/加音乐/生成文案变体；腾讯 DCO/快手能力稍弱

**⑦ 素材展示权重（同组多创意自动分流量）**
- 逻辑：同组多创意按实时表现自动分配展示，胜出拿更多、衰退被限流
- 平台差异：逻辑各平台一致；差异在新创意冷启动保护——巨量/Google 有学习期保护前几百次展示不直接砍，**Meta 较激进、新创意表现差会很快被压流量**

**⑧ 创意即定向（素材内容自动找人）**
- 逻辑：CV/NLP/音频模型分析素材本体（物体/人物/场景/关键词/语义），自动匹配历史上对这类内容感兴趣的人群，无需勾选兴趣标签
- 平台差异：巨量「创意即定向」最成熟（=Meta Creative as Targeting=TikTok 智能定向）；Google/百度无直接对应（PMax 间接实现、搜索靠关键词）

**⑨ 动态文案/AI 素材生成**
- 逻辑：从落地页/产品库抓信息动态插入标题或自动生成素材变体，人只提供模板和落地页
- 平台差异：Google DSA 无种子词从落地页自动抓词抓标题（适合 SKU 多电商）；百度 AI 创意需人工审核；巨量动态创意词插入用户搜索词；Meta Adv+ Creative 自动裁切叠字配乐

### 5. 组 D · 全托管模式（人只给目标+钱+素材）

**⑩ 全托管投放**——上述所有算法字段的「打包版」：人只填目标/预算/素材+落地页/转化回传，算法同时接管定向、版位、出价、预算分配、素材组合、关键词扩展全部决策，不再给单独调参入口。
- 平台产品：Google PMax（全渠道、透明度最低、需足够转化数据）、TikTok SPC（电商托管、新账户冷启动友好）、Meta Advantage+ Shopping Campaign（CBO+Adv+受众+版位+Creative 全开）、巨量放量投放（比 PMax 保留更多人工调参空间）

### 6. 两条判断规律（原文核心结论）

- **算法字段分四类**：钱怎么分（预算分配）、价怎么出（智能出价）、人怎么找（受众扩量/版位/关键词/创意即定向）、素材怎么拼（组合/权重/AI 生成）。全托管=四件事打包放权
- **「该不该放权」看依赖什么数据**：智能出价和预算分配依赖**转化回传质量**；受众扩量和创意即定向依赖**历史转化数据量**；素材组合依赖**素材池大小**。数据量不够时放权算法会瞎跑——**新账户前 2 周建议手动跑，等 20–50 个转化再切智能模式**

## 高频问答索引

- **Q：Meta CBO 和 ABO 的区别是什么？**
  A：CBO（系列预算优化）下组级预算锁死失效，算法跨组实时挪钱给赢家组，新组有 7 天学习期保护；ABO（广告组预算）组级预算独立锁定、人工控制分配。巨量/腾讯/快手默认 ABO 跨组分配弱。
- **Q：智能出价（tCPA/tROAS/oCPM）是怎么工作的？**
  A：每次拍卖前按设备/时段/地点/查询词/画像预测该用户的转化概率和价值，在目标值约束内算期望价值出价——高意向抢高价、低意向出低价或不抢。eCPM 换算公式见竞价链路卡。
- **Q：为什么新账户不能直接开智能出价/全托管？**
  A：放权依赖数据：智能出价和预算分配依赖转化回传质量，受众扩量和创意即定向依赖历史转化数据量。数据量不够算法会瞎跑——建议前 2 周手动跑，积累 20–50 个转化再切智能模式（与 S7「周转化≥50 脱离学习」口径呼应）`[推断]`。
- **Q：受众扩量（Adv+ Audience）把人工定向变成了什么？**
  A：从「硬筛条件」降级为「种子信号」——算法在种子内外做探索-利用找高价值人群；地域和法定年龄下限仍锁死。Meta 上画像变「建议」可保留可关闭。
- **Q：什么是「创意即定向」？**
  A：算法用 CV/NLP/音频理解素材本体（画面物体/人物/场景、文案关键词、音频语义），自动匹配对这类内容感兴趣的人群，无需人工勾选兴趣标签。巨量最成熟，Meta Creative as Targeting 与 TikTok 智能定向同类。
- **Q：程序化创意（DCO/RSA）和普通多素材有什么区别？**
  A：人传素材池，算法自动排列组合成 N 个「视频×标题×描述」变体实时测试效果；Pin 位锁死不参与组合。Meta Adv+ Creative 还会自动裁比例、叠字、加音乐、生成文案变体。
- **Q：Meta 和其他平台在「新创意冷启动」上有什么差异？**
  A：巨量/Google 对新创意有学习期保护（前几百次展示不直接按效果砍）；**Meta 较激进，新创意表现差会很快被压流量**——所以 S6/S7 要求新素材给足 50 点击或 3 天保护期 `[推断]`。
- **Q：全托管模式（PMax/SPC/ASC/放量投放）人还能调什么？**
  A：几乎不能单独调版位/人群/出价——只填目标、预算、素材+落地页、转化回传，保留排除权和品牌资产。Google PMax 透明度最低（看不到具体词/人群）；巨量放量投放比 PMax 保留更多人工调参空间。
- **Q：Audience Network 版位为什么要单独监控？**
  A：Meta Adv+ Placements 全版位自动分配时，AN（Audience Network）流量质量差、CPA 高——S7 L2-05 版位诊断要求低质版位消耗<20%，与此对应 `[推断]`。
- **Q：这份文档和 Momcozy 广告 Agent 有什么关系？**
  A：它是平台机制层参照：S4/S7 诊断树里的「Learning 期」「频控」「版位」「受众扩量」等判定逻辑，其行为本质都是本文档描述的算法机制；Agent 自动化操作（如 S5 PRD 的自动调整）本质是替人执行这些字段的调参与监控 `[推断]`。
