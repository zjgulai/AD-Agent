### 6. 建设全景解读

- **先行顺序：基础设施打底**。Agent 编排框架是唯一无依赖项（备注明确"最先启动"），P0、进行中；飞书 IM 集成与 Meta Ads API 对接同为 P0 进行中。三者构成所有上层 Agent 和页面的底座。
- **最早启动批次（2026-09-14）**：潜力评分 Agent、Meta 策略 Agent、Agent 编排框架——即"评分模型 + 首个平台策略 + 编排底座"并行起步。
- **已完成集中在 Meta/TikTok 的"策略 + 创建"4 项**：Meta 策略/创建（P0）、TikTok 策略/创建（P1）均已完成，说明平台侧投放链路已打通；YouTube 线（策略、创建、Google Ads API）整体未启动，优先级最低（P2/P1）。
- **待验收 4 项全是"对接/页面"性质**：授权索要流程、红人内容池页、加推工作台页、广告列表页——上游 Agent 已就绪、交付物进入验收环节。
- **下游链路整体未开始**：效果监控、广告优化、复盘总结 3 个 Agent 未开始，其中效果监控/广告优化计划开始时间最晚（2026-11-23）；复盘总结 Agent 虽计划开始 2026-09-21 但状态仍为未开始，且依赖的"效果分析 Agent"在任务表中无独立条目 [待确认]。
- **FDE 分工**：周文军 10 项（全平台策略/创建 Agent + 效果监控 + 广告优化 + 2 个页面）、李尚毅 5 项（编排框架 + 飞书 IM + 3 平台 API 对接）、李莹 5 项（素材发现/潜力评分/授权索要/复盘总结/效果分析页）、王璐瑶 1 项（红人内容池页）。
- **训练角色**：仅 Agent 建设任务绑定训练角色——素材侧为胡深深+雍娜，平台 Agent 为雍娜+陈英凯，监控/优化为易思琦，复盘为余越+易思琦；基础设施、集成对接、页面任务训练角色为空。「训练角色-数字化」仅素材发现、潜力评分 2 项填写（均为李莹）。

### 7. 关键依赖链 [推断整理]

- **集成底座链**：Agent 编排框架 → 飞书 IM 集成 / TikTok·Meta·YouTube Ads API 对接（5 项集成对接全部依赖编排框架）→ 各平台策略 Agent → 各平台创建 Agent。
- **素材侧链路**：素材发现 Agent → 潜力评分 Agent → 授权索要（流程确认）→ 授权完成后进入三平台策略 Agent。
- **投放后链路**：三平台创建 Agent → 效果监控 Agent / 效果分析 → 广告优化 Agent → 复盘总结 Agent。
- **页面依赖**：红人内容池页 ← 素材发现 Agent；加推工作台页 ← 三平台策略 Agent + 飞书 IM；广告列表页 ← 三平台创建 Agent + 效果监控 Agent；效果分析页 ← 效果分析 Agent（表外）。
- ⚠️ **依赖事项中的表外引用**：「红人系统对接」「三平台 API 对接」「授权索要 Agent」「TikTok/Meta/YouTube API 对接」「三平台策略 Agent」「三平台创建 Agent」「广告系统对接」可视为分组 umbrella 引用；但「上线检查 Agent」「效果分析 Agent」「优化建议 Agent」在本表和 Agent 表中均无独立条目 [待确认]。
