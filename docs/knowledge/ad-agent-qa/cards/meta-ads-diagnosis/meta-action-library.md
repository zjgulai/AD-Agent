# Meta 广告动作库 A-01~A-16 与 21 字段动作日志模板

## 核心问题

诊断引擎给出根因后，可以执行哪些标准动作？每个动作的适用场景、改动内容、预期影响幅度、风险和回滚条件是什么？执行后如何用 21 字段动作日志留痕并按 4h/24h/72h 复核？

## 系统解答

### 1. 动作库使用前提

- sheet-03「动作库与影响预估」开头声明：**DTC 中高客单商品初始经验值；实际效果需按国家、目标、季节、客单价和账户历史校准**（sheet 名标注「待细化」`[待确认]`）。
- 动作库与诊断执行台（sheet-01）配套：节点行给出「推荐动作类型 + 动作改动明细 + 预期影响」，动作库给出标准化动作 ID、影响预估与回滚条件；执行前必须过 G8/P4-01 安全检查（近 12h 人工变更、大促窗口、冷却期、回滚条件齐全）。
- 铁律约束：一次只动一个主变量、学习期不判效、冷却期 24h～72h、归因成熟度 ≥80% 才判断 CPA/ROAS。

### 3. 动作日志模板（21 列）

sheet-04 开头声明：**每次诊断和动作必须留痕；复核结果由投放人员或自动化程序回填**。模板表头即 21 列字段，空行「状态」列默认填「待复核」。

| # | 字段 | 含义与填写规范 |
|---|------|----------------|
| 1 | 日期 | 诊断/动作发生日期 |
| 2 | 项目/系列/广告组/广告 | 对象定位，按层级填写到广告（L3）粒度 |
| 3 | 诊断ID | 引用 sheet-01 节点诊断 ID（如 S1-12、P0-01），与动作日志关联诊断结论 |
| 4 | 异常现象 | 五段式第一段：发生了什么 |
| 5 | 证据指标 | 支撑判断的指标名（与指标基准线口径一致） |
| 6 | 当前值 | 动作前实测值 |
| 7 | 正常阈值 | 对照基准（sheet-02 或节点 IF 条件口径） |
| 8 | 偏离幅度 | 当前值相对阈值的偏离 |
| 9 | 主要根因 | 五段式第三段：Primary Root Cause，只记一个主因 |
| 10 | 动作ID | 引用动作库 A-01~A-16 |
| 11 | 改动明细 | 具体改了什么（预算数值/受众/素材 ID/出价等），对应节点行「动作改动明细」 |
| 12 | 预期影响 | 引用动作库「预估幅度」或节点行「预期影响」 |
| 13 | 优先级 | P0/P1/P2 |
| 14 | 执行人 | 操作人（人工或自动化程序标识） |
| 15 | 执行时间 | 动作落地时间 |
| 16 | 4小时结果 | 复核回填：花费侧指标 |
| 17 | 24小时结果 | 复核回填：CTR 等 |
| 18 | 72小时结果 | 复核回填：CVR/CPA/ROAS 等效果指标 |
| 19 | 回滚条件 | 触发回滚的判定条件（与动作库「回滚条件」一致） |
| 20 | 状态 | 默认「待复核」，复核后更新（达标/回滚/升级等） `[待确认：状态枚举值未在表中定义]` |
| 21 | 复盘备注 | 闭环复盘结论；sheet-01 P4-02 正常分支指向「诊断完成」 |

### 4. 复核流程（4h / 24h / 72h）

- **触发**：每次动作执行后自动创建三个复核时点（sheet-00 固定顺序末段「4h/24h/72h复核」；sheet-01 P4-02 节点）。
- **复核指标**（sheet-01 P4-02）：4h 看花费、24h 看 CTR、72h 看 CVR/CPA/ROAS，另加数据延迟监控。
- **判定分档**：
  - CPA 上升 ≥20% 或 ROAS 下降 ≥20% 或数据延迟 >6h → **未达标：回滚最近动作、记录原因、重新进入前置检查、升级 P0 告警**；
  - CPA 上升 10%~20% 或 ROAS 下降 10%~20% 或延迟 4~6h → **待观察：密切监控，禁止继续追加动作**；
  - CPA 未升 ≥20% 且 ROAS 未降 ≥20% 且数据正常 → **达标：诊断闭环，写入动作日志**。
- **回填责任**：复核结果由投放人员或自动化程序回填到 16~18 列；S5 PRD 要求三段复核自动回填 + 周度决策审计（LLM-3）[来源：S5]。

## 高频问答索引

- **Q：动作库一共有多少个动作？都是什么类型？**
  A：16 个（A-01~A-16）：继续观察、预算增/减（20%/50%）、暂停劣质组/广告、调整受众、加排除名单、调出价、换补素材、重剪视频前3秒、设频次上限、关劣质版位、优化落地页、简化结账、结构重构、修复归因/像素。
- **Q：动作库的预估幅度可以当承诺吗？**
  A：不能。原文声明是「DTC 中高客单商品初始经验值」，需按国家、目标、季节、客单价和账户历史校准；且每个动作都有验证窗口和回滚条件，未达预期即回滚。
- **Q：什么情况下只「继续观察」（A-01）？**
  A：指标偏离 ±15% 以内、学习期内、样本不足或大盘萎缩时。前提：学习期不足 50 次转化不强动作；验证窗口 3 天；若出现 P0 数据或资格异常则转修复。
- **Q：扩量预算怎么操作才安全？**
  A：A-02 预算增加 20% 需 ROAS≥目标1.3倍、CPA≤目标0.8倍且学习完成，单次不超 30%、分 2~3 次扩量，48 小时/次复核，回滚线 CPA+20% 或 ROAS-20%。更大扩量用 A-03（+50%）分 3 次、预留学习期、验证 7 天。
- **Q：P0 止血用什么动作？**
  A：典型是 A-04 预算缩减 20%~50%（适用 CPA>目标1.5倍连续3天），止血后必须继续找根因；或 A-05 暂停劣质广告组/广告（需 CPA≥系列均值2倍且交叉验证确认）。ROAS<盈亏平衡×0.7 时 sheet-01 走「暂停系列→查 CPA/客单价/归因口径」止血路径。
- **Q：动作日志为什么必须 21 列全填？**
  A：原文要求「每次诊断和动作必须留痕」。前 9 列对应五段式诊断输出（异常/证据/根因），10~15 列登记动作与执行人，中间 3 列是 4h/24h/72h 复核回填，末 3 列管回滚条件、状态与复盘——缺复核的动作视为未闭环。
- **Q：复核结果谁回填、什么时候回填？**
  A：由投放人员或自动化程序回填；三个时点为执行后 4h（花费）、24h（CTR）、72h（CVR/CPA/ROAS），另监控数据延迟。状态列默认「待复核」。
- **Q：达到回滚条件会怎样？**
  A：P4-02 判定 CPA+≥20% 或 ROAS-≥20% 或数据延迟>6h 为未达标：自动/人工回滚最近动作、记录原因、重新进入前置检查、升级为 P0 告警；预警档（CPA+10~20%/ROAS-10~20%）只密切监控、禁止追加动作。
- **Q：A-16 修复归因/像素算投放动作吗？**
  A：不算投放类动作，是数据修复动作——适用 EQ<4、转化漏报、数据不一致；预估影响是「不预估投放提升，但恢复判断基础」，修复后等 48 小时稳定再复测（EQ 仍<4 或重复>30% 视为失败）。
- **Q：为什么 A-15 结构重构风险标「中高」？**
  A：因它会重置学习状态、短期波动约 -10%，仅适合 Learning Limited 多、结构混杂、测试/收割混跑的场景；要求低活跃期执行、完成后 14 天不反复，回滚线为学习状态恶化。
