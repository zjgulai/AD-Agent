# Meta 投后数据明细模板与巡检记录设计（S8）

## 核心问题

Meta 广告投后巡检需要采集哪些数据？《广告投后数据明细2（meta）（待业务确认）》给出了什么样的三层级字段模板？模板里预留的「广告巡检结论 / 运营实际操作记录」列块是怎么设计的？内置的 C01–C03 案例数据长什么样？

## 系统解答

### 1. 文档定位

飞书电子表格（token `DOers7WEAhnsyktPb6fcBQn2nre`），标题含「**待业务确认**」——字段口径尚未业务定稿。三个 sheet 对应 Meta 广告三层级：**广告系列层 / 广告组层 / 广告创意层**。结构 = `广告数据明细`（指标字段区）+ `广告巡检结论`（诊断输出区）+ `运营实际操作记录`（执行回填区）。

它是**投后数据采集与巡检闭环的字段级模板**：上半区是从 Ads Manager 导出的原始指标，下半区是巡检 Agent/投手要填写的诊断结论与动作回填——与 S5 PRD 的监控工作台、S7 的动作日志模板是同一条数据链路的不同环节 `[推断]`。

### 2. 三层级字段设计

#### 广告系列层（Campaign，约 38 个指标/配置字段）

- **报表口径**：报表开始/结束日期 + 系列ID + 广告系列名称 + 实体ID/名称
- **配置字段**：投放目标、投放国家、货币、日预算/总预算（美元）、出价策略、投放状态、学习期状态
- **曝光层**：累计花费、累计展示量、累计触达人数、展现频次、展示份额、CPM
- **点击层**：累计点击量、CTR、CPC
- **站内漏斗层**（当日末次归因）：落地页访问量、落地页达到率（LPV÷点击）、落地页访客数、累计加购/添加订单/到达结账/完成结账访客数
- **漏斗转化率**：加购率、添加订单率、到达结账率、完成结账率
- **效果层**：CVR（完成结账÷点击）、CPA、GMV、ROAS

注意其漏斗口径与 S7 L4 略有差异：此处是「访客数」口径（当日末次归因），漏斗为 加购→添加订单→到达结账→完成结账 四段，而 S7 L4 是 LPV→VC→ATC→IC→Purchase 五段 `[待确认]`。

#### 广告组层（AdSet，继承系列字段 + 受众维度）

在系列层字段基础上增加：**广告组ID/名称、所属系列ID、投放人群包id/名称、排除人群包id/名称、版位**——即受众定向与版位配置字段，支撑 L2 受众诊断。

#### 广告创意层（Ad，继承组字段 + 素材维度）

在组层字段基础上增加：**广告ID/名称、所属系列/广告组ID、素材形式、素材ID/名称、素材文案、Creative as Targeting 状态、Adv+ Creative 状态**——即素材级字段与 Meta 自动化能力开关，支撑 L3 素材诊断（CAT/Adv+ Creative 与 S7 L3-05 对应）。

### 3. 巡检记录列块设计（三表共有）

每个 sheet 尾部预留两个结构相同的记录区，构成「诊断→执行→复检」闭环：

| 列块 | 字段 | 说明 |
|------|------|------|
| 广告巡检结论（系列/组层）/ 广告自动巡检记录（创意层） | 巡检日期时间、诊断结论(异常现象+证据值)、推荐动作类型、改动明细、预期影响(指标+方向+幅度)、优先级、再次巡检重点关键项/备注 | 对应 S7 五段式输出：异常→证据→根因→动作→影响预估；「再次巡检重点」对应验证窗口回看 |
| 运营实际操作记录 | 动作执行日期时间、诊断结论更新、实际动作类型、实际改动明细、预期影响、再次巡检重点关键项/备注 | 动作执行后的实际回填，对应 S7 铁律 6「动作必留痕」+ 72h 实际结果 |

设计含义：同一行 = 一个广告实体的**指标快照 + 最新一次巡检诊断 + 已执行动作回填**，是「数据-诊断-动作-复检」一体化台账 `[推断]`。

### 4. 内置案例数据（吸奶器X1 · 2026Q4 上市项目）

- **报表窗口**：2026-09-03 ~ 2026-09-16（14 天，与 S7 L4-01 数据门槛窗口一致）
- **系列层 3 条 Campaign**：
  - C01 系列01「Hook素材实验」：Sales 目标 / ROAS 出价 / 日预算 $150 / 总预算 $2100 → 花费 $2100、展示 15 万、频次 2、CPM $14、CTR 1.6%、CPC $0.88、LPV 2294（达到率 95.6%）、加购率 8%、CVR 2.08%、CPA $42、GMV $4240、**ROAS 2.02**
  - C02 系列02「出价策略实验」：Traffic 目标 / Lowest cost / 日预算 $200 / 总预算 $2800 → CTR 1.43%、CPA $49.12、ROAS 1.71
  - C03 系列03「再营销人群实验」：Leads 目标 / ROAS 出价 / **部分预算受限** / 学习期「进行中」→ CPM $11.65、CPA $28.77、ROAS 2.67
- **组层**：命名规范含「人群包×版位×出价×年龄×频次×时段」全要素（如 `组01-相似扩展-购买者1%-短视频-目标广告回报率-25至34岁-全设备-一周3次-晚6至10点`），人群包示例：购买者 1%/3% 相似扩展（LAL）、已购买用户排除包
- **创意层**：15 秒视频素材，文案示例「每分钟仅需0.5美元，轻松解放双手」「熬夜喂奶手腕酸？试试这款」；CAT 与 Adv+ Creative 均「已开启」
- 巡检结论/操作记录列在案例行中**全部留空**——模板待业务填写，印证「待业务确认」状态

### 5. 与既有卡片的关系

- **对 S5 PRD**：本模板是「广告监控工作台」的数据输入 schema——PRD 要拉的报表字段在此落成 Excel 三级结构 `[推断]`
- **对 S7/S4 诊断体系**：漏斗指标口径可互校（S8 用「访客数+末次归因」，S7 L4 用事件数口径）；巡检列块字段与 S7 sheet-09 动作日志、S6 A-3 日志模板同构
- **命名规范证据**：组/系列命名含「产品线×阶段×市场×目标×实验类型」要素，与 S7 L0-03 账户结构健康的命名规范要求互证

## 高频问答索引

- **Q：Meta 投后巡检要采集哪些数据？**
  A：按三层级采集：Campaign 层（预算/出价/状态 + 曝光 CPM/频次/份额 + 点击 CTR/CPC + LPV 漏斗五段 + CVR/CPA/GMV/ROAS）、AdSet 层（加人群包/排除包/版位）、Ad 层（加素材形式/素材ID/文案/CAT/Adv+ Creative 开关）。报表窗口 14 天。
- **Q：巡检结论和动作记录在模板里怎么设计的？**
  A：每层 sheet 尾部两个列块：「巡检结论」= 巡检日期/诊断结论(异常+证据值)/推荐动作/改动明细/预期影响/优先级/再次巡检重点；「运营操作记录」= 执行时间/诊断更新/实际动作/改动明细/预期影响/复检重点。一行=一个实体的指标+诊断+回填一体化台账。
- **Q：S8 的漏斗口径和 S7 L4 一样吗？**
  A：不完全一样。S8 用「访客数（当日末次归因）」口径，漏斗为 加购→添加订单→到达结账→完成结账 四段；S7 L4 用事件数口径，漏斗为 LPV→VC→ATC→IC→Purchase 五段。两者都保留 LP 到达率，深层节点命名与分母不同 `[待确认]`。
- **Q：模板里的案例数据说明了什么？**
  A：吸奶器X1 Q4 上市项目 14 天窗口（2026-09-03~16）：3 个 Campaign 分别做 Hook 素材实验（Sales/ROAS，ROAS 2.02）、出价策略实验（Traffic/Lowest cost）、再营销人群实验（Leads/ROAS，部分预算受限+学习中）。组命名含全要素，创意开 CAT+Adv+ Creative。巡检列留空待填。
- **Q：S8 和 S5 监控 Agent PRD 什么关系？**
  A：S8 是投后数据的字段级落地模板，S5 PRD 是产品化方案——本模板的三级字段结构可视为监控工作台报表 schema 的业务侧定义 `[推断]`。标题「待业务确认」说明字段口径仍在评审。
- **Q：为什么组命名这么长？**
  A：命名编码了诊断所需的全部分组维度：人群包类型与比例、版位、出价方式、年龄、设备、频次、投放时段——巡检时可直接按命名解析该 AdSet 的定向配置，无需回后台查询 `[推断]`。
