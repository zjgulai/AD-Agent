# Meta 投放师一日工作流 SOP · 8 环节时间轴与环节内 IF/ELSE 决策树（人类执行版）

## 核心问题

一名 Meta 投放师的一天怎么过？从 09:00 晨会到 18:00 收工的 8 个环节（M 晨会 / W 监控 / I 排查 / B 预算 / C 素材 / R 复盘 / D 日报 / P 规划）各自做什么、按什么 IF/ELSE 决策树分流、哪些动作被铁律禁止？这份 SOP 与 G0–G8 诊断策略树（S4/S5/S7）是什么关系？

## 系统解答

### 1. 文档定位与版本说明

- **文档**：《Meta 广告投放师 · 一日工作流 SOP 融合终版 v5.0》。飞书文件名标「【业务提供】Meta广告投放师一日工作流SOP_深度整合终稿v6」——**已裁决（C9，2026-11-27 业务确认）：v6 为发布版**，文内 v5.0 为未更新标题；页脚品牌标注 MOMCOZY · DTC · META ADS。
- **定位**：面向**人类投放师**的一日操作规程。将 v1~v4 四代资产按「投放师的一天」重组为主干，每个环节内嵌 IF/ELSE 决策树，全局逻辑闭环、可追溯、可套用。
- **结构**：G 全局决策树 → T 一日时间轴 → M/W/I/B/C/R/D/P 八环节 → A 附录（字段阈值速查 / 动作影响预估 / 动作日志模板）→ F 附录（资产整合映射与核对方法）。
- **v1~v4 资产去向**（文档自述）：v1.0 全平台分层诊断 → 「诊断铁律/五步法/动作影响四要素」被吸收为全文总纲与 A-2 动作库；v2.x 五层决策表+六层漏斗 → 每行重写为环节内 IF/ELSE 决策节点（编号 W/I/B/C…），六层漏斗阈值并入 I-3；v3.0 六维操作规程 → 六维（前置/步骤/记录/异常/判定/交接）压入每环节；v4.0 四代融合矫正 → 矫正结论（口径统一/优先级/数据充分性/归因兜底）成为 A-1 阈值基准与各节点「阈值依据」列。
- **编号体系**：环节字母（M/W/I/B/C/R/D/P）+ 节点序号（如 M-3 晨会第3个判断、I-5.2 排查第5节点第2分支）；HTML 与配套 Excel 同名 Sheet 同编号同列，逐格可核对纠正。
- **时区假设**：中国团队服务美国市场（如 Momcozy US）的常见作息，09:00 开盘 ~ 18:00 收工。Meta 消耗高峰在美东 19:00–23:00（北京时间次日 07:00–11:00），晚间高峰不做大幅调整，只做**超投止血值守**（Pacing>130% 或预算将尽时降 20%），并把「早间看到的昨日数据」归到正确归属日。
- **P0 修复的分层引用**：G 树与 W-0 表中的 L0-02 / L0-06 / L4-02 是 S7 分层 SOP 的节点编号——L0-02 转化事件质量（EQ/CAPI）、L0-06 政策合规与账户安全、L4-02 点击→落地页到达诊断（技术链路），对应「事件修复 / 合规申诉 / 技术修复」三个 P0 出口 [来源：S7 raw/s7-02、s7-06]。

### 2. 全局主干决策树

主干口诀：**排雷 → 监控 → 穿透 → 动作**；「先账户排雷，再分层定位，动作一次一个，72h 必回看」。

主流程（每个环节有明确触发条件、入口与出口）：

1. **09:00 晨会 M**：拿到昨日战报 / 今日 KPI / 遗留问题清单。
2. **账户级 15 秒排雷（#任何环节开始前必做）**：
   - IF Pixel/CAPI 事件质量 EQ < 6 → GOTO P0 修复（L0-02）
   - ELIF 账户受限 / 广告大量拒登 → GOTO 合规 P0（L0-06）
   - ELIF 后台订单 vs 归因购买 差 > 30% → GOTO 归因修复 P0（L0-01）
   - ELSE 排雷通过 → 进入 W 账户监控
3. **W 账户/计划监控**（逐 Campaign 打分）：
   - IF Campaign 处于 Learning（<50 转化）→ 只看趋势不动策略，标记观察
   - ELIF Pacing <60% 或 >130% → GOTO B 预算环节（欠投/超投）
   - ELIF Campaign ROAS ≥ 目标 → 健康，筛选可扩量对象午后执行
   - ELSE ROAS < 目标 → 进入 I 异常排查（穿透找根因）
4. **I 异常排查**（五层穿透：账户 → Campaign → AdSet → Ad → 落地页；只查异常对象，不全面扫）：
   - IF CTR 整体低（<0.5%）→ 判素材问题，GOTO C 素材环节
   - ELIF CTR 正常但 CVR 低 → 判落地页/漏斗，六层漏斗定位断点
   - ELIF 某 AdSet CPA 2x 均值 → 交叉验证素材×受众，定根因
   - ELSE 归因/结构问题 → 回 L0/L1
5. **B 预算/出价调整**（午后执行，一次只动 1 个变量）→ **C 素材上新**（补 CTR/疲劳素材，输出需求单）→ **R 效果复盘**（回看 72h 前动作，验证窗口）→ **D 日报 + P 次日规划**（输出：今日动作 × 结果 × 明日重点）。

### 3. 一日时间轴 · 8 环节逐段

| 时段 | 环节 | 一句话职责 |
|------|------|-----------|
| 09:00–09:30 | M · 晨会目标确认 | 昨日战报 / 今日 KPI / 遗留问题认领 |
| 09:30–10:30 | W · 账户与计划监控 | 全账户晨检：P0 排雷 → Campaign 健康度扫描 |
| 10:30–12:00 | I · 数据异常排查 | 只对异常对象五层穿透，定位根因 |
| 13:00–14:30 | B · 预算与出价调整 | 扩/缩/暂停，一次一变量 |
| 14:30–16:00 | C · 素材上新管理 | 补疲素材 / 需求单 / 上新跟踪 |
| 16:00–17:00 | R · 效果复盘 | 72h 动作回看 / A-B 判定 / 学习期检查 |
| 17:00–17:40 | D · 日报输出 | 五段式日报 / 证据存档 / 群内同步 |
| 17:40–18:00 | P · 次日规划 | 次日重点清单 / 排期提醒 / 素材储备 |

#### M · 晨会目标确认（09:00–09:30）

- **目的**：用 30 分钟对齐「昨天发生了什么、今天要守住什么、遗留什么问题今天必须闭环」。晨会不开成读数据会——只讨论**偏差 >15% 的对象**与今日动作计划。
- **M-1 输入准备（会前 10 分钟）**：
  1. 昨日战报表：GMV / 花费 / ROAS / CPA / 转化数，与目标对比，标红偏差>15% 项
  2. 前日动作日志：昨天做了哪些动作，哪些到了 72h 回看点
  3. 今日已知变量：预算变动 / 上新计划 / 大促排期 / 库存预警
  4. 遗留问题清单：P0/P1 是否已闭环，未闭环的今天责任人
- **M-2 晨会决策树（逐项过）**：
  - M-1 IF 昨日整体 ROAS ≥ 目标（如 ≥3.0）THEN 基调 = 保量，筛选可扩量 Campaign（ROAS≥1.3x）；ELSE 基调 = 排查优化，预算先守后攻；THEN 记录「今日主攻对象」→ 交 I 环节
  - M-2 IF 存在 P0 遗留（归因/像素/落地页崩）THEN 晨会结束后第一件事 = 排雷修复（占 09:00–09:30）；ELSE 进入常规监控 W
  - M-3 IF 今日有新素材 / 新 Campaign 上线计划 THEN 确认素材到位 + 分配观察预算 → C 环节跟踪；ELSE 维持现状观察
  - M-4 IF 昨日有动作到了 72h 回看点 THEN 列入今日 R 环节第一优先级；ELSE 常规排程
- **出口**：今日 KPI 目标卡（逐 Campaign 目标 ROAS/CPA）+ 主攻对象清单 + P0 排雷认领人 + 需回看动作清单。写入动作日志 Sheet09 / Excel「M-晨会」。

#### W · 账户与计划监控（09:30–10:30）

- **目的**：全账户 15 秒排雷后，对每个 Campaign 做健康度打分，分出「正常 / 观察 / 需排查」三档——只有「需排查」才进 I 环节，避免全面撒网。
- **W-0 全账户 15 秒排雷（每日必做，前置）**：

| 检查 | 字段/口径 | 正常 | 异常→动作 |
|------|----------|------|-----------|
| 归因 | 后台订单 vs 归因购买 | 差异 ≤20% | >30% P0 → 修 Pixel/CAPI/去重，修前不调策略 |
| 事件质量 | EQ(Purchase) | ≥8 | <4 P0 → 事件修复（L0-02） |
| 账户状态 | 账户/主页受限 | 无警告 | 受限 P0 → 合规申诉（L0-06） |
| 落地页 | LP 可访问/加载 | <3s | 打不开/>5s P0 → 技术修复（L4-02） |

- **W-1 Campaign 健康度逐项扫描**：

| 检查项 | 正常 | 异常 |
|--------|------|------|
| 预算消耗 Pacing | 80% ~ 120% | <60% 欠投 / >130% 超投，异常 2 天连续才算趋势 |
| 出价达成率 | 0.8x ~ 1.2x | 实际CPA/目标CPA；或实际ROAS/目标ROAS |
| 学习状态 | 周转化 ≥ 50 | Learning 期不判效；Learning 7天+ 才介入 |
| 整体 ROAS | ≥ 目标 | <目标0.7x 连续2-3天 = 需排查 |

- **W-2 监控决策树**：
  - W-1 IF 排雷发现 P0（归因/EQ/合规/LP 任一）THEN 立即修复，今日该对象不做任何投放判断；ELSE 进入 Campaign 扫描
  - W-2 FOR 每个 Campaign：
    - IF Learning 状态（转化 <50）THEN 只看趋势 + 记学习进度，不做动作（#铁律5）
    - ELIF Pacing <60%（连续2天）THEN 标「欠投」→ B-1（提上限/放宽受众）
    - ELIF Pacing >130% THEN 标「超投」→ B-2（降预算20%止血）
    - ELIF ROAS < 目标0.7x（连续2-3天）THEN 标「需排查」→ I 环节穿透
    - ELIF ROAS ≥ 目标1.3x THEN 标「可扩量候选」→ B-3（午后扩20%）
    - ELSE 健康 → 记录基线即可
  - W-3 IF 频次 >5 且 CTR 下滑（任一 Campaign）THEN 标「素材疲劳」→ C 环节上新；ELSE 记录频次基线
- **出口**：三档分类清单（正常观察/欠投/超投/需排查），每档带对象 ID 与证据值。异常对象全部进入 I 环节，**禁止在此层直接砍预算**。

#### I · 数据异常排查（10:30–12:00）

- **目的**：对 W 环节标记的「需排查」对象做**五层穿透**（账户 → Campaign → AdSet → Ad → 落地页），只查异常对象，逐层剥离，最终锁定**唯一根因层级**。核心心法：先判「问题在哪一层」，再判「为什么」，最后才动。

**I-1 · 根因快速分类（第一层判断，现象→根因映射）**

| 分支 | IF 条件 | THEN 判定与去向 |
|------|---------|----------------|
| I-1.1 | 点击率(CTR) < 0.5% | 根因 = 素材问题（90%概率）→ 进 C 环节，不看受众不看落地页 |
| I-1.2 | CTR 正常(≥0.8%)但 CVR 低(<1%) | 根因 = 落地页/站内漏斗 → 进 I-3 六层漏斗定位 |
| I-1.3 | CTR 与 CVR 都正常但 ROAS 低 | 查 AOV / 归因 / 转化事件口径 → 进 I-4 |
| I-1.4 | 整体正常但某 AdSet CPA 2x 均值 | 根因 = 受众 or 素材（需交叉验证）→ 进 I-2 |
| I-1.5 | 某素材 CTR 周环比 -30%+ | 根因 = 素材疲劳（频次>4 佐证）→ 进 C 环节上新 |

**I-2 · 受众 vs 素材交叉验证（防误诊关键）**

取「差 AdSet」与「好 AdSet」共用的同一素材做对比：

- IF 同素材在好受众表现好、在差受众差 → 判定 = 受众问题 → B-4（关停差受众 / 单独降价30%）
- ELIF 差素材在所有受众都差 → 判定 = 素材问题 → C-1（换新方向素材）
- ELSE 数据不足以判定（样本<50转化）→ 继续观察，不动作（#铁律：样本不足不判效）

**I-3 · 落地页六层漏斗定位（L4）**

当判断落在站内，用六层漏斗找「断崖式下降的那一层」，每层对应不同根因：技术 / 承接 / 说服 / 摩擦 / 归因。

| 漏斗环节 | 核心指标 | 健康基准 | 断崖时根因方向 |
|----------|----------|----------|----------------|
| 曝光→点击 | 出站CTR | ≥1%（素材） | 素材/文案/Offer → C |
| 点击→落地页到达 | LPV/出站点击 | ≥70% | 加载/链路/404 → 技术修复 |
| 到达→浏览内容 | VC/LPV | ≥60-70% | 首屏承接/信任元素 → 对齐广告 |
| 浏览→加购 | ATC/VC | 3-8% | 产品说服力/价格/评价 → 运营 |
| 加购→结账 | IC/ATC | ≥60% | 运费/总价惊讶 → 前置透明 |
| 结账→购买 | Purchase/IC | ≥70%（ATC→P ≥30%） | 流程/支付/信任 → UX 修复 |
| 归因兜底 | 后台/归因订单 | 差 ≤20% | >30-40% = 追踪问题 → 像素/CAPI |

- I-3.1 先验数据充分性：IF 近14天消耗 <$50 THEN 只做整站整体诊断，不细分（#防误诊）；ELSE 进入六层逐层照 I-3.2
- I-3.2 FOR 每层（到达→浏览→加购→结账→购买）：IF 该层转化率 < 健康基准 THEN 记为该层断崖，定位该层根因；ELIF 全层均达标但整体CVR仍低 THEN 根因在广告前段（素材/受众），回 I-1
- I-3.3 IF 断点在「点击→到达」（到达率<60%）THEN 技术问题：PageSpeed 移动端 + 链接链路 → 修复后48h复测
- I-3.4 IF 断点在「到达→浏览」（浏览率<60%）THEN 首屏承接：广告与 LP 同产品同承诺 + 信任元素首屏
- I-3.5 IF 断点在「浏览→加购」（<3%）THEN 产品说服力：价格/评价（≥10带图）/利益点文案/SKU
- I-3.6 IF 断点在「结账」（IC/ATC<40% 或 Purchase/IC<50%）THEN 结账摩擦：运费前置/Guest/支付方式/信任
- I-3.7 IF 归因兜底差异 >30% THEN P0：修 Pixel/CAPI/去重 → 48h 复测后再出结论

**I-4 · 归因与结构排雷（现象异常但链路全正常时）**

- I-4.1 IF 后台有单但归因购买少 THEN 像素漏报/去重失败 P0 → 修事件（算法失明，投放会持续变差）
- I-4.2 ELIF ROAS 崩但转化量正常 THEN 归因窗口/重复事件 → 先对口径，勿动投放
- I-4.3 ELIF 多个 Campaign 同时崩（非单点）THEN 查账户级：政策受限/频次上限/Billing/大促波动
- I-4.4 ELIF 仅单个 Campaign 崩 THEN 查该 Campaign 内部（AdSet/素材）→ 回 I-2/I-1

- **出口约束**：归因/事件/落地页这三类 P0 不排除，任何层内结论都可能是假象。I 环节结束时必须能回答：问题在哪个层级？证据值是多少？根因是什么？该走 B/C/L4 哪个动作？

#### B · 预算与出价调整（13:00–14:30）

- **目的**：把 I 环节的根因结论翻译成具体的预算/出价动作。铁律：一次只动 1 个变量；根因是素材就绝不调预算（那是放大无效消耗）。
- **B-1 ~ B-8 决策分支**：
  - B-1 IF 根因 = 素材问题（CTR低/疲劳）THEN 预算分文不动 → C 环节换素材（#在烂素材上扩预算=放大浪费）
  - B-2 IF Pacing <60%（欠投，且非素材问题）THEN 依次试：① 出价上限 +15% → ② 放宽受众 → ③ 查频控；每步间隔24h，只动一项
  - B-3 IF Pacing >130%（超投）或预算将尽 THEN 立即降日预算 20% 止血（晚间值守也适用）→ 查 CBO 是否偷预算
  - B-4 IF 确认受众问题（交叉验证通过）THEN 关停劣质 AdSet 或单独降价 30% → 48h 看整体 CPA 是否改善
  - B-5 IF 确认可扩量对象（ROAS≥1.3x, Learning 完成）THEN 扩预算 20%（一次不超+50%，分2-3次）→ 48h 后看 ROAS 是否守住
  - B-6 IF 出价达成率 <0.7x 持续3天 THEN 先查是「目标虚高」还是「竞争上涨」：目标虚高→调到可行值；竞争→备素材/容忍短期
  - B-7 IF 目标达成 >1.3x（远好）THEN 小幅上调目标 10-15% 榨量，勿一次调太多
  - B-8 IF Learning 未满 50 转化 THEN 禁止动预算（每次编辑重置学习）；ELSE 按上述分支执行
- **动作预估速查**：

| 动作 | 触发 | 预估影响 | 风险 | 验证窗 |
|------|------|----------|------|--------|
| 扩预算 +20% | ROAS≥1.3x | 花费+20% 转化+10~15% | 低 | 48h |
| 降预算 20% | 超投/ROAS<0.7x | 花费-20%，防透支 | 低 | 24h |
| 暂停劣质 AdSet | CPA 2x 且交叉验证 | ROAS+15~30% 转化-10~20% | 低 | 48h |
| 提上限 +15% | 欠投 | 展现+30~50% | 中 | 24h |

#### C · 素材上新管理（14:30–16:00）

- **目的**：素材是命根。每天固定窗口处理：识别需替换素材 → 给创意团队可执行需求单 → 上新跟踪 → 新素材保护（给足学习期）。
- **C-1 ~ C-7 决策分支**：
  - C-1 IF 素材 CTR <0.5% 或 周环比-30%+（疲劳）THEN 列「需替换」→ 输出需求单（3-5条新方向）；ELSE 保持观察，进入 C-2
  - C-2 IF 视频 3秒播放率 <20% THEN 重剪前3秒（hook前置）+ 换封面
  - C-3 ELIF 完播率 <5%（3秒率正常）THEN 节奏加速/砍冗长开头/提信息密度
  - C-4 IF 文案首行无钩子（无数字/痛点/限时）THEN 重写首行：对谁说+问题+方案+行动
  - C-5 IF CTA 与落地页承诺不一致（跳戏）THEN P0：以落地页为准改广告，当天修
  - C-6 IF 新素材上线 <3 天或点击 <50 THEN 保护期：不做判定，不做删除；ELSE 按 CTR/转化评估去留
  - C-7 IF 素材库周净增 <3 条新方向 THEN 预警创意产能 → 提前排素材档期
- **需求单格式**：① 替换对象（哪条素材、上线天数、CTR 多少）② 失败原因（视觉/首屏/文案/疲劳）③ 新方向建议（人群×场景×卖点，不要同主题微调）④ 交付时间（48h）。

#### R · 效果复盘（16:00–17:00）

- **目的**：闭环日循环：回看 72h 前的动作是否达预期；判定 A/B 测试；检查学习期是否脱离；沉淀「赢家特征」。
- **R-1 动作回看（72h 验证窗口）**：取动作日志中所有已到 72h 的动作，FOR 每条：
  - IF 实际指标达成预期（±15%）THEN 标记「有效，固化」→ 考虑是否放量或推广到同类
  - ELIF 未达成预期 THEN 标记「无效，回滚或换动作」→ 记录根因（误诊？执行错？外部变化？）
  - ELIF 数据不足以判断（样本<50/大促期）THEN 延长观察 48h，暂不下结论
- **R-2 A/B 测试判定**：
  - R-2.1 FOR 每个进行中的 A/B：IF 样本不足（转化 <50/组）THEN 继续跑，不出结论；ELIF 胜者明显（胜率 >60% 或 CPA 差 >20%）THEN 淘汰输家 → 胜者放量或转正；ELIF 结果接近（无统计差异）THEN 按成本/可扩展性人工选型 → 或加大样本再测
  - R-2.2 IF 新素材 3 天 0 转化且点击>50 THEN 淘汰，换新方向（勿同主题微调）
- **R-3 学习期与结构检查**：
  - R-3.1 IF Learning >7 天未脱离 THEN ①合并重复受众 ②扩受众 ③合并低预算AdSet ④停频繁编辑
  - R-3.2 IF 账户结构混杂（测试与收割混跑/单Campaign占预算>50%）THEN 排期重组（低活跃时段执行）,14天观察
  - R-3.3 沉淀：今日「赢家素材/受众特征」→ 写入素材方法论文档 → 供 C 环节与创意团队复用

#### D · 日报输出（17:00–17:40）

- **目的**：用 40 分钟输出一份「五段式日报」（非流水账），让管理层 2 分钟读懂：今天哪里异常、为什么、做了什么、效果如何、明天重点。
- **五段式模板**：

| 段 | 内容 | 示例 |
|----|------|------|
| ① 今日概览 | 整体花费 / GMV / ROAS vs 目标，偏差>15% 项标红 | 花费 $4,210 / ROAS 3.2（目标3.0，达标） |
| ② 异常与根因 | 只列异常对象：层级+字段+证据值+根因 | AdSet-A CPA$58（均值2.2x）→ 素材拖累（交叉验证） |
| ③ 今日动作 | 动作类型+对象+预期+验证窗（引用日志编号） | 暂停 Ad-v3 → 预期 ROAS+15%(72h) |
| ④ 结果回看 | 72h 前动作的达成情况 | 9/5 扩量20% → ROAS 3.0→3.2 有效 |
| ⑤ 明日重点 | 明日 P0/P1 + 待回看项 + 排期提醒 | 新素材3条上线跟踪；AdSet-B 待交叉验证 |

- **日报纪律**：每条结论必须带证据值（不允许「感觉变差了」）；所有动作引用动作日志编号；异常必须先排归因再下结论。

#### P · 次日规划（17:40–18:00）

- **目的**：把今天未闭环的 + 明天要发生的，变成一份可执行的次日清单。
- **P-1 ~ P-6 决策树**：
  - P-1 IF 存在未闭环的 P0/P1 THEN 排入明日晨会第一项，指定责任人
  - P-2 IF 明日有动作到 72h 回看点 THEN 写入明日 R 环节待回看清单
  - P-3 IF 明日有新素材/Campaign 上线 THEN 确认素材到位 + 预留观察预算 + 设保护期提醒
  - P-4 IF 未来 3-7 天有大促/活动（如 BFCM）THEN 提前 2 天扩预算 + 备 2x 素材 + 排班值守
  - P-5 IF 素材库存不足（周净增<3）THEN 明日晨会提创意产能预警
  - P-6 输出：明日时间块安排（排雷→监控→排查→动作→复盘→日报）

### 4. 动作铁律与验证窗口

- **动作铁律**：只动 1 个变量；同日禁止 预算+受众+素材 连环改（无法归因）。环节内落实：B-1 根因是素材就绝不调预算；W 层只标记不砍预算；I-2 样本不足不判效；B-5 扩量分 2-3 次、一次不超 +50%。
- **验证窗口**：48h / 72h / 7d——**素材 48h、动作 72h、结构调整 7d**，未达预期回滚。R-1 用 ±15% 达成带判定「有效固化 / 无效回滚」。
- **A-1 字段阈值速查**（附录，与 A-2/A-3 配套）：

| 字段 | 正常 | 观察 | 异常（动作） |
|------|------|------|--------------|
| Pacing 消耗速率 | 80–120% | ±15–30%偏离 | <60% 欠投(B-2) / >130% 超投(B-3) |
| CTR（素材） | 图≥0.8% / 视频≥1.0% | 0.5–0.8% | <0.5% → C-1 素材问题 |
| 出站 CTR（曝光→点击） | ≥1% | 0.7–1% | <0.7% → C 素材/Offer |
| CPA 达成率 | 0.8–1.2x 目标 | 1.2–1.5x | >1.5x 连续3天 → I 穿透 |
| ROAS | ≥目标 | 0.7–1.0x | <0.7x 连续2-3天 → I 穿透 |
| 频次（7天） | ≤3 | 3–5 | >5 且 CTR 跌 → C 上新+扩受众 |
| EQ（事件质量） | 购买≥8 / 其余≥6 | 4–6 | <4 → P0 修事件 |
| LPV/出站点击 | ≥70% | 60–70% | <60% → L4 加载/链路 |
| VC/LPV（浏览率） | ≥60-70% | — | <60% → L4 首屏承接 |
| ATC/VC（加购率） | 3–8% | — | <3% → L4 产品说服力 |
| IC/ATC（结账发起） | ≥60% | 40–60% | <40% → L4 运费/总价 |
| Purchase/IC | ≥70%（ATC→P≥30%） | 50–70% | <50% → L4 结账摩擦 |
| 归因差异（后台/归因） | ≤20% | 20–30% | >30-40% → P0 追踪修复 |
| 3秒播放率 / 完播 | ≥30% / 15s≥25% | — | <20% / <5% → C-2/C-3 |

- **A-2 动作影响预估（速查，10 条）**：继续观察（偏离±15%内/学习期，3天）；扩预算+20%（ROAS≥1.3x 且 Learning 完成，花费+20% 转化+10-15%，48h）；扩预算+50%（高ROI放量期分3次，ROAS 短期-10-20% 7天恢复，7天）；缩预算-50%（CPA>1.5x 连续3天止血，转化-30-40%，48h）；暂停劣质 AdSet（交叉验证确认受众差，ROAS+15-30%，48h）；换/补素材3-5条（CTR<0.5%/疲劳/新方向测试，CTR+10-25% CPA-10-20%，72h）；重剪前3秒（3秒率<20%，完播+30-100%，48h）；优化落地页改版（LP CVR<1%/漏斗断点，CVR+30-100% ROAS+20-50% 影响最大，7-14天）；设频次上限 3/7天（频次>5 且 CTR 跌，无效曝光-20-40%，72h）；归因/像素修复（EQ<4/归因差>30%，恢复真实口径影响所有判断，48h）。
- **A-3 动作日志模板（每日维护）**：日期 | 对象（Campaign/AdSet/Ad）| 诊断结论（异常+证据值）| 动作类型 | 改动明细 | 预期影响 | 72h实际 | 复盘。日报③段与 R-1 回看均引用其编号。
- **核对方法**：任取一条真实数据 → 从 G 全局树进入对应环节 → 按环节决策节点逐条 IF 判定 → 命中 THEN 执行并记入 A-3 动作日志 → 72h 后回 R 环节核对。阈值不适用品类时直接改 Excel 对应格并在「校准」列注明。

### 5. 与诊断 SOP 的关系（人执行版 ↔ 规则资产版）

- S6 是**人类投放师执行版**：以「一天的时间 × 环节」组织，回答「现在该停在哪个环节、按什么顺序判断、谁来闭环」；S4/S5/S7 诊断体系是**规则资产版**：S4 按 G0–G8×65 节点、S7 按 T0–T5 主树+L0–L4 五层组织，回答「某个异常对象怎么穿透定位根因、出什么动作」。
- **阈值同源但口径有差异**：Pacing<60%/>130%、归因差>30%、ROAS<0.7x 连续2-3天、频次>5、样本<50不判效、Learning<50不动预算等在两边一致 `[推断：同源于 v1~v4 资产]`；EQ 阈值两边曾不一致——S6 G 树排雷用 EQ<6，W-0/A-1 判 P0 用 EQ<4（与 S7 T0.1「EQ(Purchase)<4」一致）；**已裁决（C1，2026-11-27 业务确认）：EQ<4=P0 为主口径，S6 G 树 EQ<6 判为笔误**。
- S6 的 P0 修复出口直接引用 S7 分层节点编号（L0-02 事件质量、L0-06 政策合规、L4-02 落地页到达），说明两份「业务提供」文档共用同一套 L0–L4 节点坐标系。
- **对 Agent 的意义**：S6 的 8 环节 + 环节内 IF/ELSE 节点可直接映射为 Agent 的日节奏编排（晨间巡检 → 异常穿透 → 午后动作 → 复盘 → 日报）；每个决策节点的 THEN 动作是动作白名单的人类基准，A-3 动作日志是 Agent 动作日志的字段原型 `[推断]`。

## 高频问答索引

- **Q：投放师的一天按什么顺序做事？能跳环节吗？**
  A：09:00 晨会 M → 09:30–10:30 W 监控 → 10:30–12:00 I 排查 → 13:00–14:30 B 预算 → 14:30–16:00 C 素材 → 16:00–17:00 R 复盘 → 17:00–17:40 D 日报 → 17:40–18:00 P 规划。主干口诀「排雷→监控→穿透→动作」；且**任何环节开始前先做账户级 15 秒排雷**（EQ<4 / 账户受限 / 归因差>30% 任一命中即 P0 收口；S6 原文 G 树排雷写 EQ<6，经 C1 裁决为笔误，按 EQ<4 执行），命中 P0 时该对象今日不做任何投放判断。
- **Q：哪些情况下禁止直接动预算？**
  A：三条——①根因是素材问题（CTR<0.5%/疲劳）时预算分文不动，去 C 换素材；②Learning 未满 50 转化时禁止动预算（每次编辑重置学习）；③W 层只标记「需排查」不砍预算，必须进 I 穿透定根因。同日禁止预算+受众+素材连环改（无法归因）。
- **Q：Campaign 处于 Learning 怎么处理？**
  A：只看趋势 + 记学习进度，不做任何动作；Learning 7 天+ 未脱离才介入（R-3.1：合并重复受众 / 扩受众 / 合并低预算 AdSet / 停频繁编辑）。B-8 同样禁止动预算。
- **Q：排查时怎么区分是素材问题还是受众问题？**
  A：I-2 交叉验证——取「差 AdSet」与「好 AdSet」共用的同一素材对比：同素材在好受众好、差受众差 → 受众问题（B-4 关停差受众/单独降价30%）；差素材在所有受众都差 → 素材问题（C-1 换新方向）；样本<50 转化 → 继续观察不动作。
- **Q：落地页 CVR 低怎么定位断在哪一层？**
  A：I-3 六层漏斗找「断崖式下降」：曝光→点击（出站CTR≥1%）→ 到达（LPV/出站点击≥70%）→ 浏览（VC/LPV≥60-70%）→ 加购（ATC/VC 3-8%）→ 结账（IC/ATC≥60%）→ 购买（Purchase/IC≥70%，ATC→P≥30%）+ 归因兜底（差≤20%）。近14天消耗<$50 只做整站整体诊断不细分；断点在「点击→到达」<60% 按技术问题修复后 48h 复测。
- **Q：素材什么时候换、怎么给创意团队提需求？**
  A：C-1：素材 CTR<0.5% 或周环比-30%+（疲劳）即列「需替换」。需求单四要素：替换对象（素材/上线天数/CTR）、失败原因（视觉/首屏/文案/疲劳）、新方向建议（人群×场景×卖点，不要同主题微调）、交付时间 48h。素材库周净增<3 条新方向 → 预警创意产能。
- **Q：新素材上线后多久能判？素材疲劳怎么识别？**
  A：C-6 保护期——上线 <3 天或点击 <50 不做判定不做删除；之后按 CTR/转化评估去留。疲劳信号：CTR<0.5% 或周环比-30%+（I-1.5 佐证频次>4）；W-3 频次>5 且 CTR 下滑 → 标素材疲劳进 C；R-2.2 新素材 3 天 0 转化且点击>50 → 淘汰换新方向。
- **Q：动作做完多久验证一次？不达预期怎么办？**
  A：验证窗口 48h（素材）/72h（动作）/7d（结构调整）。R-1 回看：实际指标达成预期 ±15% → 「有效，固化」可放量；未达成 → 「无效，回滚或换动作」并记录根因（误诊？执行错？外部变化？）；样本<50/大促期 → 延长观察 48h 不下结论。归因/像素类 P0 修复后 48h 复测。
- **Q：日报必须包含什么？有什么纪律？**
  A：五段式——①今日概览（花费/GMV/ROAS vs 目标，偏差>15% 标红）②异常与根因（层级+字段+证据值+根因）③今日动作（类型+对象+预期+验证窗，引用日志编号）④结果回看（72h 前动作达成情况）⑤明日重点（P0/P1+待回看项+排期提醒）。纪律：每条结论带证据值、所有动作引用动作日志编号、异常必须先排归因再下结论。
- **Q：这份 SOP 和 Meta 广告诊断与优化 SOP（S4/S5/S7）什么关系？Agent 能直接用吗？**
  A：S6 是人类执行版——按「一天的时间×环节」组织，告诉投放师现在该停在哪；S4/S5/S7 是规则资产版——按 G0–G8×65 节点（S4）或 T0–T5+L0–L4（S7）组织，告诉 Agent 异常对象怎么穿透定位根因。两者阈值大体同源，S6 的 P0 修复引用 S7 的 L0/L4 节点编号；对 Agent 而言 S6 提供日节奏编排与动作白名单的人类基准 `[推断]`。
