## 使用规则

1. **引用阈值时先查本表**：若某指标在多源间有冲突，卡片答案中必须带 `[待确认]` 或注明口径。
2. **新增源时回填**：新文档若再出现同名指标不同值，追加 C18+ 并在对应卡片标注。
3. **冲突裁决路径**：业务侧确认 → 更新源文档 → 重跑 raw 快照 → 修订卡片 → 本表状态改「已裁决」并记录裁决口径。
4. **本表只登记不裁决**：除「无冲突」项外，所有冲突当前均为开放状态，等待业务确认。**例外**：2026-11-27 业务侧已对 C1/C4/C5/C9 四项给出裁决（见裁决分级表），口径已回填卡片；后续新冲突仍按开放状态登记。
