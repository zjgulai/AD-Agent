# 竞品分析 Q&A

覆盖 `cards/competitor-analysis/`（1 卡：ad-agent-competitor-landscape，源 S12–S15）。

### Q1. Navos 是什么？有哪些 Agent？
**A**：钛动科技的出海营销 AI 产品，「AI 广告团队」。六 Agent：市场洞察（24h 监测趋势/竞品）、创意策划（策略+Campaign 方案）、创意创作（文生图/图生视频）、广告投放（直连 Meta/TikTok/Google 自动投放+A/B 测试）、数据分析（ROI/人群/素材→优化建议）、资产管理（素材库/版本/历史）。
> 溯源：`cards/competitor-analysis/ad-agent-competitor-landscape.md`

### Q2. Navos 除投放外还做什么？
**A**：调研拆出 VOC 分析、GEO/AI 可见性诊断、竞品营销数据追踪（上架时间/库存/打法）、KOL 布局分析（Htag）、素材审核（含 Meta 预审风险分级）、投放分析报告（含素材衰退预警与行动清单）。
> 溯源：`cards/competitor-analysis/ad-agent-competitor-landscape.md`

### Q3. GrowthGPT 的产品结构是什么？数据从哪来？
**A**：四层结构——AI 大模型底座（脑）、专家技能层（知识库+投手经验）、广告平台 API 层（手，对接 Meta/TikTok/Google）、自然语言交互层（对话即操作）。六大功能：市场洞察/增长策略/预算分配/素材生产/广告投放/实时优化。数据四路：①Claude/OpenAI/Seedance 等大模型实时跟随更新；②十几家 API（平台方 + AppLovin/FastMoss/Kalodata 第三方数据）拉取+交叉验证；③十年+投手经验蒸馏成专家 skill 模型；④ChatGPT 式对话交互。
> 溯源：`cards/competitor-analysis/ad-agent-competitor-landscape.md`

### Q5. 竞品能给自家广告 Agent 提供什么参考？
**A**：`[推断]`：Navos 的素材预审分级/衰退预警/行动清单输出形态、GrowthGPT 的「经验蒸馏+平台 API」双引擎逻辑可借鉴；红人素材加推 Loop 是竞品未覆盖的差异化场景。
> 溯源：`cards/competitor-analysis/ad-agent-competitor-landscape.md`

### Q6. 三个竞品的定位差异是什么？
**A**：Navos 偏「全链路 AI 广告团队」（钛动科技出海营销，六 Agent 覆盖洞察→创意→投放→分析→资产）；GrowthGPT 偏「对话式增长副驾」（四层结构+经验蒸馏，交互即操作）；Zalify 资料不足无法定位 `[待确认]`。Momcozy 自建体系的差异化在红人素材加推 Loop 与 Meta 深度诊断 SOP（S4/S6/S7），竞品均未覆盖这两块 `[推断]`。
> 溯源：`cards/competitor-analysis/ad-agent-competitor-landscape.md`
